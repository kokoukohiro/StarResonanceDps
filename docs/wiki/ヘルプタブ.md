アプリのバージョンを確かめ、使い方などのページを開くタブです。

## 見方

- 上の欄: アプリの名前・バージョン・紹介
- 「リンク」の欄: 押すと次のページを開きます

| 欄 | 開くページ |
|---|---|
| 使い方 | このWikiの[Home](Home) |
| プラグインの作り方 | このWikiの[プラグイン開発](プラグイン開発) |
| GitHub | GitHubのリポジトリのホームページ |
| リリースノート | GitHubのリリースのページ(バージョンごとの変更点) |

- いちばん下: 著作権とライセンス。「ライセンス情報」を押すと、GitHubのライセンスの説明のページを開きます

## 操作

- 欄を押すと、ブラウザでそのページを開きます

## 注意

- ページを開くには、インターネットへの接続が必要です
- ライセンスの本文と、使っているライブラリのライセンスは、アプリのフォルダの`LICENSE`・`LICENSING.md`・`THIRD-PARTY-NOTICES.txt`にもあります
