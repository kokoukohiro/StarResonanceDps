'[플러그인](플러그인)'의 행을 눌러 여는 창을 플러그인으로 만들기 위한 설명입니다. 모든 플러그인에 필요한 것은 [플러그인 개발](플러그인-개발)에 있습니다.

## 만드는 방법

진입점 클래스에 `IPluginWindowProvider`를 구현합니다. 창이 있는 플러그인에는 `PluginGenre`가 필요합니다.

```csharp
using System.Windows;
using System.Windows.Controls;
using StarResonanceDps.PluginSdk;

[assembly: PluginRegistration(typeof(MyPlugin.Plugin), PluginSdkVersion.Current)]
[assembly: PluginDisplayName("ja-JP", "私のプラグイン")]
[assembly: PluginGenre("ja-JP", "ツール")]
[assembly: PluginAuthor("YourName")]
[assembly: PluginVersion("1.0.0")]

namespace MyPlugin;

public sealed class Plugin : IStarResonancePlugin, IPluginWindowProvider
{
    public void Initialize(IPluginContext context)
    {
    }

    public FrameworkElement CreateContent()
    {
        var text = new TextBlock { Text = "Hello", Margin = new Thickness(16) };
        text.SetResourceReference(TextBlock.ForegroundProperty, PluginResourceKeys.Brushes.TextPrimary);
        return text;
    }

    public PluginWindowOptions? GetWindowOptions()
    {
        return new PluginWindowOptions(width: 720, height: 640, minWidth: 480, minHeight: 320);
    }

    public void Shutdown()
    {
    }
}
```

| 멤버 | 하는 일 |
|---|---|
| `CreateContent` | 창의 내용을 반환합니다. 창을 열 때마다 호출되므로, 매번 새로 만들어 반환합니다. `Window`가 아니라 `UserControl` 등의 요소를 반환합니다. |
| `GetWindowOptions` | 창을 열 때의 크기와 최소 크기를 반환합니다. 생략하거나 `null`을 반환하면 앱의 기본 크기가 됩니다. |

- `CreateContent`가 `null`을 반환하면 플러그인이 멈춥니다.
- `PluginWindowOptions`의 값은 모두 0보다 크게 하고, 크기는 최소 크기 이상으로 합니다. 맞지 않으면 `ArgumentOutOfRangeException`이 되어 플러그인이 멈춥니다.
- 내용이 `IDisposable`이면 창을 닫은 뒤에 `Dispose`가 호출됩니다. 이벤트 구독이나 타이머는 거기서 해제합니다.
- `CreateContent`, `GetWindowOptions`, `Dispose`는 UI 스레드에서 호출됩니다. 예외를 내면 플러그인이 멈춥니다.

## 창의 동작

- 창의 틀과 위쪽 줄(아이콘, 플러그인 이름, 최소화, 최대화, 닫기)은 앱이 만듭니다. 내용은 위쪽 줄 아래의 전부이며, 여백과 스크롤은 없습니다.
- 창은 하나의 플러그인에 1개입니다. 열려 있을 때 행을 누르면 그 창을 앞으로 가져옵니다(`CreateContent`는 호출하지 않습니다).
- 창은 메인 화면의 왼쪽 위 근처에 표시됩니다. 크기와 위치는 저장하지 않습니다. 열려 있었는지도 저장하지 않으므로, 다음 실행 때는 열리지 않습니다.
- 창은 항상 위에 표시되지 않으며, 작업 표시줄에 표시됩니다.
- 메인 화면을 닫으면 플러그인 창도 닫힙니다.
- 앱이 플러그인을 멈출 때는 창을 닫고 내용을 `Dispose`한 뒤에, `Stopping`의 취소와 `Shutdown`을 합니다.

## 모양

- 내용의 모양은 자유롭게 만들 수 있습니다. 창의 바탕은 설정의 '테마'의 '창 색상'입니다.
- 창은 글자 색과 글꼴을 정하지 않습니다. 내용의 글자에는 앱의 색(`Brush.TextPrimary` 등)과 글꼴(`Font.ProjectDefault`)을 붙여 주세요.
- 내용의 `DataContext`에는 앱의 값이 이어져 있습니다. 바인딩을 사용할 때는 직접 넣어 주세요.

### 앱의 모양 키

앱의 모양은 `PluginResourceKeys`의 키로 사용할 수 있습니다. 여기에 있는 키의 이름은 바뀌지 않습니다. 여기에 없는 키는 앱의 것으로, 예고 없이 바뀝니다.

```xml
<TextBlock Text="Hello"
           Foreground="{DynamicResource Brush.TextPrimary}"
           FontFamily="{DynamicResource Font.ProjectDefault}" />
<Button Content="OK" Style="{StaticResource Button.Text}" />
```

- 브러시를 `DynamicResource`로 가져오면 테마 색의 변경을 따라갑니다. `StaticResource`로 가져온 브러시는 변경 전의 색 그대로 남습니다.
- 코드에서 붙일 때는 `SetResourceReference`를 사용합니다(위의 만드는 방법의 예).

| 묶음(`PluginResourceKeys` 아래) | 키 |
|---|---|
| 색(`Brushes`) | `Brush.WindowSurface`, `Brush.PanelBackground`, `Brush.Border`, `Brush.BorderSoft`, `Brush.ControlBackground`, `Brush.ControlActiveBackground`, `Brush.InputBackground`, `Brush.InputHoverBackground`, `Brush.TextPrimary`, `Brush.TextSecondary`, `Brush.TextMuted`, `Brush.Success` |
| 글자(`Text`) | `Font.ProjectDefault`, `Text.WidgetWindow`, `Text.WidgetWindowSubtitle`, `Effect.WidgetWindowTextShadow` |
| 버튼과 링크(`Buttons`) | `Button.Text`, `Button.Icon`, `Hyperlink.Base`, `Hyperlink.Inline` |
| 입력(`Inputs`) | `Input.PathBox`, `Input.MultilineTextBox`, `Input.SearchBox`, `Input.SelectBox`, `Input.SettingsComboBox`, `Input.SettingsComboBoxItem`, `Input.Switch`, `Input.ValueSlider` |
| 틀(`Panels`) | `Surface.RoundedOutline`, `Surface.RoundedButtonOutline`, `Panel.Root`, `Panel.SettingSection`, `Panel.SettingField`, `Panel.SettingFieldLast` |
| 스크롤(`Scrolling`) | `ScrollViewer.WidgetList`, `ScrollBar.WidgetList`, `ScrollViewer.WidgetWindow`, `ScrollBar.WidgetWindow` |
| 툴팁(`ToolTips`) | `ToolTip.Info`, `ToolTip.WidgetWindowInfo`, `ToolTipOwner.Default`, `ToolTipOwner.KeepsOnClick` |
| 치수(`Sizes`) | `Radius.Default`, `Radius.Button`, `Padding.Card` |
| 아이콘(`Icons`) | 그리는 방법의 `Icon.Stroke`(선), `Icon.Fill`(채우기)와, 모양의 `Icon.Search`, `Icon.Add`, `Icon.ChevronDown`, `Icon.ChevronRight`, `Icon.Copy`, `Icon.Settings`, `Icon.Filter`, `Icon.Sort`, `Icon.EyeOff`, `Icon.MoreVertical`, `Icon.Help`, `Icon.Wrench`, `Icon.Sliders` |

- 모든 키의 모양은 [SampleWindow](https://github.com/kokoukohiro/StarResonanceDps/tree/main/StarResonanceDps.Plugins.Samples/SampleWindow)의 창에서 나란히 볼 수 있습니다.
- `Text.WidgetWindow`, `Text.WidgetWindowSubtitle`, `Effect.WidgetWindowTextShadow`는 위젯의 어두운 바탕을 위한 흰 글자와 그림자입니다.
- `ToolTip.WidgetWindowInfo`, `ScrollViewer.WidgetWindow`는 위젯 창의 색을 읽으므로, 위젯 안에서만 사용합니다([플러그인 개발(위젯)](플러그인-개발(위젯))).
- 아이콘은 `Path`의 `Style`에 그리는 방법의 키를, `Data`에 모양의 키를 넣습니다(`Style="{StaticResource Icon.Stroke}" Data="{DynamicResource Icon.Search}"`).

### 툴팁

- 앱과 같은 툴팁으로 할 때는, 툴팁을 붙이는 요소의 `Style`에 `ToolTipOwner.Default`(누르면 무언가 일어나는 요소)나 `ToolTipOwner.KeepsOnClick`(눌러도 아무 일도 일어나지 않는 요소)을 붙이고, `ToolTip`에 `ToolTip.Info`의 툴팁을 넣습니다.
- `Style`은 하나의 요소에 1개이므로, `Button.Text` 등의 스타일을 붙인 요소에는 붙일 수 없습니다.

### 사용할 수 없는 것

- 앱의 행 정렬과, 행을 넘는 문자의 선택과 복사는 앱의 형식을 사용하는 구조이므로, 플러그인에서는 사용할 수 없습니다.
- '예', '아니요'를 고르게 하는 창은 없습니다(메시지 창은 [플러그인 개발](플러그인-개발)의 '메시지').
