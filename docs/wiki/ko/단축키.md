![단축키](images/ko/Settings4.png)

키를 눌러 위젯의 실행이나 고정, 측정 등을 하는 기능입니다. 키는 [설정](설정)의 '단축키'에서 정합니다.

## 조작 목록

| 항목 | 기본 키 | 하는 일 |
|---|---|---|
| 플레이어 이름 표시/숨기기 | Ctrl+F11 | 설정의 '플레이어 이름'을 전환합니다. '표시'면 '숨기기'로, 그 외에는 '표시'로 합니다. |
| 즐겨찾기 시작/모두 중지 | Ctrl+F8 | 실행 중인 위젯이 있으면 모두 중지하고, 없으면 즐겨찾기한 위젯을 실행합니다. |
| 실행 중 고정/고정 모두 해제 | Ctrl+F7 | 고정한 위젯이 있으면 모두 해제하고, 없으면 실행 중인 위젯을 모두 고정합니다. |
| 고정 항목 마우스 통과/마우스 통과 모두 해제 | Ctrl+F6 | 마우스 통과인 위젯이 있으면 모두 해제하고, 없으면 고정한 위젯을 모두 마우스 통과로 합니다. |
| 항상 위에 표시/고정 시에만 위에 표시 | Ctrl+F5 | 설정의 '위젯 창'을 전환합니다. |
| 측정 | Ctrl+F10 | '[집계](집계)'의 '측정'과 같습니다(측정하는 동안에는 측정을 멈춥니다). |
| 리셋 | Ctrl+F9 | '[집계](집계)'의 '리셋'과 같습니다. |

## 키 지정 방법

1. 설정의 '단축키'에서 바꿀 항목의 칸을 누릅니다. 칸에 '키를 입력'이 표시됩니다.
2. 지정할 키를 누릅니다. Ctrl, Alt, Shift와의 조합도 할 수 있습니다.
3. '저장'을 누르면 확정됩니다.

- 같은 키를 지정했던 다른 항목은 빈칸이 됩니다.
- 다른 앱이 사용하고 있는 키는 지정할 수 없습니다. '단축키 오류' 창이 표시되고 이전 키 그대로 남습니다.
- '키를 입력'이 표시된 동안 칸 밖을 누르면 취소되고 이전 키로 돌아갑니다.
- '키를 입력'이 표시된 동안 누른 키는 Esc, Delete도 지정됩니다. 지정을 빈칸으로 하는 조작은 없습니다.
- 설정의 '초기화'로 기본 키로 되돌릴 수 있습니다.

## 주의 사항

- 단축키는 게임이나 이 앱이 앞에 있을 때만 작동합니다. 그때 누른 키는 게임에 전달되지 않습니다. 다른 앱이 앞에 있을 때는 키가 그 앱에 그대로 전달됩니다.
- 단축키를 받으려면 보조 프로그램이 필요합니다. 앱을 실행할 때 보조 프로그램을 실행하며, 사용자 계정 컨트롤 확인이 표시됩니다. '아니요'를 고르면 '단축키 오류' 창이 표시되고, 이번 실행 중에는 단축키를 사용할 수 없습니다.
- 보조 프로그램이 작동하지 않는 동안에는 설정의 '단축키'가 표시되지 않습니다. 단축키를 사용하지 않을 때는 설정의 '시작 설정'에서 '앱 시작 시 단축키 보조 프로그램 실행'을 끄세요.
- '[위젯](위젯)'의 점 3개 메뉴 항목 뒤에도 그 조작의 키가 표시됩니다.
