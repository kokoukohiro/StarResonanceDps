![버프·디버프 카드](images/ko/BuffDebuffCard1.png)

플레이어나 적에게 붙어 있는 버프·디버프를 1개 골라, 이름, 아이콘, 남은 시간을 크게 표시하는 위젯입니다.

## 여는 방법

- '[위젯](위젯)'의 '버프·디버프 카드' 카드에서, 이름 칸의 선택 목록으로 항목을 고르고 실행 버튼을 누릅니다. 다음 순서로 나열됩니다.
  1. 설정의 '바로가기'에서 켠 행(대상은 자신)
  2. '버프 목록' 카드의 이름 칸에서 고른 대상의 버프
  3. '디버프 목록' 카드의 이름 칸에서 고른 대상의 디버프
  4. 열려 있는 창 중 위에 없는 것
- 기본 항목은 바로가기의 1번째이며, 기본 설정이면 '버프 카드(요리) - 자신의 이름'입니다.
- 나열할 것이 없을 때는 이름 칸이 '버프·디버프 카드'만 됩니다. 이때 실행 버튼을 누르면 자신의 버프 목록(없으면 디버프 목록)의 1번째 행의 카드를 엽니다. 그것도 없으면 빈 창을 열고, 처음으로 붙은 것의 카드가 됩니다.
- [버프 목록](버프-목록)과 [디버프 목록](디버프-목록)의 행을 누르거나, 행을 우클릭해서 '버프 카드', '디버프 카드'를 고르면 그 버프·디버프의 카드를 엽니다.
- [엔티티 정보](엔티티-정보)의 칸과 [버프·디버프 그룹](버프·디버프-그룹)의 행을 우클릭해서도 열 수 있습니다. 그룹의 행은 눌러도 열립니다.
- 대상과 버프의 조합마다 창을 엽니다. 같은 조합의 창이 열려 있으면 그 창을 앞으로 가져옵니다.

## 보는 방법

- 제목: '버프 카드(버프 이름) - 대상의 이름'이나 '디버프 카드(디버프 이름) - 대상의 이름'입니다. 요리와 포션은 '버프 카드(요리)', '버프 카드(포션)'입니다.
- 본체: 위부터 이름 줄(표시 설정의 '버프 이름'), 아이콘, 남은 시간입니다. 겹친 수가 2 이상일 때는 아이콘 위에 수를 겹쳐 표시합니다. 남은 시간을 표시하는 방법은 버프 목록과 같습니다.
- 요리와 포션은 종류별로 따라갑니다. 다시 먹어 다른 요리·포션으로 바뀌어도 같은 창에 표시합니다.
- 같은 버프가 여러 사람에게서 붙어 있을 때는 남은 시간이 가장 긴 것을 표시합니다.
- 효과가 끝나면 이름 줄만 남습니다. 같은 버프가 다시 붙으면 다시 표시됩니다.
- 헤더: 닫기 버튼 왼쪽에 '축소', '확대' 버튼이 있습니다.

## 조작

- 축소·확대: 본체의 크기를 25%씩 100~1000% 사이에서 바꿉니다(기본값: 200%). 창의 크기는 바뀌지 않습니다. 배율은 카드별(요리·포션은 종류별, 적은 적의 종류별)로 저장되며, 다음에 같은 카드를 열 때도 사용됩니다.
- 우클릭하면 다음 항목을 고를 수 있습니다. 표시할 항목이 없을 때는 메뉴가 열리지 않습니다.
  - '그룹에 추가': [버프·디버프 그룹](버프·디버프-그룹)에 추가합니다. 자신의 카드에서, 그룹에 아직 들어 있지 않은 버프에 표시됩니다.
  - '버프·디버프 카드 바로가기에 추가': 바로가기에 추가합니다. 자신의 카드에서, 바로가기에 아직 들어 있지 않은 버프에 표시됩니다.
  - '이 버프를 알림 대상으로 지정', '이 버프를 알림 대상에서 제외'(디버프는 '이 디버프를 …'): 알림 대상을 전환합니다. 모든 카드에 표시됩니다.
- 우클릭으로 바꾼 내용은 그 자리에서 저장됩니다.

## 설정

창 설정과 테마는 [위젯 공통 설정](위젯-공통-설정)에 있습니다.

### 표시 설정

- 버프 이름: 이름 줄에 표시할 내용을 씁니다. 선택 목록에서 항목을 고르고 '삽입'을 누르면 그 문자가 들어갑니다(기본값: `{BuffName}({TargetName})`).

| 항목 | 문자 | 표시되는 내용 |
|---|---|---|
| 버프 이름 | `{BuffName}` | 버프의 이름. 요리와 포션은 '요리', '포션'. |
| 대상자 이름 | `{TargetName}` | 카드의 대상의 이름. |
| 부여자 플레이어 이름 | `{CasterName}` | 표시하고 있는 버프를 붙인 플레이어의 이름. 플레이어 이외가 붙였을 때는 빈칸. |
| 레벨 | `{Level}` | 카드의 대상의 레벨 수치. |
| 줄바꿈 | `{NewLine}` | 줄바꿈. |

값이 비어 남은 괄호는 지워집니다. 쓰는 방법은 모든 카드에서 같습니다.

### 바로가기

카드의 이름 칸의 선택 목록 맨 앞에 표시할 행입니다. 스위치로 켜고 끄며, 행을 드래그해 정렬합니다. 기본값은 다음 7행입니다.

| 행 | 기본값 |
|---|---|
| 요리 | 켜기 |
| 포션 | 켜기 |
| 시간 지연 | 켜기 |
| 기계 고장 | 켜기 |
| 정체된 원소 | 켜기 |
| 탈진・화염 분신 | 켜기 |
| 허약・기도 금지 | 끄기 |

자신의 버프 목록·디버프 목록의 행과 자신의 카드를 우클릭해 '버프·디버프 카드 바로가기에 추가'로 추가할 수 있습니다. 추가한 행은 끄고 저장하면 사라집니다.

### 알림 대상

카드를 열고 있는 동안 [알림](알림)의 '버프·디버프 효과 종료'로 효과 종료를 알릴 버프·디버프입니다. 기본 행과 켜기·끄기는 바로가기와 같습니다. 카드를 우클릭해 '이 버프를 알림 대상으로 지정'으로 추가할 수 있습니다. 모든 카드에서 같은 목록을 사용합니다.

## 주의 사항

- 다른 플레이어의 카드는 그 사람이 주위에 없는 동안 이름 줄만 됩니다. 적의 카드는 그 적이 쓰러지거나 멀어지면 이름 줄만 됩니다.
- 버프 목록의 숨김 목록은 카드에는 적용되지 않습니다.
- 기록을 열고 있어도 현재의 버프를 표시합니다.
- 1초마다 다시 읽습니다.
- 실행 중인 채로 앱을 닫은 카드는 다음 실행 시 같은 대상과 버프로 다시 열립니다. 적의 카드는 같은 종류의 적이 나타났을 때 그 적을 표시합니다.
