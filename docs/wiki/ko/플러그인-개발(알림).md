'[알림](알림)'에 항목을 추가하고, 플러그인이 정한 시점에 알리기 위한 설명입니다. 모든 플러그인에 필요한 것은 [플러그인 개발](플러그인-개발)에 있습니다.

| 앱이 갖는 것 | 플러그인이 넘겨주는 것 |
|---|---|
| '알림' 목록의 행과 체크, 문장 입력 칸과 미리보기, 알림 방식, 알림 음량, 음성 읽기 방식, 화자, 값의 저장 | 항목의 정의(이름, 기본 문장, 삽입 항목, 항목의 설정)와 알리는 시점(`Notify`) |

## 만드는 방법

진입점 클래스에 `IPluginNotificationProvider`를 구현합니다. `IPluginWindowProvider`의 창이 없는 플러그인이라면 `PluginGenre`는 필요하지 않습니다.

다음 예는 맵을 이동했을 때 알립니다.

```csharp
using StarResonanceDps.PluginSdk;

[assembly: PluginRegistration(typeof(MyPlugin.Plugin), PluginSdkVersion.Current)]
[assembly: PluginDisplayName("ja-JP", "私のプラグイン")]
[assembly: PluginAuthor("YourName")]
[assembly: PluginVersion("1.0.0")]

namespace MyPlugin;

public sealed class Plugin : IStarResonancePlugin, IPluginNotificationProvider
{
    private const string MapEnteredId = "map-entered";

    private IPluginContext? _context;

    public void Initialize(IPluginContext context)
    {
        _context = context;
        context.GameData.MapEntered += OnMapEntered;
    }

    public IReadOnlyList<PluginNotificationDefinition> GetNotificationDefinitions()
    {
        return
        [
            new PluginNotificationDefinition
            {
                Id = MapEnteredId,
                Names = new Dictionary<string, string> { ["ja-JP"] = "マップ移動", ["en-US"] = "Map change" },
                DefaultTexts = new Dictionary<string, string> { ["ja-JP"] = "{MapName}に移動しました", ["en-US"] = "Moved to {MapName}" },
                Fields =
                [
                    new PluginNotificationField
                    {
                        Key = "MapName",
                        Names = new Dictionary<string, string> { ["ja-JP"] = "マップ名", ["en-US"] = "Map name" },
                        SampleValues = new Dictionary<string, string> { ["ja-JP"] = "アステルリーズ" },
                    },
                ],
            },
        ];
    }

    private void OnMapEntered(object? sender, EventArgs e)
    {
        if (_context is null || !_context.Notifications.IsEnabled(MapEnteredId))
        {
            return;
        }

        int? sceneId = _context.GameData.Session.SceneId;
        string? mapName = sceneId is int id ? _context.Names.GetSceneName(id) : null;
        _context.Notifications.Notify(MapEnteredId, new Dictionary<string, string> { ["MapName"] = mapName ?? string.Empty });
    }

    public void Shutdown()
    {
        if (_context is not null)
        {
            _context.GameData.MapEntered -= OnMapEntered;
        }
    }
}
```

| 멤버 | 호출되는 시점 | 하는 일 |
|---|---|---|
| `GetNotificationDefinitions` | `Initialize` 뒤에 1번(위젯의 정의가 있으면 그 뒤) | 추가할 항목의 목록을 반환합니다. 반환한 순서대로 '알림'에 나열됩니다. 나중에 바꿔도 반영되지 않습니다 |

- 빈 목록을 반환하면 '알림'에는 아무것도 추가되지 않습니다.

### 항목의 정의(`PluginNotificationDefinition`)

| 속성 | 필수 여부 | 내용 |
|---|---|---|
| `Id` | 필수 | 항목의 ID. 1~128자의 영숫자와 '.', '-', '_'입니다. 저장의 키이므로 버전을 넘어 바꾸지 않습니다 |
| `Names` | 필수 | '알림' 목록에 표시되는 항목 이름 |
| `DefaultTexts` | 필수 | 사용자가 문장을 쓸 때까지 사용하는 문장. 삽입 항목은 `{Key}`로 씁니다 |
| `Fields` | 선택 | 삽입 항목(`PluginNotificationField`) |
| `Settings` | 선택 | 항목의 설정. 종류는 위젯의 설정과 같으며, 색(`PluginColorSetting`)만은 사용할 수 없습니다([플러그인 개발(위젯)](플러그인-개발(위젯))의 '설정') |

| 삽입 항목(`PluginNotificationField`)의 속성 | 필수 여부 | 내용 |
|---|---|---|
| `Key` | 필수 | 1~64자의 영문자와 숫자('.', '-', '_'는 사용할 수 없습니다). 문장 안에서는 `{Key}`로 씁니다 |
| `Names` | 필수 | '알림'에서 삽입 항목의 선택 목록에 표시되는 이름 |
| `SampleValues` | 필수 | 미리보기에 넣는 견본 값. 빈 사전이어도 괜찮습니다 |

- 언어별 문자는 언어 이름(`ja-JP` 등)을 키로 한 사전으로 씁니다. 고르는 방식은 속성과 같습니다([플러그인 개발](플러그인-개발)의 '진입점 클래스와 속성').
- 항목의 `Id`는 플러그인 안에서, 삽입 항목의 `Key`와 설정의 `Id`는 항목 안에서 겹치지 않게 합니다. 대소문자는 구분하지 않습니다.

## 알리기

`IPluginContext.Notifications`(`IPluginNotificationService`)를 사용합니다.

| 멤버 | 내용 |
|---|---|
| `IsEnabled(id)` | 사용자가 그 항목에 체크를 했는지 |
| `Notify(id, values)` | 알립니다. `values`는 삽입 항목의 `Key`와 값입니다. 생략할 수 있습니다 |
| `GetSettings(id)` | 항목의 설정의 현재 값(`PluginSettingValues`). 읽는 방법은 위젯의 설정과 같습니다 |
| `SettingsChanged` | 항목의 체크나 설정 값이 바뀌었을 때 UI 스레드에서 오는 이벤트. 값은 항목의 `Id`입니다 |

- `IsEnabled`, `Notify`, `GetSettings`는 어느 스레드에서 호출해도 괜찮습니다.
- 항목은 `Initialize` 뒤에 읽으므로, `Initialize`와 `GetNotificationDefinitions` 안에서는 어느 `Id`든 `ArgumentException`이 됩니다. `SettingsChanged`의 구독은 괜찮습니다.
- 정의에 없는 `Id`나 `Fields`에 없는 `Key`를 넘기면 `ArgumentException`이 됩니다.
- `Notify`는 알리는 시점에 체크가 해제되어 있으면 아무것도 하지 않습니다. 값을 만드는 데 수고가 들 때는 먼저 `IsEnabled`를 봅니다.
- 문장은 사용자의 문장이거나, 없으면 표시 언어의 기본 문장입니다. `{Key}`를 값으로 바꾸고, 값을 넘기지 않은 항목은 비게 됩니다. 정의에 없는 `{…}`는 그대로 남습니다. 문장이 비어 있으면 알리지 않습니다.
- 알렸는지 여부는 반환되지 않습니다. Windows 알림을 띄울 수 없거나 음성을 사용할 수 없을 때도 예외가 되지 않고, 앱의 로그에 남습니다.
- 앱은 알리는 횟수를 줄이지 않습니다. 호출할 때마다 알리고, 음성 읽기와 알림 소리는 1건씩 순서대로 울립니다. 짧은 사이에 여러 번 호출하지 않도록, 간격이나 상한은 플러그인에서 갖습니다.
- 플러그인이 멈춘 뒤에는 `Notify`가 아무것도 하지 않습니다.

### 항목의 설정

- 값은 '알림'에서 바꾸었을 때 그 자리에서 저장되며, `SettingsChanged`가 옵니다. 스위치와 선택 목록은 바꾸었을 때, 숫자는 확정했을 때(Enter나 칸을 벗어났을 때), 문자는 입력을 마치고 0.3초 뒤, 슬라이더는 손잡이를 놓았을 때입니다.
- `SettingsChanged`는 그 항목의 체크나 설정 값이 이전과 다를 때만 옵니다. 문장, 알림 방식, 알림 음량, 음성을 바꾸었을 때는 오지 않습니다.
- 앱을 시작했을 때는 오지 않으므로, 처음 값은 `IsEnabled`, `GetSettings`로 읽습니다.

## '알림'에서의 표시

- 목록의 앱 항목 뒤에, 플러그인 이름의 머리글을 붙여서 나열됩니다. 플러그인은 설치한 순서, 플러그인 안은 정의의 순서입니다.
- 항목은 처음에는 체크가 해제되어 있습니다. 플러그인에서 처음부터 체크를 할 수는 없습니다.
- 오른쪽 위의 문장 칸 아래의 선택 목록에 삽입 항목의 이름이 나열되며, '삽입'으로 `{Key}`를 넣을 수 있습니다. 미리보기에는 견본 값이 들어갑니다.
- 오른쪽 아래에는 항목의 설정이 알림 방식 위에 나열됩니다.
- Windows 알림에는 앱의 이름과 아이콘이 표시됩니다. 플러그인의 이름은 표시되지 않습니다.
- 값은 앱이 `Data\AppSettings.json`에 저장합니다(플러그인 폴더의 설정 파일과는 별개). 플러그인이 멈춰도 남고, 삭제하면 사라지며, 업데이트해도 남습니다.
- 항목의 `Id`나 어셈블리 이름을 바꾸면 다른 항목이 되며, 이전 값은 이어지지 않습니다.

## 오류와 예외

- 정의의 오류(ID나 키의 형태, 중복, 숫자나 슬라이더의 범위, 색의 설정 등)에서는 플러그인이 멈추고, '[플러그인](플러그인)'의 행의 툴팁에 '알림 항목의 구성에 오류가 있습니다'가 표시됩니다. 이유는 영어로 로그에 남습니다.
- `GetNotificationDefinitions`와 `SettingsChanged`의 예외에서도 플러그인이 멈춥니다.
- 항목 이름, 기본 문장, 삽입 항목의 이름이 비어 있으면 빌드가 멈춥니다(SRDPS014).
