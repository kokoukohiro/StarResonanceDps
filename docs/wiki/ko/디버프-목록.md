![디버프 목록](images/ko/DebuffList1.png)

플레이어 1명이나 적 1체에게 붙어 있는 디버프를, 남은 시간과 게이지와 함께 1행씩 나열하는 위젯입니다. 구성은 [버프 목록](버프-목록)과 같으며, 설정은 버프 목록과 따로 가집니다.

## 여는 방법

- '[위젯](위젯)'의 '디버프 목록' 카드에서, 이름 칸의 선택 목록으로 대상을 고르고 실행 버튼을 누릅니다. 순서는 버프 목록과 같습니다(기본값은 자신).
- [플레이어 목록](플레이어-목록), [부활 목록](부활-목록), [엔티티 목록](엔티티-목록)의 행을 우클릭해서 '디버프 목록'을 골라도 열 수 있습니다. [엔티티 정보](엔티티-정보)의 디버프 칸을 눌러도 열립니다.
- 대상마다 창을 엽니다. 같은 대상의 창이 열려 있으면 그 창을 앞으로 가져옵니다.

## 보는 방법

- 제목: '디버프 목록 - 대상의 이름'입니다.
- 행을 보는 방법은 [버프 목록](버프-목록)과 같습니다. 적의 창은 기본적으로 플레이어가 붙인 디버프를 붙인 사람마다 1행으로 하고, 붙인 사람의 이름을 붙입니다(이미지는 2명의 플레이어가 보스에게 붙인 디버프).
- 순서: 우선 표시 목록에서 켜진 디버프가 맨 앞(목록 순)이고, 나머지는 붙은 순서(새것이 아래)입니다.

## 조작

- 행을 누르면 그 디버프의 [버프·디버프 카드](버프·디버프-카드)를 엽니다.
- 행을 우클릭하면 '디버프 카드', '이 디버프 우선 표시'(우선 표시 중에는 '이 디버프 우선 표시 해제'), '이 디버프 숨기기'를 고를 수 있습니다. 자신의 창에서는 '그룹에 추가', '버프·디버프 카드 바로가기에 추가'도 표시됩니다. 작동은 버프 목록과 같습니다.
- 행이 창에 다 들어가지 않을 때는 휠이나 오른쪽 스크롤 바로 움직입니다.

## 설정

창 설정과 테마는 [위젯 공통 설정](위젯-공통-설정)에 있습니다.

### 표시 설정

항목과 넣을 수 있는 문자는 [버프 목록](버프-목록)과 같습니다. 기본값은 버프 이름이 `{BuffName}({CasterName})`, 게이지 길이가 '30초', 같은 버프 표시가 '플레이어만 묶기', 부여자 플레이어 이름 표시가 '타인 부여만'입니다.

### 우선 표시 목록

맨 앞에 표시할 디버프입니다. 스위치로 켜고 끄며, 행을 드래그해 정렬합니다. 기본값은 다음 6행입니다.

| 행 | 기본값 |
|---|---|
| 시간 지연 | 끄기 |
| 기계 고장 | 끄기 |
| 정체된 원소 | 끄기 |
| 중상 | 켜기 |
| 치료 금지('오의! 지옥의 찌르기'의 것) | 켜기 |
| 치료 금지(역할 스킬 '지옥의 찌르기'의 것) | 켜기 |

행을 우클릭해 '이 디버프 우선 표시'로 추가할 수 있습니다. 추가한 행은 끄고 저장하면 사라집니다.

### 숨김 목록

표시하지 않을 디버프입니다. 행을 우클릭해 '이 디버프 숨기기'로 추가합니다. 스위치를 끄고 저장하면 목록에서 사라지고 다시 표시됩니다.

### 디버프 색상

게이지 왼쪽과 오른쪽의 색(왼쪽에서 오른쪽으로 바뀝니다)과 디버프 색상 불투명도입니다(기본값: 100%).

## 주의 사항

- 주의 사항은 [버프 목록](버프-목록)과 같습니다.
- 우선 표시와 숨기기는 디버프의 번호로 정해집니다. 이름이 같아도 번호가 다른 디버프(2개의 '치료 금지' 등)는 따로 다룹니다.
