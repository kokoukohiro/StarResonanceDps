![알림](images/ko/Notifications1.png)

게임 안에서 일어난 일을 Windows 알림이나 음성 읽기로 알리는 탭입니다. 항목마다 알릴지, 문장, 알리는 방법을 정합니다.

## 보는 방법

- 가운데: 알림 항목입니다. 왼쪽에 체크한 항목만 알립니다(기본값은 모두 꺼짐).
- 오른쪽 위: 선택한 항목의 문장과 '미리보기'(예시 이름을 넣은 문장)입니다.
- 오른쪽 아래: 선택한 항목의 설정과 알리는 방법입니다.

## 조작

- 항목을 누르면 그 항목의 문장과 설정이 오른쪽에 표시됩니다.
- 문장: 알릴 문장을 씁니다. 선택 목록에서 항목을 고르고 '삽입'을 누르면 커서 위치에 `{PlayerName}` 등의 문자가 들어가고, 알릴 때 이름 등으로 바뀝니다. 빈칸으로 두면 기본 문장으로 알립니다.
- 바꾼 내용은 그 자리에서 저장됩니다.

![HP 저하를 선택했을 때](images/ko/Notifications2.png)

### 항목

| 항목 | 알리는 때 | 기본 문장 |
|---|---|---|
| 입장 확인 | 매칭이 성립했을 때와, 파티 멤버가 콘텐츠 입장을 시작했을 때(게임의 입장 확인 화면이 열릴 때). | {Content}에 입장합니다 |
| HP 저하 | '대상 플레이어'의 HP가 'HP 저하 판정'의 비율 이하인 상태가 '알림 조건'의 초 수만큼 계속되었을 때. 그 사이에 HP가 회복되거나 쓰러지면 알리지 않습니다. | {PlayerName}의 HP가 낮아졌습니다 |
| 플레이어 출현 | 이름이나 UID가 대상에 해당하는 플레이어가 주위에 나타났을 때. | {PlayerName}이(가) 출현했습니다 |
| 엔티티 출현 | 이름이나 ID가 대상에 해당하는 적이 주위에 나타났을 때. | {EntityName}이(가) 출현했습니다 |
| 공격 대상 플레이어 | '대상 엔티티'의 적이 '대상 플레이어'를 노리는 상태가 '알림 조건'의 초 수만큼 계속되었을 때. | {PlayerName}이(가) {EntityName}의 공격 대상이 되었습니다 |
| 버프·디버프 효과 종료 | 실행 중인 [버프·디버프 카드](버프·디버프-카드)나 [버프·디버프 그룹](버프·디버프-그룹)에 표시된 버프·디버프가 시간이 다 되어 사라졌을 때. | {TargetName}의 {BuffName} 효과가 끝났습니다 |
| 포션·요리 효과 종료 | 포션·요리 버프의 남은 시간이 '알림 조건'의 시간 아래로 내려갔을 때. | {TargetName}의 {BuffName} 효과가 곧 끝납니다 |
| 예고 스킬 | 보스 스킬 중 게임에서 예고나 경고가 표시되는 스킬이 올 때. | {SkillName}이(가) 옵니다 |
| 엔티티 캐스팅 | HP 바가 있는 적이, 이름이나 ID가 대상에 해당하는 스킬의 캐스팅을 시작했을 때. | {EntityName}이(가) 캐스팅 중입니다 |
| 귓속말 | 다른 플레이어에게서 귓속말이 도착했을 때. 게임에서 그 상대와의 대화를 열고 있을 때는 알리지 않습니다. | {PlayerName}의 귓속말이 도착했습니다 |
| 월드 채팅 | 월드 채팅의 발언에 일치 단어가 모두 포함되어 있을 때. | {PlayerName}의 모집이 있습니다 |

### 항목별 설정

- HP 저하
  - 대상 플레이어: '모두', '파티 멤버만', '파티 멤버 외', '본인만'(기본값: '모두').
  - HP 저하 판정: 'HP 45%', 'HP 35%', 'HP 25%', 'HP 15%', 'HP 5%'(기본값: 'HP 15%').
  - 알림 조건: '무조건', 'HP 저하 상태 1초 이상', 'HP 저하 상태 2초 이상', 'HP 저하 상태 3초 이상'(기본값: 'HP 저하 상태 3초 이상').
- 플레이어 출현
  - 대상 플레이어 이름·대상 플레이어 UID: 알릴 플레이어입니다(기본값: 빈칸). '|'로 구분해 여러 개 입력할 수 있습니다. UID를 입력하면 이름보다 우선합니다.
- 엔티티 출현
  - 대상 엔티티 이름·대상 엔티티 ID: 알릴 적입니다(기본값: 빈칸). '|'로 구분해 여러 개 입력할 수 있습니다. ID를 입력하면 이름보다 우선합니다. ID는 설정의 '내부 ID'로 표시할 수 있고, ID와 이름은 [타임라인](타임라인)에서 복사할 수 있습니다.
- 공격 대상 플레이어
  - 대상 플레이어: '모두', '파티 멤버', '수호 클래스 외', '수호 클래스 외 파티 멤버'(기본값: '수호 클래스 외').
  - 대상 엔티티: '보스만', '보스와 정예', '모두'(기본값: '보스만').
  - 알림 조건: '무조건', '공격 대상 상태 1초 이상', '공격 대상 상태 2초 이상', '공격 대상 상태 3초 이상'(기본값: '공격 대상 상태 3초 이상').
- 버프·디버프 효과 종료
  - 알릴 버프·디버프는 카드와 그룹 설정의 '알림 대상'에서 고릅니다. 카드나 그룹의 행을 우클릭해서도 전환할 수 있습니다.
- 포션·요리 효과 종료
  - 알림 조건: '효과 1분 이하', '효과 2분 이하', '효과 5분 이하', '효과 10분 이하'(기본값: '효과 2분 이하').
- 예고 스킬
  - 알림 조건: '발동 시', '발동 1초 전', '발동 2초 전', '발동 3초 전'(기본값: '발동 시'). 예고가 있는 스킬은 예고가 끝나 스킬이 발동하는 시각을 기준으로 알립니다. 경고만 표시되는 스킬은 알림 조건과 관계없이 스킬이 시작되었을 때 알립니다.
- 엔티티 캐스팅
  - 대상 스킬 이름·대상 스킬 ID: 알릴 스킬입니다(기본값: 빈칸). '|'로 구분해 여러 개 입력할 수 있습니다. ID를 입력하면 이름보다 우선합니다.
- 월드 채팅
  - 일치 단어: 알릴 발언에 포함될 단어입니다(기본값: 빈칸). 공백으로 구분해 여러 개 입력하면 모두 포함한 발언만 알립니다.

### 알리는 방법(모든 항목 공통)

- 알림 방식: 'Windows 알림', '음성 읽기'(기본값: 'Windows 알림').
- 알림 음량: Windows 알림의 소리와 음성 읽기 목소리의 크기입니다(기본값: 100%). 0%로 하면 Windows 알림은 소리 없이 표시되고, 음성 읽기는 읽지 않습니다.
- 음성 읽기 방식: 'Windows 음성', 'VOICEVOX'(기본값: 'Windows 음성'). 알림 방식이 '음성 읽기'일 때 표시됩니다.
- 화자·스타일: VOICEVOX의 목소리를 고릅니다. 음성 읽기 방식이 'VOICEVOX'일 때 표시됩니다(스타일은 화자의 스타일이 2개 이상일 때만).

## 주의 사항

- '버프·디버프 효과 종료'와, 다른 플레이어의 '포션·요리 효과 종료'는 위젯을 실행하고 있을 때만 알립니다. 다른 항목은 위젯을 열지 않아도 알립니다.
- 플레이어 출현, 엔티티 출현, 엔티티 캐스팅, 월드 채팅은 이름, ID, 일치 단어를 입력하지 않으면 켜도 알리지 않습니다.
- 이름에는 설정의 '플레이어 이름'이 적용됩니다('숨기기'면 `*****`).
- 게임 중에는 Windows의 '방해 금지 자동 켜기' 때문에 Windows 알림이 도착하지 않을 수 있습니다. 도착하지 않을 때는 Windows 설정의 '알림'에서 게임을 플레이할 때와 전체 화면일 때의 항목을 끄세요.
- 음성 읽기는 도착한 순서대로 1건씩 읽으며 겹치지 않습니다.
- Windows 음성은 앱의 표시 언어의 목소리로 읽습니다. Windows에 그 언어의 음성이 설치되어 있지 않으면 읽을 수 없습니다.
- VOICEVOX는 앱에 포함되어 있지 않습니다. 사용할 때는 [VOICEVOX](https://voicevox.hiroshiba.jp/)를 설치하고 실행해 두세요([설정](설정)의 '시작 설정'에서 앱과 함께 실행할 수 있습니다). 일본어만 지원합니다.
- VOICEVOX의 목소리는 화자별 이용 약관에 따라 사용하세요. 화자 행의 '(화자 이름) 이용 약관'에서 확인할 수 있습니다.
