앱을 설치한 뒤 사용을 시작하기까지 해야 할 일과, 게임 통신을 제대로 읽고 있는지 확인하는 방법입니다. 설치 방법은 [설치와 업데이트](설치와-업데이트)에 있습니다.

## 처음 실행

처음 실행하면 메인 화면이 '[위젯](위젯)' 화면으로 열립니다. 위젯은 아직 하나도 열려 있지 않습니다.

실행할 때 다음 창이 표시될 수 있습니다.

| 창 | 표시될 때 | 할 일 |
|---|---|---|
| 'Npcap 설치' | Npcap이 설치되어 있지 않거나 버전을 감지할 수 없을 때 | '예'를 누르면 Npcap 페이지가 열립니다. 어느 쪽을 눌러도 앱은 종료되므로, Npcap을 설치한 뒤 앱을 다시 시작하세요. |
| 사용자 계정 컨트롤 | 단축키 보조 프로그램을 실행할 때 | '예'를 선택하면 [단축키](단축키)를 사용할 수 있습니다. '아니요'를 선택하면 '단축키 오류' 창이 표시되고, 이번 실행 중에는 단축키를 사용할 수 없습니다. |
| 'Npcap 업데이트' | Npcap 버전이 1.86보다 오래되었을 때(실행할 때마다 표시됩니다) | '예'를 누르면 Npcap 페이지가 열립니다. 어느 쪽을 눌러도 앱은 작동하지만, 1.86 이상으로 업데이트하세요. |
| '업데이트' | 앱의 새 버전이 있을 때 | '예'를 누르면 앱을 닫고 업데이트한 뒤 다시 시작합니다([설치와 업데이트](설치와-업데이트)). |

## Npcap

- 앱은 PC에 도착하는 게임 통신을 읽어서 표시합니다. 통신을 읽는 데 Npcap을 사용합니다.
- 버전 1.86 이상을 설치하세요. 그보다 오래된 버전에는 통신을 읽는 동안 PC가 멈추는 버그가 있습니다.
- 게임을 실행한 채로 Npcap을 설치했을 때는 게임을 다시 시작하지 않으면 읽지 못할 수 있습니다.

## 읽어 들일 통신 설정

[설정](설정)의 '기본 설정'에서 선택합니다. 보통은 기본값인 '자동' 그대로 읽을 수 있습니다.

- 네트워크 어댑터: '자동'은 Windows가 인터넷 연결에 사용하고 있는 어댑터를 선택합니다. 유선과 무선이 모두 있을 때 등에 수치가 표시되지 않으면 게임 통신이 지나가는 어댑터를 선택하세요. 목록의 이름은 어댑터의 제품명입니다.
- 게임 실행 파일: '자동'은 목록에 있는 어느 배포처의 게임이든 읽습니다. 목록에 없는 이름의 실행 파일로 작동하는 게임은 '사용자 지정'을 선택하고 '사용자 지정 실행 파일 이름'에 실행 파일 이름을 입력합니다. `.exe`는 붙여도 되고 붙이지 않아도 됩니다. 대문자와 소문자를 구분합니다.
- 설정을 바꾸면 그 자리에서 다시 읽기 시작합니다. 다시 읽기 시작한 뒤에는 맵을 한 번 이동하세요.
- '자동'일 때의 어댑터는 앱을 실행할 때 정해집니다. 앱을 실행한 뒤 유선과 무선을 전환했을 때는 앱을 다시 시작하세요.

## 실행 순서

- 앱을 먼저 실행한 뒤 게임에 로그인하세요. 로그인과 맵 이동 시에 전달되는 정보를 처음부터 받을 수 있습니다.
- 게임에 로그인한 뒤에 앱을 실행했을 때는 맵을 한 번 이동하세요. 그때까지는 자신의 버프나 장비 등의 정보가 부족하여 위젯 창 제목의 원이 빨간색이 됩니다([위젯 공통 설정](위젯-공통-설정)).
- 이전 채팅 중에는 다시 로그인할 때까지 받을 수 없는 것이 있습니다([채팅](채팅)).

## 제대로 읽고 있는지 확인하는 방법

- 게임에 로그인한 뒤에(로그인한 뒤에 앱을 실행했을 때는 맵을 이동한 뒤에) [플레이어 목록](플레이어-목록)에 자신의 행이 표시되고, 푸터 왼쪽에 현재 있는 맵의 이름이 표시되면 제대로 읽고 있는 것입니다.
- 전투하면 [DPS 미터](DPS-미터)에 수치가 표시됩니다. 기본적으로 아스텔리즈, 가든 정원, 가든 주택에서는 집계하지 않습니다.
- 위젯 창 제목의 원은 부족한 정보가 발견되었을 때만 노란색·빨간색이 됩니다. 아무것도 읽지 못하고 있을 때도 초록색 그대로이므로 확인하는 데는 사용할 수 없습니다.
- 읽지 못할 때는 [문제 해결](문제-해결)의 '아무것도 표시되지 않음'을 보세요.

## 사용을 시작할 때 알아 둘 점

- 위젯은 '[위젯](위젯)'의 카드에서 실행합니다. 자주 사용하는 위젯을 즐겨찾기로 지정하면 한꺼번에 실행할 수 있습니다.
- 게임 조작을 방해하지 않도록 위젯을 고정하거나 마우스 통과로 설정할 수 있습니다([위젯 공통 설정](위젯-공통-설정)).
- [단축키](단축키)로 위젯 실행이나 고정, 측정 등을 키로 할 수 있습니다.
- 화면을 다른 사람에게 보여 줄 때는 설정의 '플레이어 이름' 또는 Ctrl+F11로 플레이어 이름을 숨길 수 있습니다.
- 메인 화면을 닫으면 위젯도 모두 닫히고 앱이 종료됩니다. 위젯만 띄워 두려면 메인 화면을 최소화하세요.

## 주의 사항

- 앱을 관리자 권한으로 실행할 필요는 없습니다. 관리자 권한이 필요한 단축키 보조 프로그램만 사용자 계정 컨트롤을 거쳐 실행합니다.
- 앱은 하나만 실행됩니다. 이미 실행 중일 때 실행하면 실행 중인 앱의 메인 화면이 앞으로 나옵니다.
