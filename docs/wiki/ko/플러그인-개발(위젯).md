'[위젯](위젯)'에 카드를 추가하고, 위젯 창의 내용을 플러그인으로 만들기 위한 설명입니다. 모든 플러그인에 필요한 것은 [플러그인 개발](플러그인-개발)에 있습니다.

## 2가지 형태

| 형태 | 진입점 클래스가 구현하는 인터페이스 | 창 |
|---|---|---|
| 창이 1개인 위젯 | `IPluginWidgetProvider` | 하나의 위젯에 1개 |
| 대상별로 창을 여는 위젯 | `IPluginMultiWidgetProvider` | 대상마다 1개. 카드의 선택 목록에서 대상을 고릅니다 |

- 하나의 플러그인에서 둘 다 구현할 수 있습니다. 위젯의 `Id`는 둘을 통틀어 겹치지 않게 합니다. 카드는 창이 1개인 형태, 대상별 형태의 순으로, 정의의 순서대로 나열됩니다.
- `IPluginWindowProvider`의 창이 없는 플러그인이라면 `PluginGenre`는 필요하지 않습니다.

| 앱이 갖는 것 | 플러그인이 넘겨주는 것 |
|---|---|
| 카드(즐겨찾기, 고정, 마우스 통과, 설정, 시작), 창의 틀과 헤더(상태 원, 제목, 닫기), 설정 창의 '창 설정'과 '테마', 위치와 크기의 저장 | 위젯의 정의(이름, 기본 크기, 푸터의 유무, 설정의 절)와 창의 내용(본체, 푸터, 헤더의 버튼) |

## 창이 1개인 위젯

```csharp
using System.Windows;
using System.Windows.Controls;
using StarResonanceDps.PluginSdk;

[assembly: PluginRegistration(typeof(MyPlugin.Plugin), PluginSdkVersion.Current)]
[assembly: PluginDisplayName("ja-JP", "私のプラグイン")]
[assembly: PluginAuthor("YourName")]
[assembly: PluginVersion("1.0.0")]

namespace MyPlugin;

public sealed class Plugin : IStarResonancePlugin, IPluginWidgetProvider
{
    public void Initialize(IPluginContext context)
    {
    }

    public IReadOnlyList<PluginWidgetDefinition> GetWidgetDefinitions()
    {
        return
        [
            new PluginWidgetDefinition
            {
                Id = "hello",
                Names = new Dictionary<string, string> { ["ja-JP"] = "あいさつ", ["en-US"] = "Hello" },
                DefaultWidth = 240,
                DefaultHeight = 80,
            },
        ];
    }

    public PluginWidgetContent CreateWidget(string widgetId, IPluginWidgetContext context)
    {
        var text = new TextBlock { Text = "Hello", Margin = new Thickness(8) };
        text.SetResourceReference(FrameworkElement.StyleProperty, PluginResourceKeys.Text.WidgetWindow);
        return new PluginWidgetContent { Body = text };
    }

    public void Shutdown()
    {
    }
}
```

| 멤버 | 호출되는 시점 | 하는 일 |
|---|---|---|
| `GetWidgetDefinitions` | `Initialize` 직후에 1번 | 추가할 위젯의 정의 목록을 반환합니다. 반환한 순서대로 카드가 나열됩니다. 나중에 바꿔도 반영되지 않습니다 |
| `CreateWidget` | 창을 열 때마다(UI 스레드) | 창의 내용을 반환합니다. `widgetId`는 정의의 `Id`입니다 |

### 정의(`PluginWidgetDefinition`)

| 속성 | 필수 여부 | 내용 |
|---|---|---|
| `Id` | 필수 | 위젯의 ID. 1~128자의 영숫자와 '.', '-', '_'입니다. 저장의 키이므로 버전을 넘어 바꾸지 않습니다 |
| `Names` | 필수 | 카드, 창의 제목, 설정 창의 제목에 표시되는 이름 |
| `DefaultWidth`, `DefaultHeight` | 필수 | 처음 열 때의 창 크기. 최소는 240×60이며, 높이에는 헤더(30)와 푸터(30)가 포함됩니다 |
| `HasFooter` | 선택(기본값은 없음) | 푸터 행을 만들지 여부 |
| `ScrollsVertically` | 선택(기본값은 없음) | 본체를 세로 스크롤 바로 움직일지 여부 |
| `SettingSections` | 선택 | 설정 창에 추가하는 절(아래 '설정') |

- 언어별 문자는 `Names`처럼 언어 이름(`ja-JP` 등)을 키로 한 사전으로 씁니다. 고르는 방식은 속성과 같습니다([플러그인 개발](플러그인-개발)의 '진입점 클래스와 속성').
- 카드에는 위젯의 이름만 표시됩니다. 플러그인의 이름과 아이콘은 표시되지 않습니다.
- 한 번 저장한 창 크기가 있으면 `DefaultWidth`, `DefaultHeight`는 사용되지 않습니다.

### 내용(`PluginWidgetContent`)

| 속성 | 필수 여부 | 내용 |
|---|---|---|
| `Body` | 필수 | 창의 본체 |
| `Footer` | `HasFooter`일 때는 필수, 그렇지 않으면 `null` | 푸터. 높이 30이며, 창의 전체 폭을 사용합니다 |
| `HeaderButtons` | 선택 | 헤더의 문자 버튼(`PluginWidgetHeaderButton`). 제목의 오른쪽, 닫기 버튼의 왼쪽에 나열됩니다 |

- `ScrollsVertically`가 `false`일 때 본체는 헤더와 푸터 사이를 모두 사용합니다. `true`일 때는 본체가 창의 폭에 맞춰 넓어지고, 높이는 본체가 원하는 높이가 되며, 다 들어가지 않으면 세로 스크롤 바가 표시됩니다.
- 본체와 푸터의 `DataContext`는 `null`입니다. 바인딩을 사용할 때는 직접 넣습니다.
- 창은 글자 색을 정하지 않습니다. 위젯의 흰 글자와 그림자는 `Text.WidgetWindow` 스타일을 붙여서 표시합니다.
- 설정의 '창 불투명도'는 창의 바탕과 틀에 적용되며, 본체와 푸터는 옅어지지 않습니다.
- 헤더 버튼은 `Text`를 바꾸면 글자가 바뀌고, 누르면 `Click`이 UI 스레드에서 옵니다. 내용을 만들었을 때의 목록 그대로이며, 늘지도 줄지도 않습니다. 설정의 '고정 중 헤더 숨기기'로 헤더가 숨겨져 있는 동안에는 버튼도 숨겨집니다.
- 본체와 푸터가 `IDisposable`이면 창을 닫은 뒤에 `Dispose`가 호출됩니다. 이벤트 구독이나 타이머는 거기서 해제합니다.

### 내용을 만들 때 받는 것(`IPluginWidgetContext`)

| 멤버 | 내용 |
|---|---|
| `WidgetId` | 정의의 `Id` |
| `Settings` | 이 위젯의 설정의 현재 값(아래 '설정') |
| `SettingsChanged` | 설정이 바뀌었을 때 UI 스레드에서 오는 이벤트 |

- 창 1개마다 만들어집니다. 창을 닫으면 `SettingsChanged`는 오지 않게 됩니다.
- 창을 연 것만으로는 이벤트가 오지 않으므로, 처음 값은 `CreateWidget` 안에서 `Settings`로부터 읽습니다.

## 설정

정의의 `SettingSections`에 절을 쓰면, 위젯 설정 창의 '창 설정'과 '테마' 사이에 표시됩니다.

```csharp
SettingSections =
[
    new PluginWidgetSettingSection
    {
        Names = new Dictionary<string, string> { ["ja-JP"] = "表示", ["en-US"] = "Display" },
        Icon = PluginResourceKeys.Icons.Settings,
        IconStyle = PluginResourceKeys.Icons.FillStyle,
        Settings =
        [
            new PluginSwitchSetting
            {
                Id = "showTime",
                Names = new Dictionary<string, string> { ["ja-JP"] = "時刻を表示", ["en-US"] = "Show time" },
                DefaultValue = true,
            },
        ],
    },
],
```

```csharp
bool showTime = context.Settings.GetSwitch("showTime");
```

| 절(`PluginWidgetSettingSection`)의 속성 | 내용 |
|---|---|
| `Names` | 절의 이름 |
| `Icon` | 왼쪽 목록의 아이콘. `PluginResourceKeys.Icons`의 모양 키(`Icon.Settings` 등) |
| `IconStyle` | 아이콘을 그리는 방법. `Icon.Stroke`(선)나 `Icon.Fill`(채우기) |
| `Settings` | 행의 목록(1개 이상) |

행의 종류(모두 `Id`와 `Names`가 필수이며, `Notes`에 주의 문구를 붙일 수 있습니다):

| 형식 | 화면 | 읽는 방법 |
|---|---|---|
| `PluginSwitchSetting` | 스위치 | `GetSwitch(id)` → `bool` |
| `PluginChoiceSetting` | 선택 목록. `Options`의 `PluginChoiceOption`에서 고르며, 기본값은 `DefaultOptionId` | `GetChoice(id)` → 고른 선택지의 `Id` |
| `PluginNumberSetting` | 숫자 칸. `Minimum`~`Maximum`의 0 이상의 정수 | `GetNumber(id)` → `long` |
| `PluginTextSetting` | 1줄의 문자 칸 | `GetText(id)` → `string` |
| `PluginSliderSetting` | 슬라이더. `Minimum`~`Maximum`을 `Step` 단위로 | `GetSlider(id)` → `double` |
| `PluginColorSetting` | 색의 원과 '색상 선택'. `DefaultColors`에 `#RRGGBB`를 1~5개 | `GetColor(id)` → `Color` |

- 값이 바뀌는 시점: 스위치와 색은 눌렀을 때, 선택 목록은 골랐을 때, 숫자는 확정했을 때(Enter나 칸을 벗어났을 때), 문자는 1글자마다, 슬라이더는 움직이는 동안.
- 설정 창을 열고 있는 동안에는 바꾼 값이 바로 `Settings`에 들어가고 `SettingsChanged`가 옵니다(저장 전의 미리보기). '초기화'와 '저장'을 눌렀을 때와, 저장하지 않고 닫아서 원래 값으로 돌렸을 때도 옵니다. 값이 같아도 옵니다.
- 값은 앱이 `Data\WidgetSettings.json`에 저장합니다(플러그인 폴더의 설정 파일과는 별개). 플러그인을 삭제하면 사라지고, 업데이트하면 남습니다.
- 저장한 값을 읽을 수 없을 때와, 선택지가 없어졌을 때는 기본값으로, 범위 밖의 값은 가까운 쪽의 끝 값이 됩니다.
- 행의 `Id`는 저장의 키이므로 버전을 넘어 바꾸지 않습니다. 절을 넘어, 위젯 안에서 겹치지 않게 합니다.
- 정의에 없는 `id`를 읽으면 `KeyNotFoundException`, 종류가 다른 메서드로 읽으면 `InvalidOperationException`입니다.
- 같은 위젯의 창이 몇 개 있어도 설정은 한 세트입니다.

## 대상별로 창을 여는 위젯

```csharp
public sealed class Plugin : IStarResonancePlugin, IPluginMultiWidgetProvider
{
    public void Initialize(IPluginContext context)
    {
    }

    public IReadOnlyList<PluginWidgetDefinition> GetMultiWidgetDefinitions()
    {
        return
        [
            new PluginWidgetDefinition
            {
                Id = "slot",
                Names = new Dictionary<string, string> { ["ja-JP"] = "枠", ["en-US"] = "Slot" },
                DefaultWidth = 240,
                DefaultHeight = 80,
            },
        ];
    }

    public IReadOnlyList<PluginWidgetTarget> GetWidgetTargets(string widgetId)
    {
        return
        [
            new PluginWidgetTarget { Id = "a", Names = new Dictionary<string, string> { ["ja-JP"] = "A" }, IsDefault = true },
            new PluginWidgetTarget { Id = "b", Names = new Dictionary<string, string> { ["ja-JP"] = "B" } },
        ];
    }

    public PluginWidgetContent CreateWidget(string widgetId, string targetId, IPluginWidgetContext context)
    {
        var text = new TextBlock { Text = targetId, Margin = new Thickness(8) };
        text.SetResourceReference(FrameworkElement.StyleProperty, PluginResourceKeys.Text.WidgetWindow);
        return new PluginWidgetContent { Body = text };
    }

    public void Shutdown()
    {
    }
}
```

| 멤버 | 호출되는 시점 | 하는 일 |
|---|---|---|
| `GetMultiWidgetDefinitions` | `Initialize` 직후에 1번 | 정의의 목록을 반환합니다 |
| `GetWidgetTargets` | 카드의 선택 목록을 열었을 때와, 기본 대상을 다시 고르는 동안(UI 스레드) | 대상의 목록을 반환합니다 |
| `CreateWidget` | 대상의 창을 열 때마다(UI 스레드) | 그 대상의 창의 내용을 반환합니다 |

- 대상(`PluginWidgetTarget`)은 `Id`(1~128자의 영숫자와 '.', '-', '_', 목록 안에서 겹치지 않음), `Names`, `IsDefault`를 갖습니다.
- 직접 고를 때까지는 `IsDefault`인 대상, 없으면 목록의 첫 번째가 선택됩니다. 나중에 `IsDefault`인 대상이 나타나면 그쪽으로 바뀝니다.
- 선택 목록에서 골라도 창은 열리지 않습니다. 시작 버튼으로 고른 대상의 창을 열고 닫습니다. 같은 대상의 창은 1개입니다.
- 목록이 비어 있을 때는 시작 버튼으로 앱이 빈 창을 띄웁니다(플러그인은 호출되지 않습니다). 나중에 목록에 대상이 나타나면 그 창에 내용이 들어갑니다.
- 대상이 목록에서 사라져도 창은 닫히지 않습니다.
- 실행 중인 채로 앱을 닫으면, 다음 실행 때 같은 대상의 창을 다시 엽니다. 대상이 목록에 없어도, 저장한 ID로 `CreateWidget`이 호출됩니다.
- 창마다 갖는 것은 대상, 위치와 크기, 내용입니다. 설정, 테마, 즐겨찾기, 고정, 마우스 통과는 그 위젯의 모든 창에서 공유합니다.
- `GetWidgetTargets`는 1초에 1번보다 많이 호출될 수 있으므로, 무거운 처리를 하지 마세요.
- 항상 빈 목록을 반환하면 빌드가 멈춥니다(SRDPS013). 내용을 반환하는 `return`이 따로 있으면, 일시적으로 빈 목록을 반환하는 `return`은 괜찮습니다.

## 앱의 모양 키

- `Text.WidgetWindow`(흰 글자와 그림자), `Text.WidgetWindowSubtitle`(같은 글자에 크기 13)은 위젯의 어두운 바탕을 위한 글자입니다. 위젯의 색을 바꿔도 흰색 그대로입니다.
- `Brush.*`와 그것을 사용하는 스타일(`Button.Text` 등)은 위젯의 색이 아니라 앱 전체의 테마 색으로 그려집니다.
- `ScrollViewer.WidgetWindow`는 스크롤 바의 색이 위젯의 색과 불투명도를 따라갑니다. 위젯 창 안에서만 효과가 있습니다.
- `ToolTip.WidgetWindowInfo`는 툴팁의 바탕과 테두리가 위젯의 색이 됩니다. 툴팁을 붙이는 요소의 `Tag`에 위젯 창(`Window`)의 `DataContext`가 들어 있지 않으면 색이 적용되지 않습니다.
- 키 목록은 [플러그인 개발(창)](플러그인-개발(창))의 '앱의 모양 키'에 있습니다.

## 오류와 예외

- 정의의 오류(ID의 형태, 중복, 크기, 아이콘, 설정 값의 범위 등)에서는 플러그인이 멈추고, '[플러그인](플러그인)'의 행이 '오류'가 됩니다. '플러그인 오류' 창에는 '초기화하지 못했습니다.'가 표시되고, 이유는 영어로 로그에 남습니다.
- 내용의 오류(`Body`가 `null`, `HasFooter`와 `Footer`가 맞지 않음)와 `CreateWidget`의 예외에서는 플러그인이 멈추고, 그 창은 열리지 않으며, 다음 실행 때도 열리지 않습니다.
- `SettingsChanged`, 헤더 버튼의 `Click`, `Dispose`, `GetWidgetTargets`의 예외에서도 플러그인이 멈춥니다.
- 플러그인이 멈추면 열려 있던 창은 닫힙니다. 창의 상태는 남으므로, 다음 실행 때 다시 엽니다.
- 이름 등 필수 문자가 비어 있으면 빌드가 멈춥니다(SRDPS014).
