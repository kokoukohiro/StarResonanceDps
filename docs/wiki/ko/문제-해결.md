문제가 생겼을 때의 증상별 원인과 해결 방법입니다. 해결되지 않을 때는 '[피드백](피드백)'에서 제보하세요.

## 실행할 수 없음

### 영어 창이 표시되고 실행되지 않음

'You must install .NET to run this application.' 등의 영어 창은 .NET 10 데스크톱 런타임이 설치되어 있지 않을 때 표시됩니다. [설치와 업데이트](설치와-업데이트)의 '필요 사항'에서 설치하세요.

### 'Npcap 설치'가 표시되고 종료됨

Npcap이 설치되어 있지 않거나 버전을 감지할 수 없을 때 표시됩니다. 어느 쪽을 눌러도 앱은 종료됩니다. '예'를 누르면 열리는 Npcap 페이지에서 Npcap을 설치하고 앱을 다시 시작하세요([초기 설정](초기-설정)).

### '시작 오류'가 표시되고 종료됨

- '앱을 시작하지 못했습니다.': 앱 폴더의 `Data`에 쓸 수 없습니다. 창에 표시된 폴더의 쓰기 권한과 보안 소프트웨어 설정을 확인하거나, 앱 폴더 전체를 쓸 수 있는 위치로 옮기세요.
- '초기화에 실패했습니다.': 앱의 데이터 파일이 누락되었거나 손상되었을 수 있습니다. Releases에서 zip을 받아 앱 폴더에 덮어쓰세요. 설정과 전투 기록은 유지됩니다.

### '오류'가 표시되고 종료됨

예기치 않은 오류가 발생했습니다. 다시 실행하세요. 여러 번 표시될 때는 '[피드백](피드백)'에서 제보하세요.

### 실행해도 새 창이 표시되지 않음

앱은 하나만 실행됩니다. 이미 실행 중일 때는 새로 실행되지 않고, 실행 중인 앱의 메인 화면이 앞으로 나옵니다.

## 실행할 때 창이 표시됨

### 사용자 계정 컨트롤이 표시됨

단축키 보조 프로그램을 실행할 때 표시됩니다. '예'를 선택하면 단축키를 사용할 수 있습니다. 단축키를 사용하지 않을 때는 설정의 '시작 설정'에서 '앱 시작 시 단축키 보조 프로그램 실행'을 끄면 표시되지 않습니다.

### '단축키 오류'가 표시됨

- '단축키가 비활성화되었습니다.': 보조 프로그램을 실행하지 못했거나 도중에 멈췄습니다. 앱을 다시 시작하고 사용자 계정 컨트롤에서 '예'를 선택하세요.
- '다음 단축키를 설정할 수 없습니다.': 창에 표시된 키를 다른 앱이 사용하고 있습니다. 설정의 '단축키'에서 다른 키를 할당하세요.

### 'Npcap 업데이트'가 표시됨

Npcap 버전이 1.86보다 오래된 경우, 앱을 실행할 때마다 표시됩니다. 오래된 버전에는 PC가 멈추는 버그가 있습니다. 앱은 그대로 사용할 수 있지만, 1.86 이상으로 업데이트하세요.

### '설정 불러오기 오류'가 표시됨

설정 파일이 손상되었거나 읽을 수 없어 기본값으로 실행되고 있습니다. 창에 표시된 파일은 다음에 설정을 저장할 때 덮어쓰게 됩니다. 필요에 따라 설정을 다시 하세요.

### '시작 설정 오류'가 표시됨

설정의 '시작 설정'에서 'Windows 시작 시 앱 실행'이 켜져 있는데 Windows 시작 프로그램에 등록하지 못했을 때 표시됩니다. 보안 소프트웨어가 시작 프로그램 등록을 막고 있지 않은지 확인하세요.

### '플러그인 오류'가 표시됨

불러오지 못한 플러그인이 있습니다. 창의 상세 내용에 플러그인별 이유와 해결 방법이 표시됩니다([플러그인](플러그인)).

## 아무것도 표시되지 않음

### 어떤 위젯에도 아무것도 표시되지 않음

게임 통신을 읽지 못하고 있습니다.

- 설정의 '게임 실행 파일'을 '자동'으로 설정하세요.
- '네트워크 어댑터'에서 게임 통신이 지나가는 어댑터를 선택하세요. 앱을 실행한 뒤 유선과 무선을 전환했을 때는 앱을 다시 시작하세요.
- 제대로 읽고 있는지 확인하는 방법은 [초기 설정](초기-설정)에 있습니다.

### 수치가 표시되지 않음, 자신만 표시됨

- 아스텔리즈, 가든 정원, 가든 주택에서는 기본적으로 집계하지 않습니다([설정](설정)의 '집계 설정').
- 미터의 푸터에 '[측정 중]'이 표시되어 있을 때는 측정 중입니다. 측정하는 동안에는 자신의 몫만 집계합니다. '측정 중지'를 누르면 돌아옵니다([집계](집계)).
- 미터의 표시 설정에 있는 '필터 설정'에서 표시할 사람을 좁히고 있지 않은지 확인하세요.

### 값이 바뀌지 않음

- '[집계](집계)'의 왼쪽 위가 '기록 표시 중'일 때는 기록을 열고 있는 것입니다. 열려 있는 기록의 행을 한 번 더 누르면 현재 전투로 돌아갑니다.
- 미터의 푸터에 '[측정 완료]'가 표시되어 있을 때는 측정 시간이 끝난 상태입니다. '측정 중지'를 누르면 돌아옵니다.

## 정보가 부족함

### 상태 원이 노란색·빨간색이 됨

원이나 제목에 마우스를 올리면 이유가 표시됩니다([위젯 공통 설정](위젯-공통-설정)). 게임에 로그인한 뒤에 앱을 실행했을 때는 맵을 한 번 이동하세요.

### 이름이 'UID:번호'로 표시됨

이름이 아직 전달되지 않은 사람입니다. 그 사람에게 다시 다가가거나 게임에서 그 사람을 클릭하면 이름이 표시됩니다.

### 이름이 직업 이름으로 표시됨

도우미 NPC는 이름 대신 직업 이름으로 표시됩니다.

### 클래스가 '알 수 없음', '1단계'로 표시됨

'알 수 없음'은 아직 알 수 없는 상태입니다. 그 사람이 주변에 오면 알 수 있습니다. '1단계'는 어빌리티를 설정하지 않은 상태입니다.

### 가든 정원에서 자신이 '1단계', '미적용'으로 표시됨

가든 정원에서는 게임이 요리와 포션 이외의 버프를 부여하지 않으므로, 자신의 클래스와 깊은 잠 심상의를 알 수 없습니다. 다른 장소로 나가면 돌아옵니다.

## 창이 보이지 않음, 클릭할 수 없음

### 위젯의 헤더가 없음, 움직일 수 없음

고정되어 있습니다. 기본적으로 고정되어 있는 동안에는 헤더가 숨겨집니다. '[위젯](위젯)'의 카드에서 고정을 해제하면 헤더가 표시되고 움직일 수 있습니다.

### 위젯을 클릭할 수 없음

마우스 통과로 설정되어 있습니다. '[위젯](위젯)'의 카드에서 해제하세요.

### 위젯이 게임 뒤에 가려짐

설정의 '위젯 창'이 '고정 시에만 위에 표시'일 때는 고정하지 않은 창이 게임 뒤에 가려집니다. '항상 위에 표시'로 되돌리거나 창을 고정하세요.

### 위젯이 화면 밖으로 나감

'[위젯](위젯)'의 카드에서 중지한 뒤 다시 실행하면 화면 안에 표시됩니다.

### 위젯 표시가 갑자기 바뀜

단축키를 누르지 않았는지 확인하세요. 기본 키로 일어나는 일과 되돌리는 방법입니다([단축키](단축키)).

| 일어난 일 | 키 | 되돌리는 방법 |
|---|---|---|
| 실행 중인 위젯이 모두 닫힘 | Ctrl+F8 | '위젯'의 카드에서 실행 |
| 창을 움직일 수 없음, 헤더가 사라짐 | Ctrl+F7 | 한 번 더 누름 |
| 창을 클릭할 수 없음 | Ctrl+F6 | 한 번 더 누름 |
| 창이 게임 뒤에 가려짐 | Ctrl+F5 | 한 번 더 누름 |
| 이름이 `*****`로 바뀜 | Ctrl+F11 | 한 번 더 누름 |
| 미터가 비고 푸터에 '[측정 중]'이 표시됨 | Ctrl+F10 | 한 번 더 누름 |
| 미터가 비었음 | Ctrl+F9 | 이전 집계는 '[집계](집계)'의 기록에서 열 수 있습니다. |

### 메인 화면을 닫았더니 위젯도 닫힘

메인 화면을 닫으면 앱이 종료됩니다. 위젯만 띄워 두려면 메인 화면을 최소화하세요.

## 이름이나 값이 다름

### 스킬 이름이 중국어로 표시됨

게임에 표시 이름이 없는 스킬은 내부 이름(중국어)으로 표시됩니다. 설정의 '이름 없는 스킬과 버프'에서 빈칸으로 둘 수도 있습니다.

### 게임 내 미터와 값이 다름

- 초당 값은 합계를 전투 경과 시간으로 나눈 값입니다. 경과 시간을 세는 방식이 게임과 다르므로 초당 값이 조금 다를 수 있습니다.
- 회복은 실제로 늘어난 HP를 셉니다. 회복약, 요리, 자연 회복도 셉니다([HPS 미터](HPS-미터)).

## 단축키가 작동하지 않음

- 단축키는 게임이나 이 앱이 맨 앞에 있을 때만 작동합니다.
- 사용자 계정 컨트롤에서 '아니요'를 선택한 경우, 이번 실행 중에는 사용할 수 없습니다. 앱을 다시 시작하고 '예'를 선택하세요.
- 설정의 '시작 설정'에서 '앱 시작 시 단축키 보조 프로그램 실행'을 끈 경우에는 사용할 수 없습니다.
- 다른 앱이 사용 중인 키는 할당할 수 없습니다. 다른 키를 할당하세요.
- 게임이 맨 앞에 있는데도 작동하지 않을 때는 설정의 '게임 실행 파일'을 '자동'으로 설정하세요. 게임이 맨 앞에 있는지를 이 설정으로 판별합니다.
- 자세한 내용은 [단축키](단축키)에 있습니다.

## 알림이 도착하지 않음, 음성으로 읽지 않음

- 알림 항목 중에는 위젯을 실행하고 있을 때만 알리는 것이 있습니다([알림](알림)의 '주의 사항').
- Windows 알림이 게임 중에 도착하지 않을 때는 Windows 설정의 '알림'에서 '방해 금지 자동 켜기' 중 게임을 플레이할 때와 전체 화면일 때의 항목을 끄세요.
- 음성 읽기 방식이 VOICEVOX일 때는 VOICEVOX를 미리 실행해 두세요. 실행되고 있지 않으면 앱을 실행할 때 등에 'VOICEVOX 연결 오류' 창이 표시됩니다. 게임 중에 음성으로 읽지 못했을 때는 창이 표시되지 않고 '[로그](로그)'에 경고 행이 남습니다.
- 'VOICEVOX 실행 오류'가 표시되었을 때는 설정의 '시작 설정'에서 '설치 경로'를 확인하세요.
- 'Windows 음성' 창이 표시되었을 때는 Windows 설정에서 창에 표시된 언어의 음성을 추가하세요.

## 업데이트할 수 없음

- '업데이트 오류' 창의 세부 정보에 해결 방법이 표시됩니다.
- 업데이트가 '사용 중인 파일이 해제되기를 기다리는 중입니다…'에서 멈출 때는 앱 폴더를 열고 있는 파일 탐색기 등을 닫으세요.
- 업데이트가 제대로 되지 않을 때는 Releases에서 zip을 받아 앱 폴더에 덮어쓰세요([설치와 업데이트](설치와-업데이트)).

## 플러그인이 작동하지 않음

'[플러그인](플러그인)'의 행이 '오류'일 때는 '플러그인 오류' 창에 이유가 표시됩니다. 불러오지 못한 플러그인이 있으면 앱을 실행할 때마다 이 창이 표시됩니다.

## 기록을 열 수 없음

'기록 불러오기 오류'는 그 기록의 데이터를 찾을 수 없거나 손상되었을 때 표시됩니다([집계](집계)).

## 버그 제보하기

- '[피드백](피드백)'의 '버그 제보 · 기능 요청'에서 앱 버전 등이 입력된 작성 화면이 열립니다.
- 앱이 실행되지 않을 때는 [GitHub 작성 화면](https://github.com/kokoukohiro/StarResonanceDps/issues/new?template=feedback.yml)에서 제보하세요. 환경 란에 Windows와 앱의 버전을 적으세요.
- 로그를 요청받았을 때는 앱 폴더의 `Data\CombatRuntime.log`를 첨부하세요([로그](로그)).
