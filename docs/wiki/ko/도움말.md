앱의 버전을 확인하고 사용 방법 등의 페이지를 여는 탭입니다.

## 보는 방법

- 위쪽 칸: 앱의 이름, 버전, 소개입니다. 버전 뒤의 괄호에 업데이트 확인 결과가 표시됩니다.
- '링크' 칸: 누르면 다음 페이지를 엽니다.

| 칸 | 여는 페이지 |
|---|---|
| 사용 방법 | 이 Wiki의 [Home](내-DPS-조회하지-마-Wiki) |
| 플러그인 만들기 | 이 Wiki의 [플러그인 개발](플러그인-개발) |
| GitHub | GitHub 리포지토리의 홈페이지(README) |
| 릴리스 노트 | GitHub의 릴리스 노트(버전별 변경 사항) |

- 사용 방법과 플러그인 만들기는 앱 언어의 페이지를 엽니다. 표는 한국어일 때 여는 곳이며, 다른 언어에서는 Wiki의 그 언어 페이지를 엽니다. GitHub의 README는 일본어이며, 맨 위의 링크에서 다른 언어의 README를 열 수 있습니다.
- 맨 아래: 저작권과 라이선스입니다. '라이선스 정보'를 누르면 GitHub의 라이선스 설명 페이지를 엽니다.

## 조작

- '업데이트 확인'을 누르면 새 버전이 있는지 확인합니다. 있으면 확인 창이 표시됩니다([설치와 업데이트](설치와-업데이트)).
- 확인 중에는 버튼이 '취소'로 바뀌며, 누르면 확인을 그만둡니다.
- 칸을 누르면 브라우저에서 그 페이지를 엽니다.

## 주의 사항

- 업데이트 확인과 페이지를 열려면 인터넷 연결이 필요합니다.
- 라이선스 본문과 사용하는 라이브러리의 라이선스는 앱 폴더의 `LICENSE`, `LICENSING.md`, `THIRD-PARTY-NOTICES.txt`에도 있습니다.
