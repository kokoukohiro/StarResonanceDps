앱 전체의 설정입니다. 메인 화면 왼쪽 아래의 '설정'으로 엽니다.

- 왼쪽 목록을 누르면 그 섹션으로 이동합니다.
- 바꾼 항목은 그 자리에서 화면에 반영됩니다(시작 설정과 집계 설정은 저장한 뒤부터 적용됩니다).
- '저장'으로 확정하고 창을 닫습니다. 저장하지 않고 닫으면 확인 창이 표시되며, '예'를 누르면 원래대로 돌아갑니다.
- '초기화'를 누르고 확인 창에서 '예'를 누르면 이 창의 모든 항목이 초기값이 됩니다. 확정되는 것은 '저장'을 눌렀을 때입니다.

## 기본 설정

- 네트워크 어댑터: 게임 통신을 읽을 네트워크 어댑터를 고릅니다. '자동'은 Windows가 인터넷 연결에 사용하고 있는 어댑터를 고릅니다(기본값: '자동').
- 게임 실행 파일: 통신을 읽을 게임을 게임 배포처별로 고릅니다. '자동'은 지원하는 어느 게임이든 읽습니다(기본값: '자동').
- 사용자 지정 실행 파일 이름: 게임 실행 파일에서 '사용자 지정'을 골랐을 때 표시됩니다. 읽을 게임의 실행 파일 이름을 입력합니다(기본값: 빈칸).

## 시작 설정

- Windows 시작 시 앱 실행: Windows에 로그인할 때 앱을 실행합니다(기본값: 끄기).
- 앱 시작 시 업데이트 확인: 앱을 실행할 때 새 버전이 있는지 확인합니다(기본값: 켜기).
- 앱 시작 시 단축키 보조 프로그램 실행: [단축키](단축키)를 받는 보조 프로그램을 실행합니다. 실행할 때 사용자 계정 컨트롤 확인이 표시됩니다. 끄면 단축키를 사용할 수 없습니다(기본값: 켜기).
- 앱 시작 시 VOICEVOX 실행: 앱을 실행할 때 VOICEVOX가 작동하고 있지 않으면 실행합니다(기본값: 끄기).
- 설치 경로: '앱 시작 시 VOICEVOX 실행'이 켜져 있을 때 표시됩니다. VOICEVOX의 폴더를 고릅니다. 작동 중인 VOICEVOX가 있으면 그 위치가 자동으로 들어갑니다(기본값: 빈칸).

## 표시 설정

- 언어: 앱의 표시 언어입니다. '시스템 설정 따르기'는 Windows의 표시 언어가 일본어, 한국어, 중국어면 그 언어, 그 외에는 영어가 됩니다(기본값: '시스템 설정 따르기').
- 숫자: 큰 수를 줄이는 방법입니다. '서양식(KMBT)'은 K, M, B, T를, '동아시아식(만억조)'은 만, 억, 조를 사용합니다(기본값: '서양식(KMBT)').
- 플레이어 이름: 플레이어 이름을 표시할지 정합니다. 숨긴 이름은 `*****`가 됩니다. '자신 이외 숨기기'는 자신의 이름만 표시합니다(기본값: '표시').
- 내부 ID: 이름 뒤에 게임 안의 번호를 붙입니다. 전부, 또는 스킬, 버프, 엔티티, 맵 중 하나를 고를 수 있습니다(기본값: '숨기기').
- 이름 없는 스킬과 버프: 게임에 표시 이름이 없는 스킬(버프로 인한 피해와 회복 포함)의 이름과 타임라인의 버프 이름을 빈칸으로 둘지, 내부 이름으로 표시할지 고릅니다. 버프 목록 등의 버프 이름에는 적용되지 않습니다. 내부 이름은 중국어뿐입니다(기본값: '내부 이름으로 표시').

## 위젯 설정

- 위젯 창: 위젯 창을 항상 위에 표시할지, 고정한 창만 위에 표시할지 고릅니다(기본값: '항상 위에 표시').
- 위젯 상태: 위젯 창 제목 왼쪽에 상태 원을 표시할지 정합니다. '정상 상태가 아닐 때만 표시'는 노란색과 빨간색일 때만 표시합니다(기본값: '표시').

## 집계 설정

- 비전투 지역에서 집계 중지: 아스텔리즈, 가든 정원, 가든 주택에서는 집계하지 않습니다(기본값: 켜기).
- 자동 일시정지: 전투가 멈춘 뒤 이 초 수가 지나면 경과 시간을 멈춥니다. 다음 전투에서 이어서 셉니다(기본값: 10초).
- 진행에 따라 자동 리셋: 던전 시작, 보스 방 입장, 전멸 시 집계를 구분합니다(기본값: 켜기).
- 다음 이벤트까지 결과 유지: 집계가 구분되어도 다음 전투가 시작될 때까지는 이전 결과를 표시한 채로 둡니다(기본값: 켜기).
- 기록 표시 자동 해제: 기록을 열고 있는 동안 현재 전투에서 일이 일어나면 현재 전투로 돌아갑니다(기본값: 켜기).
- 기록 최대 보관 수: 저장할 기록의 수입니다. 넘으면 오래된 것부터 삭제됩니다(기본값: 99개).
- 측정 시간: '측정'으로 집계하는 시간입니다. 30~1200초로 입력합니다(기본값: 180초).
- 처음 공격한 적만 측정: 측정하는 동안 처음 피해를 준 적에 대한 피해만 집계합니다(기본값: 켜기).

## 단축키

키 목록과 지정 방법은 [단축키](단축키)에 있습니다. 단축키 보조 프로그램이 작동하고 있는 동안에만 표시됩니다.

## 테마

- 창 색상: 메인 화면이나 설정 등의 창 색상입니다. 나열된 색을 누르거나 '색상 선택'으로 고릅니다(기본값: 흰색).

## 주의 사항

- 위젯 창의 색상과 불투명도는 위젯별 설정에 있습니다([위젯 공통 설정](위젯-공통-설정)).
- 초기화해도 '[알림](알림)'의 설정과 위젯별 설정은 돌아가지 않습니다.
