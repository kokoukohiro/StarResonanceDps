「[ウィジェット](ウィジェット)」にカードを足し、ウィジェットの窓の中身をプラグインで作るための説明です。どのプラグインにも要ることは、[プラグイン開発](プラグイン開発)にあります。

## 2つの形

| 形 | 入口のクラスが実装するインターフェース | 窓 |
|---|---|---|
| 窓が1枚のウィジェット | `IPluginWidgetProvider` | 1つのウィジェットに1枚 |
| 相手ごとに窓を開くウィジェット | `IPluginMultiWidgetProvider` | 相手ごとに1枚。カードの選択リストで相手を選びます |

- 1つのプラグインで両方を実装できます。ウィジェットの`Id`は、両方を通して重ならないようにします。カードは、窓が1枚の形、相手ごとの形の順に、定義の順で並びます
- `IPluginWindowProvider`の窓が無いプラグインなら、`PluginGenre`は要りません

| アプリが持つもの | プラグインが渡すもの |
|---|---|
| カード(お気に入り・ピン留め・クリック透過・設定・起動)、窓の枠とヘッダー(状態の円・タイトル・閉じる)、設定の窓の「ウィンドウ設定」と「テーマ」、位置と大きさの保存 | ウィジェットの定義(名前・既定の大きさ・フッターの有無・設定の節)と、窓の中身(本体・フッター・ヘッダーのボタン) |

## 窓が1枚のウィジェット

```csharp
using System.Windows;
using System.Windows.Controls;
using StarResonanceDps.PluginSdk;

[assembly: PluginRegistration(typeof(MyPlugin.Plugin), PluginSdkVersion.Current)]
[assembly: PluginDisplayName("ja-JP", "私のプラグイン")]
[assembly: PluginAuthor("YourName")]
[assembly: PluginVersion("1.0.0")]

namespace MyPlugin;

public sealed class Plugin : IStarResonancePlugin, IPluginWidgetProvider
{
    public void Initialize(IPluginContext context)
    {
    }

    public IReadOnlyList<PluginWidgetDefinition> GetWidgetDefinitions()
    {
        return
        [
            new PluginWidgetDefinition
            {
                Id = "hello",
                Names = new Dictionary<string, string> { ["ja-JP"] = "あいさつ", ["en-US"] = "Hello" },
                DefaultWidth = 240,
                DefaultHeight = 80,
            },
        ];
    }

    public PluginWidgetContent CreateWidget(string widgetId, IPluginWidgetContext context)
    {
        var text = new TextBlock { Text = "Hello", Margin = new Thickness(8) };
        text.SetResourceReference(FrameworkElement.StyleProperty, PluginResourceKeys.Text.WidgetWindow);
        return new PluginWidgetContent { Body = text };
    }

    public void Shutdown()
    {
    }
}
```

| メンバー | 呼ばれる時機 | すること |
|---|---|---|
| `GetWidgetDefinitions` | `Initialize`の直後に1回 | 足すウィジェットの定義の一覧を返します。返した順にカードが並びます。後から変えても反映されません |
| `CreateWidget` | 窓を開くたび(UIスレッド) | 窓の中身を返します。`widgetId`は定義の`Id`です |

### 定義(`PluginWidgetDefinition`)

| プロパティ | 必須か | 中身 |
|---|---|---|
| `Id` | 必須 | ウィジェットのID。1〜128文字の英数字と「.」「-」「_」です。保存のキーなので、バージョンをまたいで変えません |
| `Names` | 必須 | カード・窓のタイトル・設定の窓のタイトルに出る名前 |
| `DefaultWidth`・`DefaultHeight` | 必須 | 初めて開くときの窓の大きさ。最小は240×60で、高さにはヘッダー(30)とフッター(30)を含みます |
| `HasFooter` | 任意(既定は無し) | フッターの行を作るか |
| `ScrollsVertically` | 任意(既定は無し) | 本体を縦のスクロールバーで動かすか |
| `SettingSections` | 任意 | 設定の窓に足す節(下の「設定」) |

- 言語ごとの文字は、`Names`のように、言語の名前(`ja-JP`など)をキーにした辞書で書きます。選ばれ方は属性と同じです([プラグイン開発](プラグイン開発)の「入口のクラスと属性」)
- カードには、ウィジェットの名前だけが出ます。プラグインの名前とアイコンは出ません
- 一度保存した窓の大きさがあると、`DefaultWidth`・`DefaultHeight`は使われません

### 中身(`PluginWidgetContent`)

| プロパティ | 必須か | 中身 |
|---|---|---|
| `Body` | 必須 | 窓の本体 |
| `Footer` | `HasFooter`のときは必須、そうでなければ`null` | フッター。高さ30で、窓の全幅を使います |
| `HeaderButtons` | 任意 | ヘッダーの文字のボタン(`PluginWidgetHeaderButton`)。タイトルの右、閉じるボタンの左に並びます |

- `ScrollsVertically`が`false`のとき、本体はヘッダーとフッターのあいだを全部使います。`true`のときは、本体が窓の幅に合わせて広がり、高さは本体の望む高さになり、入りきらないと縦のスクロールバーが出ます
- 本体とフッターの`DataContext`は`null`です。バインディングを使うときは、自分で入れます
- 窓は文字の色を決めていません。ウィジェットの白い文字と影は、`Text.WidgetWindow`のスタイルを付けて出します
- 設定の「ウィンドウの不透明度」は窓の地と枠に掛かり、本体とフッターは薄くなりません
- ヘッダーのボタンは、`Text`を変えると文字が変わり、押すと`Click`がUIスレッドで来ます。中身を作ったときの一覧のまま、増えも減りもしません。設定の「ピン留め中ヘッダーを隠す」でヘッダーが隠れている間は、ボタンも隠れます
- 本体とフッターが`IDisposable`なら、窓を閉じた後に`Dispose`が呼ばれます。イベントの購読やタイマーは、そこで外します

### 中身を作るときに受け取るもの(`IPluginWidgetContext`)

| メンバー | 中身 |
|---|---|
| `WidgetId` | 定義の`Id` |
| `Settings` | このウィジェットの設定の今の値(下の「設定」) |
| `SettingsChanged` | 設定が変わったときに、UIスレッドで来るイベント |

- 窓1枚ごとに作られます。窓を閉じると、`SettingsChanged`は来なくなります
- 窓を開いただけではイベントは来ないので、最初の値は`CreateWidget`の中で`Settings`から読みます

## 設定

定義の`SettingSections`に節を書くと、ウィジェットの設定の窓の「ウィンドウ設定」と「テーマ」のあいだに出ます。

```csharp
SettingSections =
[
    new PluginWidgetSettingSection
    {
        Names = new Dictionary<string, string> { ["ja-JP"] = "表示", ["en-US"] = "Display" },
        Icon = PluginResourceKeys.Icons.Settings,
        IconStyle = PluginResourceKeys.Icons.FillStyle,
        Settings =
        [
            new PluginSwitchSetting
            {
                Id = "showTime",
                Names = new Dictionary<string, string> { ["ja-JP"] = "時刻を表示", ["en-US"] = "Show time" },
                DefaultValue = true,
            },
        ],
    },
],
```

```csharp
bool showTime = context.Settings.GetSwitch("showTime");
```

| 節(`PluginWidgetSettingSection`)のプロパティ | 中身 |
|---|---|
| `Names` | 節の名前 |
| `Icon` | 左の一覧のアイコン。`PluginResourceKeys.Icons`の形のキー(`Icon.Settings`など) |
| `IconStyle` | アイコンの描き方。`Icon.Stroke`(線)か`Icon.Fill`(塗り) |
| `Settings` | 行の一覧(1つ以上) |

行の種類(どれも`Id`と`Names`が必須で、`Notes`に注意書きを付けられます):

| 型 | 画面 | 読み方 |
|---|---|---|
| `PluginSwitchSetting` | スイッチ | `GetSwitch(id)` → `bool` |
| `PluginChoiceSetting` | 選択リスト。`Options`の`PluginChoiceOption`から選び、既定は`DefaultOptionId` | `GetChoice(id)` → 選んだ選択肢の`Id` |
| `PluginNumberSetting` | 数字の欄。`Minimum`〜`Maximum`の0以上の整数 | `GetNumber(id)` → `long` |
| `PluginTextSetting` | 1行の文字の欄 | `GetText(id)` → `string` |
| `PluginSliderSetting` | スライダー。`Minimum`〜`Maximum`を`Step`刻み | `GetSlider(id)` → `double` |
| `PluginColorSetting` | 色の丸と「色を選択」。`DefaultColors`に`#RRGGBB`を1〜5個 | `GetColor(id)` → `Color` |

- 値が変わる時機: スイッチと色は押したとき、選択リストは選んだとき、数字は確定したとき(Enterか欄を離れたとき)、文字は1文字ごと、スライダーは動かしている間
- 設定の窓を開いている間は、変えた値がすぐ`Settings`に入り、`SettingsChanged`が来ます(保存の前の試し)。「初期化」と「保存」を押したときと、保存せずに閉じて元の値に戻したときも来ます。値が同じでも来ます
- 値はアプリが`Data\WidgetSettings.json`に保存します(プラグインのフォルダの設定ファイルとは別)。プラグインを削除すると消え、更新では残ります
- 保存した値が読めないときと、選択肢が無くなったときは既定値に、範囲の外の値は近いほうの端になります
- 行の`Id`は保存のキーなので、バージョンをまたいで変えません。節をまたいで、ウィジェットの中で重ならないようにします
- 定義に無い`id`を読むと`KeyNotFoundException`、種類の違うメソッドで読むと`InvalidOperationException`です
- 同じウィジェットの窓が何枚あっても、設定は1組です

## 相手ごとに窓を開くウィジェット

```csharp
public sealed class Plugin : IStarResonancePlugin, IPluginMultiWidgetProvider
{
    public void Initialize(IPluginContext context)
    {
    }

    public IReadOnlyList<PluginWidgetDefinition> GetMultiWidgetDefinitions()
    {
        return
        [
            new PluginWidgetDefinition
            {
                Id = "slot",
                Names = new Dictionary<string, string> { ["ja-JP"] = "枠", ["en-US"] = "Slot" },
                DefaultWidth = 240,
                DefaultHeight = 80,
            },
        ];
    }

    public IReadOnlyList<PluginWidgetTarget> GetWidgetTargets(string widgetId)
    {
        return
        [
            new PluginWidgetTarget { Id = "a", Names = new Dictionary<string, string> { ["ja-JP"] = "A" }, IsDefault = true },
            new PluginWidgetTarget { Id = "b", Names = new Dictionary<string, string> { ["ja-JP"] = "B" } },
        ];
    }

    public PluginWidgetContent CreateWidget(string widgetId, string targetId, IPluginWidgetContext context)
    {
        var text = new TextBlock { Text = targetId, Margin = new Thickness(8) };
        text.SetResourceReference(FrameworkElement.StyleProperty, PluginResourceKeys.Text.WidgetWindow);
        return new PluginWidgetContent { Body = text };
    }

    public void Shutdown()
    {
    }
}
```

| メンバー | 呼ばれる時機 | すること |
|---|---|---|
| `GetMultiWidgetDefinitions` | `Initialize`の直後に1回 | 定義の一覧を返します |
| `GetWidgetTargets` | カードの選択リストを開いたときと、既定の相手を選び直す間(UIスレッド) | 相手の一覧を返します |
| `CreateWidget` | 相手の窓を開くたび(UIスレッド) | その相手の窓の中身を返します |

- 相手(`PluginWidgetTarget`)は、`Id`(1〜128文字の英数字と「.」「-」「_」、一覧の中で重ならない)・`Names`・`IsDefault`を持ちます
- 手で選ぶまでは、`IsDefault`の相手、無ければ一覧の1番目が選ばれます。後から`IsDefault`の相手が出ると、そちらに替わります
- 選択リストで選んでも、窓は開きません。起動のボタンで、選んでいる相手の窓を開け閉めします。同じ相手の窓は1枚です
- 一覧が空のときは、起動のボタンでアプリが空の窓を出します(プラグインは呼ばれません)。後で一覧に相手が出ると、その窓に中身が入ります
- 相手が一覧から消えても、窓は閉じません
- 起動中のままアプリを閉じると、次の起動で同じ相手の窓を開き直します。相手が一覧にいなくても、保存したIDで`CreateWidget`が呼ばれます
- 窓ごとに持つのは、相手・位置と大きさ・中身です。設定・テーマ・お気に入り・ピン留め・クリック透過は、そのウィジェットの窓すべてで共有します
- `GetWidgetTargets`は1秒に1回より多く呼ばれることがあるので、重い処理をしないでください
- いつも空の一覧を返すと、ビルドが止まります(SRDPS013)。中身を返す`return`がほかにあれば、一時的に空を返す`return`はかまいません

## アプリの見た目のキー

- `Text.WidgetWindow`(白い文字と影)・`Text.WidgetWindowSubtitle`(同じ文字で大きさ13)は、ウィジェットの暗い地のための文字です。ウィジェットの色を変えても白のままです
- `Brush.*`と、それを使うスタイル(`Button.Text`など)は、ウィジェットの色ではなく、アプリ全体のテーマの色で描かれます
- `ScrollViewer.WidgetWindow`は、スクロールバーの色がウィジェットの色と不透明度に付いていきます。ウィジェットの窓の中でだけ効きます
- `ToolTip.WidgetWindowInfo`は、TIPSの地と枠がウィジェットの色になります。TIPSを付ける要素の`Tag`に、ウィジェットの窓(`Window`)の`DataContext`が入っていないと、色が付きません
- キーの一覧は[プラグイン開発(窓)](プラグイン開発(窓))の「アプリの見た目のキー」にあります

## 誤りと例外

- 定義の誤り(IDの形・重なり、大きさ、アイコン、設定の値の範囲など)では、プラグインが止まり、「[プラグイン](プラグイン)」の行のTIPSに「ウィジェットの作りに誤りがあります」と出ます。理由は英語でログに出ます
- 中身の誤り(`Body`が`null`、`HasFooter`と`Footer`が合わない)と`CreateWidget`の例外では、プラグインが止まり、その窓は開かず、次の起動でも開きません
- `SettingsChanged`・ヘッダーのボタンの`Click`・`Dispose`・`GetWidgetTargets`の例外でも、プラグインが止まります
- プラグインが止まると、開いていた窓は閉じます。窓の状態は残るので、次の起動で開き直します
- 名前などの必須の文字が空だと、ビルドが止まります(SRDPS014)
