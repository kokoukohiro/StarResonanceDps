![バフ・デバフカード](images/ja/BuffDebuffCard1.png)

プレイヤーか敵に付いているバフ・デバフを1つ選び、名前・アイコン・残り時間を大きく出すウィジェットです。

## 開き方

- 「[ウィジェット](ウィジェット)」の「バフ・デバフカード」のカードで、名前の欄の選択リストから項目を選び、起動のボタンを押します。並ぶのは次の順です
  1. 設定の「ショートカット」でオンにした行(相手は自分)
  2. 「バフリスト」のカードの名前の欄で選んでいる相手のバフ
  3. 「デバフリスト」のカードの名前の欄で選んでいる相手のデバフ
  4. 開いているウィンドウのうち、上に無いもの
- 既定の項目はショートカットの1つ目で、既定の設定なら「バフカード(料理) - 自分の名前」です
- 並べるものが無いときは、名前の欄が「バフ・デバフカード」だけになります。このとき起動のボタンを押すと、自分のバフリスト(無ければデバフリスト)の1行目のカードを開きます。それも無ければ空のウィンドウを開き、最初に付いたもののカードになります
- [バフリスト](バフリスト)と[デバフリスト](デバフリスト)の行を押すか、行を右クリックして「バフカード」「デバフカード」を選ぶと、そのバフ・デバフのカードを開きます
- [エンティティ情報](エンティティ情報)の枠と[バフ・デバフグループ](バフ・デバフグループ)の行の右クリックからも開けます。グループの行は押しても開きます
- 相手とバフの組ごとにウィンドウを開きます。同じ組のウィンドウが開いていれば、そのウィンドウを前に出します

## 見方

- タイトル: 「バフカード(バフ名) - 相手の名前」か「デバフカード(デバフ名) - 相手の名前」です。料理と薬剤は「バフカード(料理)」「バフカード(薬剤)」です
- 本体: 上から、名前の行(表示設定の「バフ名」)・アイコン・残り時間です。重なっている数が2以上のときは、アイコンに数を重ねます。残り時間の出し方はバフリストと同じです
- 料理と薬剤は種類ごとに追います。食べ直して別の料理・薬剤に替わっても、同じウィンドウに出します
- 同じバフが何人からも付いているときは、残り時間の一番長いものを出します
- 効果が切れると、名前の行だけが残ります。同じバフがまた付くと、また出ます
- ヘッダー: 閉じるボタンの左に「縮小」「拡大」のボタンがあります

## 操作

- 縮小・拡大: 本体の大きさを25%ずつ、100〜1000%で変えます(200%)。ウィンドウの大きさは変わりません。倍率はカードごと(料理・薬剤は種類ごと、敵は敵の種類ごと)に保存され、次に同じカードを開くときも使われます
- 右クリックすると、次の項目を選べます。出せる項目が無いときはメニューが開きません
  - 「グループに追加」: [バフ・デバフグループ](バフ・デバフグループ)に足します。自分のカードで、グループにまだ入っていないバフに出ます
  - 「バフ・デバフカードのショートカットに追加」: ショートカットに足します。自分のカードで、ショートカットにまだ入っていないバフに出ます
  - 「このバフを通知対象にする」「このバフを通知対象にしない」(デバフは「このデバフを…」): 通知対象を切り替えます。どのカードにも出ます
- 右クリックで変えた内容は、その場で保存されます

## 設定

ウィンドウ設定とテーマは[ウィジェットの共通設定](ウィジェットの共通設定)にあります。

### 表示設定

- バフ名: 名前の行に出す内容を書きます。選択リストで項目を選んで「挿入」を押すと、その文字が入ります(`{BuffName}({TargetName})`)

| 項目 | 文字 | 出る内容 |
|---|---|---|
| バフ名 | `{BuffName}` | バフの名前。料理と薬剤は「料理」「薬剤」 |
| 対象者名 | `{TargetName}` | カードの相手の名前 |
| 付与者プレイヤー名 | `{CasterName}` | 出しているバフを付けたプレイヤーの名前。プレイヤー以外が付けたときは空 |
| レベル | `{Level}` | カードの相手のレベルの数値 |
| 改行 | `{NewLine}` | 改行 |

値が空になって残った括弧は消えます。書き方は全部のカードで同じです。

### ショートカット

カードの名前の欄の選択リストの先頭に出す行です。スイッチでオン・オフし、行をドラッグで並べ替えます。既定は次の7行です。

| 行 | 既定 |
|---|---|
| 料理 | オン |
| 薬剤 | オン |
| 時間凝固 | オン |
| 機械の故障 | オン |
| 属性停滞 | オン |
| 疲労・烈火の焼身 | オン |
| 虚弱・祈り禁止 | オフ |

自分のバフリスト・デバフリストの行と自分のカードの右クリックの「バフ・デバフカードのショートカットに追加」で足せます。足した行はオフにして保存すると消えます。

### 通知対象

カードを開いている間に、[通知](通知)の「バフ・デバフ効果切れ」で効果切れを知らせるバフ・デバフです。既定の行とオン・オフは、ショートカットと同じです。カードの右クリックの「このバフを通知対象にする」で足せます。全部のカードで同じ一覧を使います。

## 注意

- ほかのプレイヤーのカードは、その人が周りにいない間は名前の行だけになります。敵のカードは、その敵が倒された・離れたときに名前の行だけになります
- バフリストの非表示リストは、カードには効きません
- 履歴を開いていても、今のバフを出します
- 1秒ごとに読み直します
- 起動中のままアプリを閉じたカードは、次の起動で同じ相手とバフのまま開き直します。敵のカードは、同じ種類の敵が現れたときにその敵を映します
