「[プラグイン](プラグイン)」の行を押して開く窓を、プラグインで作るための説明です。どのプラグインにも要ることは、[プラグイン開発](プラグイン開発)にあります。

## 作り方

入口のクラスに`IPluginWindowProvider`を実装します。窓のあるプラグインには、`PluginGenre`が要ります。

```csharp
using System.Windows;
using System.Windows.Controls;
using StarResonanceDps.PluginSdk;

[assembly: PluginRegistration(typeof(MyPlugin.Plugin), PluginSdkVersion.Current)]
[assembly: PluginDisplayName("ja-JP", "私のプラグイン")]
[assembly: PluginGenre("ja-JP", "ツール")]
[assembly: PluginAuthor("YourName")]
[assembly: PluginVersion("1.0.0")]

namespace MyPlugin;

public sealed class Plugin : IStarResonancePlugin, IPluginWindowProvider
{
    public void Initialize(IPluginContext context)
    {
    }

    public FrameworkElement CreateContent()
    {
        var text = new TextBlock { Text = "Hello", Margin = new Thickness(16) };
        text.SetResourceReference(TextBlock.ForegroundProperty, PluginResourceKeys.Brushes.TextPrimary);
        return text;
    }

    public PluginWindowOptions? GetWindowOptions()
    {
        return new PluginWindowOptions(width: 720, height: 640, minWidth: 480, minHeight: 320);
    }

    public void Shutdown()
    {
    }
}
```

| メンバー | すること |
|---|---|
| `CreateContent` | 窓の中身を返します。窓を開くたびに呼ばれるので、毎回新しく作って返します。`Window`ではなく、`UserControl`などの要素を返します |
| `GetWindowOptions` | 窓を開くときの大きさと、最小の大きさを返します。省くか`null`を返すと、アプリの既定の大きさになります |

- `CreateContent`が`null`を返すと、プラグインが止まります
- `PluginWindowOptions`の値は、どれも0より大きくし、大きさは最小の大きさ以上にします。合わないと`ArgumentOutOfRangeException`になり、プラグインが止まります
- 中身が`IDisposable`なら、窓を閉じた後に`Dispose`が呼ばれます。イベントの購読やタイマーは、そこで外します
- `CreateContent`・`GetWindowOptions`・`Dispose`はUIスレッドで呼ばれます。例外を出すと、プラグインが止まります

## 窓の動き

- 窓の枠と、上の段(アイコン・プラグインの名前・最小化・最大化・閉じる)は、アプリが作ります。中身は上の段の下の全部で、余白とスクロールはありません
- 窓は1つのプラグインに1枚です。開いているときに行を押すと、その窓を前に出します(`CreateContent`は呼びません)
- 窓はメイン画面の左上の近くに出ます。大きさと位置は保存しません。開いていたかも保存しないので、次の起動では開きません
- 窓は最前面ではなく、タスクバーに出ます
- メイン画面を閉じると、プラグインの窓も閉じます
- アプリがプラグインを止めるときは、窓を閉じて中身を`Dispose`してから、`Stopping`のキャンセルと`Shutdown`をします

## 見た目

- 中身の見た目は自由に作れます。窓の地は、全体設定の「テーマ」の「ウィンドウの色」です
- 窓は文字の色と書体を決めていません。中身の文字には、アプリの色(`Brush.TextPrimary`など)と書体(`Font.ProjectDefault`)を付けてください
- 中身の`DataContext`には、アプリの値が受け継がれています。バインディングを使うときは、自分で入れてください

### アプリの見た目のキー

アプリの見た目は、`PluginResourceKeys`のキーで使えます。ここにあるキーの名前は変わりません。ここに無いキーはアプリのもので、予告なく変わります。

```xml
<TextBlock Text="Hello"
           Foreground="{DynamicResource Brush.TextPrimary}"
           FontFamily="{DynamicResource Font.ProjectDefault}" />
<Button Content="OK" Style="{StaticResource Button.Text}" />
```

- ブラシは`DynamicResource`で引くと、テーマの色の変更に付いていきます。`StaticResource`で引いたブラシは、変更の前の色のまま残ります
- コードで付けるときは、`SetResourceReference`を使います(上の作り方の例)

| まとまり(`PluginResourceKeys`の下) | キー |
|---|---|
| 色(`Brushes`) | `Brush.WindowSurface`・`Brush.PanelBackground`・`Brush.Border`・`Brush.BorderSoft`・`Brush.ControlBackground`・`Brush.ControlActiveBackground`・`Brush.InputBackground`・`Brush.InputHoverBackground`・`Brush.TextPrimary`・`Brush.TextSecondary`・`Brush.TextMuted`・`Brush.Success` |
| 文字(`Text`) | `Font.ProjectDefault`・`Text.WidgetWindow`・`Text.WidgetWindowSubtitle`・`Effect.WidgetWindowTextShadow` |
| ボタンとリンク(`Buttons`) | `Button.Text`・`Button.Icon`・`Hyperlink.Base`・`Hyperlink.Inline` |
| 入力(`Inputs`) | `Input.PathBox`・`Input.MultilineTextBox`・`Input.SearchBox`・`Input.SelectBox`・`Input.SettingsComboBox`・`Input.SettingsComboBoxItem`・`Input.Switch`・`Input.ValueSlider` |
| 枠(`Panels`) | `Surface.RoundedOutline`・`Surface.RoundedButtonOutline`・`Panel.Root`・`Panel.SettingSection`・`Panel.SettingField`・`Panel.SettingFieldLast` |
| スクロール(`Scrolling`) | `ScrollViewer.WidgetList`・`ScrollBar.WidgetList`・`ScrollViewer.WidgetWindow`・`ScrollBar.WidgetWindow` |
| TIPS(`ToolTips`) | `ToolTip.Info`・`ToolTip.WidgetWindowInfo`・`ToolTipOwner.Default`・`ToolTipOwner.KeepsOnClick` |
| 寸法(`Sizes`) | `Radius.Default`・`Radius.Button`・`Padding.Card` |
| アイコン(`Icons`) | 描き方の`Icon.Stroke`(線)・`Icon.Fill`(塗り)と、形の`Icon.Search`・`Icon.Add`・`Icon.ChevronDown`・`Icon.ChevronRight`・`Icon.Copy`・`Icon.Settings`・`Icon.Filter`・`Icon.Sort`・`Icon.EyeOff`・`Icon.MoreVertical`・`Icon.Help`・`Icon.Wrench`・`Icon.Sliders` |

- 全部のキーの見た目は、[SampleWindow](https://github.com/kokoukohiro/StarResonanceDps/tree/main/StarResonanceDps.Plugins.Samples/SampleWindow)の窓で並べて見られます
- `Text.WidgetWindow`・`Text.WidgetWindowSubtitle`・`Effect.WidgetWindowTextShadow`は、ウィジェットの暗い地のための白い文字と影です
- `ToolTip.WidgetWindowInfo`・`ScrollViewer.WidgetWindow`は、ウィジェットの窓の色を読むので、ウィジェットの中でだけ使います([プラグイン開発(ウィジェット)](プラグイン開発(ウィジェット)))
- アイコンは、`Path`の`Style`に描き方のキーを、`Data`に形のキーを入れます(`Style="{StaticResource Icon.Stroke}" Data="{DynamicResource Icon.Search}"`)

### TIPS

- アプリと同じTIPSにするときは、TIPSを付ける要素の`Style`に`ToolTipOwner.Default`(押すと何か起きる要素)か`ToolTipOwner.KeepsOnClick`(押しても何も起きない要素)を付け、`ToolTip`に`ToolTip.Info`のTIPSを入れます
- `Style`は1つの要素に1つなので、`Button.Text`などのスタイルを付けた要素には付けられません

### 使えないもの

- アプリの行の並べ替えと、行をまたいだ文字の選択とコピーは、アプリの型を使う仕組みなので、プラグインでは使えません
- 「はい」「いいえ」を選ばせる窓はありません(メッセージの窓は[プラグイン開発](プラグイン開発)の「メッセージ」)
