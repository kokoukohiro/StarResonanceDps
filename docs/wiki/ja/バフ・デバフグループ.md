![バフ・デバフグループ](images/ja/BuffDebuffGroup1.png)

自分のバフ・デバフのうち、選んだものだけを決まった並びで出すウィジェットです。付いていないものも「効果なし」で出します。

## 開き方

「[ウィジェット](ウィジェット)」の「バフ・デバフグループ」のカードで、起動のボタンを押します。自分だけのウィンドウで、1枚だけ開きます。

## 見方

- タイトル: 「バフ・デバフグループ」です
- 行: 設定の「バフ・デバフ」でオンにした行を、その並びで出します。左から、アイコン・名前・残り時間です。重なっている数が2以上のときは、アイコンに数を重ねます
- 付いている行: 残り時間とゲージを出します。ゲージの色は、バフの行がバフカラー、デバフの行がデバフカラーです。残り時間とゲージの見方は[バフリスト](バフリスト)と同じです
- 付いていない行: 右端に「効果なし」と出し、ゲージは出しません。時間が切れたときと解除されたときも「効果なし」です
- 料理と薬剤の行は、どの料理・薬剤が付いていても「料理」「薬剤」の1行です
- 同じバフが何人からも付いているときは、残り時間の一番長いものを出します。付けた人の名前は出しません
- 既定の行のうち料理と薬剤以外は、イマジンの奥義などの後に付くデバフです。付いている間は、次のことができません

| 行 | 付いている間 |
|---|---|
| 時間凝固 | 「奥義！タイムエディクト」の効果を、もう一度受けられない |
| 機械の故障 | 「奥義！超伝導波動」を、もう一度発動できない |
| 属性停滞 | 「奥義！デススパイラル」の効果を、もう一度受けられない |
| 疲労・烈火の焼身 | 「奥義！フレイムハート」を、もう一度使えない |
| 虚弱・祈り禁止 | 「奥義！ライフブレス」とロールスキル「復活の祈り」を、もう一度かけられない |

## 操作

- 行を押すと、その行の[バフ・デバフカード](バフ・デバフカード)を開きます。付いていない行からも開けます
- 行を右クリックすると、次の項目を選べます
  - 「バフカード」(デバフの行は「デバフカード」): 行を押したときと同じです
  - 「このバフをグループから削除」(デバフの行は「このデバフを…」): 行を外します。既定の行はオフになって設定の一覧に残り、足した行は一覧から消えます
  - 「このバフを通知対象にする」「このバフを通知対象にしない」(デバフの行は「このデバフを…」): 通知対象を切り替えます
- 右クリックで変えた内容は、その場で保存されます
- 行を掴んで動かすと、並べ替えられます。動かさずに離すと、カードを開きます。ウィンドウの外で離すかEscで取り消します
- 行を足すときは、自分の[バフリスト](バフリスト)・[デバフリスト](デバフリスト)の行か、自分のバフ・デバフカードを右クリックして「グループに追加」を選びます。足した行は一番下に入ります
- ウィンドウを小さくしたときは、ホイールか右のスクロールバーで動かします

## 設定

ウィンドウ設定とテーマは[ウィジェットの共通設定](ウィジェットの共通設定)にあります。

### 表示設定

- ゲージの長さ: 自動 / 10秒 / 20秒 / 30秒 から選びます。自動は、そのバフの効果時間です(自動)

### バフ・デバフ

出す行です。スイッチでオン・オフし、行をドラッグで並べ替えます(ウィンドウの行を掴んでも並べ替えられます)。既定は次の7行です。

| 行 | 既定 |
|---|---|
| 料理 | オン |
| 薬剤 | オン |
| 時間凝固 | オン |
| 機械の故障 | オン |
| 属性停滞 | オン |
| 疲労・烈火の焼身 | オン |
| 虚弱・祈り禁止 | オフ |

足した行はオフにして保存すると消えます。既定の行は、オフでも一覧に残ります。

### 通知対象

ウィンドウを開いている間に、[通知](通知)の「バフ・デバフ効果切れ」で効果切れを知らせるバフ・デバフです。既定の行とオン・オフは「バフ・デバフ」と同じです。行の右クリックの「このバフを通知対象にする」で足せます。「バフ・デバフ」でオフの行は知らせません。

### バフカラー

バフの行のゲージの左側と右側の色(左から右へ変わります)と、バフカラーの不透明度です(100%)。

### デバフカラー

デバフの行のゲージの左側と右側の色と、デバフカラーの不透明度です(100%)。

## 注意

- ゲームの途中でアプリを起動したときは、マップを移動するまで、起動の前から付いていたものが足りないことがあります(ウィンドウのタイトルの円が赤)
- 履歴を開いていても、今のバフ・デバフを出します
- 1秒ごとに読み直します
- ウィンドウの高さは、行の数に合わせて変わります
