困ったときの、症状ごとの理由と直し方です。直らないときは「[フィードバック](フィードバック)」から報告してください。

## 起動できない

### 英語のウィンドウが出て起動しない

「You must install .NET to run this application.」などの英語のウィンドウは、.NET 10デスクトップランタイムが入っていないときに出ます。[入れ方と更新](入れ方と更新)の「必要なもの」から入れてください。

### 「Npcapのインストール」が出て終わる

Npcapが入っていないか、バージョンを検出できないときに出ます。どちらを押してもアプリは終わります。「はい」で開くNpcapのページからNpcapを入れて、アプリを起動し直してください([最初の設定](最初の設定))。

### 「起動エラー」が出て終わる

- 「アプリを起動できませんでした。」: アプリのフォルダの`Data`に書き込めません。ウィンドウに出るフォルダの書き込み権限とセキュリティソフトの設定を確かめるか、アプリのフォルダごと書き込める場所へ移してください
- 「初期化に失敗しました。」: アプリのデータのファイルが足りないか、壊れている可能性があります。Releasesからzipを取得して、アプリのフォルダへ上書きしてください。設定と戦闘の履歴は残ります

### 「エラー」が出て終わる

予期しないエラーが起きました。もう一度起動してください。何度も出るときは、「[フィードバック](フィードバック)」から報告してください。

### 起動しても新しいウィンドウが出ない

アプリは1つしか動きません。すでに動いているときは、新しく起動せず、動いているアプリのメイン画面が前に出ます。

## 起動したときにウィンドウが出る

### ユーザーアカウント制御が出る

ホットキーの補助プログラムを起動するときに出ます。「はい」を選ぶと、ホットキーを使えます。ホットキーを使わないときは、全体設定の「起動設定」で「アプリ起動時にホットキー補助プログラムを起動」をオフにすると、出なくなります。

### 「ホットキーエラー」が出る

- 「ホットキーが無効になりました。」: 補助プログラムを起動できなかったか、途中で止まりました。アプリを起動し直して、ユーザーアカウント制御で「はい」を選んでください
- 「次のホットキーを設定できませんでした。」: ウィンドウに出るキーを、ほかのアプリが使っています。全体設定の「ホットキー」で、別のキーを割り当ててください

### 「Npcap更新」が出る

Npcapのバージョンが1.86より古いときに、起動のたびに出ます。古いバージョンには、パソコンが止まる不具合があります。アプリはそのまま使えますが、1.86以上へ更新してください。

### 「設定読み込みエラー」が出る

設定のファイルが壊れているか読み取れなかったので、初期値で起動しています。ウィンドウに出るファイルは、次に設定を保存したときに上書きされます。必要に応じて、設定をやり直してください。

### 「起動設定エラー」が出る

全体設定の「起動設定」の「Windows起動時にアプリを起動」がオンで、Windowsのスタートアップへ登録できなかったときに出ます。セキュリティソフトがスタートアップへの登録を止めていないか確かめてください。

### 「プラグインエラー」が出る

読み込めなかったプラグインがあります。ウィンドウの詳細に、プラグインごとの理由と対処方法が表示されます([プラグイン](プラグイン))。

## 何も出ない

### どのウィジェットにも何も出ない

ゲームの通信を読み取れていません。

- 全体設定の「ゲーム実行ファイル」を「自動」にしてください
- 「ネットワークアダプター」で、ゲームの通信が通るアダプターを選んでください。アプリを起動した後に有線と無線を切り替えたときは、アプリを起動し直してください
- 読み取れているかの確かめ方は、[最初の設定](最初の設定)にあります

### 数値が出ない・自分しか出ない

- アステルリーズ・ホームガーデン・ホームハウスでは、既定で集計しません([全体設定](全体設定)の「集計設定」)
- メーターのフッターに「[計測中]」が出ているときは、計測をしています。計測の間は、自分の分だけを集計します。「計測停止」を押すと戻ります([集計](集計))
- メーターの表示設定の「フィルター設定」で、出す人を絞っていないか確かめてください

### 値が変わらない

- 「[集計](集計)」の左上が「履歴表示中」のときは、履歴を開いています。開いている履歴の行をもう一度押すと、今の戦闘に戻ります
- メーターのフッターに「[計測完了]」が出ているときは、計測の時間が終わっています。「計測停止」を押すと戻ります

## 情報が足りない

### 状態の円が黄・赤になる

円かタイトルにマウスを乗せると、理由が出ます([ウィジェットの共通設定](ウィジェットの共通設定))。ゲームにログインした後でアプリを起動したときは、一度マップを移動してください。

### 名前が「UID:番号」になる

名前がまだ届いていない人です。その人に近づき直すか、ゲームでその人をクリックすると、名前が出ます。

### 名前が職業名になる

助っ人のNPCは、名前の代わりに職業名で出ます。

### クラスが「不明」「クラスR1」になる

「不明」は、まだ分からない状態です。その人が周りに来ると分かります。「クラスR1」は、アビリティを付けていない状態です。

### ホームガーデンで自分が「クラスR1」「無効」になる

ホームガーデンでは、ゲームが料理と薬剤以外のバフを付けないので、自分のクラスと潜在心相晶が分かりません。ほかの場所へ出ると戻ります。

## ウィンドウが見えない・押せない

### ウィジェットのヘッダーが無い・動かせない

ピン留めしています。既定では、ピン留めしている間はヘッダーが隠れます。「[ウィジェット](ウィジェット)」のカードでピン留めを外すと、ヘッダーが出て動かせます。

### ウィジェットを押せない

クリック透過になっています。「[ウィジェット](ウィジェット)」のカードで外してください。

### ウィジェットがゲームの後ろに隠れる

全体設定の「ウィジェットウィンドウ」が「ピン留め時のみ最前面」のときは、ピン留めしていないウィンドウがゲームの後ろに隠れます。「常に最前面」に戻すか、ウィンドウをピン留めしてください。

### ウィジェットが画面の外に出た

「[ウィジェット](ウィジェット)」のカードで停止して起動し直すと、画面の中に出ます。

### ウィジェットの表示が急に変わった

ホットキーを押していないか確かめてください。既定のキーで起きることと、戻し方です([ホットキー](ホットキー))。

| 起きたこと | キー | 戻し方 |
|---|---|---|
| 起動中のウィジェットが全部閉じた | Ctrl+F8 | 「ウィジェット」のカードで起動する |
| ウィンドウを動かせない・ヘッダーが消えた | Ctrl+F7 | もう一度押す |
| ウィンドウを押せない | Ctrl+F6 | もう一度押す |
| ウィンドウがゲームの後ろに隠れる | Ctrl+F5 | もう一度押す |
| 名前が`*****`になった | Ctrl+F11 | もう一度押す |
| メーターが空になり、フッターに「[計測中]」が出た | Ctrl+F10 | もう一度押す |
| メーターが空になった | Ctrl+F9 | 前の集計は「[集計](集計)」の履歴から開けます |

### メイン画面を閉じたらウィジェットも閉じた

メイン画面を閉じると、アプリが終わります。ウィジェットだけを出しておくときは、メイン画面を最小化してください。

## 名前や値が違う

### スキルの名前が中国語になる

ゲームに表示名の無いスキルは、内部名(中国語)で出ます。全体設定の「名前のないスキルとバフ」で、空欄にもできます。

### ゲームの中のメーターと値が違う

- 秒間の値は、合計を戦闘の経過時間で割った値です。経過時間の数え方がゲームと違うので、秒間の値が少し違うことがあります
- 回復は、実際に増えたHPを数えます。回復薬・料理・自然回復も数えます([HPSメーター](HPSメーター))

## ホットキーが効かない

- ホットキーは、ゲームかこのアプリが前面のときだけ効きます
- ユーザーアカウント制御で「いいえ」を選んだときは、その起動の間は使えません。アプリを起動し直して「はい」を選んでください
- 全体設定の「起動設定」で「アプリ起動時にホットキー補助プログラムを起動」をオフにしているときは、使えません
- ほかのアプリが使っているキーは割り当てられません。別のキーを割り当ててください
- ゲームが前面なのに効かないときは、全体設定の「ゲーム実行ファイル」を「自動」にしてください。ゲームが前面かどうかを、この設定で見分けます
- 詳しくは[ホットキー](ホットキー)にあります

## 通知が届かない・読み上げない

- 通知の項目には、ウィジェットを起動しているときだけ知らせるものがあります([通知](通知)の「注意」)
- Windows通知がゲーム中に届かないときは、Windowsの設定の「通知」で、「応答不可を自動的にオンにする」のうち、ゲームをプレイしているときと全画面のときの項目をオフにしてください
- 読み上げ方法がVOICEVOXのときは、VOICEVOXを起動しておいてください。動いていないと、起動のときなどに「VOICEVOX接続エラー」のウィンドウが出ます。ゲーム中に読み上げられなかったときはウィンドウが出ず、「[ログ](ログ)」に警告の行が残ります
- 「VOICEVOX起動エラー」が出たときは、全体設定の「起動設定」の「インストール先」を確かめてください
- 「Windowsの音声」のウィンドウが出たときは、Windowsの設定で、ウィンドウに出る言語の音声を追加してください

## 更新できない

- 「更新エラー」のウィンドウの詳細に、直し方が出ます
- 更新が「使用中のファイルが解放されるのを待っています…」で止まるときは、アプリのフォルダを開いているエクスプローラーなどを閉じてください
- うまく更新できないときは、Releasesからzipを取得して、アプリのフォルダへ上書きしてください([入れ方と更新](入れ方と更新))

## プラグインが動かない

「[プラグイン](プラグイン)」の行が「エラー」のときは、「プラグインエラー」のウィンドウに理由が表示されます。読み込めなかったプラグインがあると、アプリを起動するたびにこのウィンドウが表示されます。

## 履歴を開けない

「履歴読み込みエラー」は、その履歴のデータが見つからないか、壊れているときに出ます([集計](集計))。

## 不具合を報告する

- 「[フィードバック](フィードバック)」の「不具合報告・機能要望」で、アプリのバージョンなどが入った投稿画面が開きます
- アプリが起動しないときは、[GitHubの投稿画面](https://github.com/kokoukohiro/StarResonanceDps/issues/new?template=feedback.yml)から報告してください。環境の欄に、Windowsとアプリのバージョンを書いてください
- ログを頼まれたときは、アプリのフォルダの`Data\CombatRuntime.log`を添付してください([ログ](ログ))
