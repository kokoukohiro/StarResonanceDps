1人のプレイヤーの装備を、部位ごとに1行ずつ並べるウィジェットです。

## 開き方

- 「[ウィジェット](ウィジェット)」の「装備情報」のカードで、名前の欄の選択リストから相手を選び、起動のボタンを押します。既定の相手は自分です
- [プレイヤーリスト](プレイヤーリスト)と[蘇生リスト](蘇生リスト)の行を右クリックして、「装備情報」を選んでも開けます
- 相手ごとにウィンドウを開きます。同じ相手のウィンドウが開いていれば、そのウィンドウを前に出します

## 見方

- タイトル: 「装備情報 - プレイヤー名」です
- 行: 左から、部位のアイコン・装備の名前(表示設定の「装備名」)・装備Lvです。部位は武器・頭部・胴部・腕部・脚部・耳飾り・首飾り・指輪・腕輪-左・腕輪-右・護符の順です
- 名前の色はレアリティごとの色です(テキストカラー)
- 装備Lv: 「装備Lv.260」の形です。ほかのプレイヤーの突破のある装備は、突破の段階が分からないので「装備Lv.260~270」のように範囲で出ます
- 行にマウスを乗せると、装備の能力値がTIPSで出ます。ほかのプレイヤーの値は「筋力 412~528」のように範囲で、自分の値は具体的な値です
- 何も着けていない部位は「装備なし」、分からない部位は「不明」です

## 操作

- 行にマウスを乗せるとTIPSが出ます。押しても閉じません
- ウィンドウを小さくしたときは、ホイールか右のスクロールバーで動かします

## 設定

ウィンドウ設定とテーマは[ウィジェットの共通設定](ウィジェットの共通設定)にあります。

### 表示設定

- 装備名: 行の名前に出す内容を書きます。選択リストで項目を選んで「挿入」を押すと、その項目の文字が入ります。入力欄の下のプレビューで確かめられます(`{EquipName}({MainStat})`)

| 項目 | 文字 | 出る内容 |
|---|---|---|
| 装備名 | `{EquipName}` | 装備の名前 |
| 装備レベル | `{EquipLevel}` | 右の装備Lvと同じ文字(範囲のときも同じ) |
| メインステータス | `{MainStat}` | 筋力・知力・敏捷のどれか。無い装備では空 |

### テキストカラー

装備の名前の色を、レアリティ1〜6ごとに選びます。

## 注意

- 自分とほかのプレイヤーでは、取得できる情報が異なります。ほかのプレイヤーについてゲームから取得できるのは各部位に装着している装備だけのため、数値は装備のデータから範囲で表示します

| | 自分 | ほかのプレイヤー |
|---|---|---|
| 装備の名前・レアリティ・メインステータス | 表示する | 表示する |
| 装備Lv | 具体的な値 | 突破のある装備は範囲(「装備Lv.260~270」) |
| 基礎ステータス・進化ステータス | 具体的な値 | 範囲(「筋力 412~528」)。装備ごとにランダムで決まる行は表示しない |
| 改鋳・レアステータス | 具体的な値 | 表示しない |
| 精練・ジェム・刻印・セット効果 | 表示しない | 表示しない |

- 自分の装備は、ログイン時とマップ移動時に受信するデータから具体的な値を表示します。ゲームの途中でアプリを起動した場合は、マップを移動するまでほかのプレイヤーと同じ表示です
- クラスで変わる項目は、その人のクラスの値で出します。クラスが分からないときは、その職業の1つ目のクラスの値です
- 前のシーズンの装備のシーズン強度は、TIPSで「（無効）」が付いて灰色になります
- ほかのプレイヤーの装備は、その人が周りに来たとき・パーティの情報・ゲームでその人の名刺を開いたときに届きます
- プレイヤーリストから外れた人も、最後に分かった装備を出したままにします。ログアウトすると消えます
- 履歴を開いている間は、その戦闘にいて今は周りにいない人について、そのときの装備を出します
- ウィンドウの高さは保存されず、開くたびに既定の高さになります。幅と位置は保存されます
