1人のプレイヤーの潜在心相晶で効いているノード効果・上級ノード効果・因子を、1行ずつ並べるウィジェットです。

## 開き方

- 「[ウィジェット](ウィジェット)」の「潜在心相晶情報」のカードで、名前の欄の選択リストから相手を選び、起動のボタンを押します。既定の相手は自分です
- [プレイヤーリスト](プレイヤーリスト)と[蘇生リスト](蘇生リスト)の行を右クリックして、「潜在心相晶情報」を選んでも開けます
- 相手ごとにウィンドウを開きます。同じ相手のウィンドウが開いていれば、そのウィンドウを前に出します

## 見方

- タイトル: 「潜在心相晶情報 - プレイヤー名」です
- 行: 左にアイコン、右に名前です。ノード効果 → 上級ノード効果 → 因子の順に並びます
- 上級ノード効果の名前は「共通1」〜「共通5」で、アイコンは型ごとに違います
- 因子の名前: 自分は因子レベル(「G10」など)を付けて表示し、ほかのプレイヤーは因子レベルなしで表示します(「ヘヴィガーディアン・実像因子X6」など)
- 何も無いときは空です

## 操作

- 行にマウスを乗せると背景が付きます。押しても何も起きません
- 行がウィンドウに入りきらないときは、ホイールか右のスクロールバーで動かします

## 設定

ウィンドウ設定とテーマだけです([ウィジェットの共通設定](ウィジェットの共通設定))。

## 注意

- 自分とほかのプレイヤーでは、取得できる情報が異なります。ほかのプレイヤーの因子はゲームから取得できないため、効果によって付与されるバフから判別できる範囲で表示します

| | 自分 | ほかのプレイヤー |
|---|---|---|
| ノード効果・上級ノード効果 | 表示する | 表示する |
| 因子 | すべて(バフが付与されない因子も含む) | バフが付与される因子のみ |
| 因子レベル(「G10」など) | 表示する | 表示しない |

- 自分の因子は、潜在心相晶の育成データから表示します。ゲームの途中でアプリを起動した場合は、マップを移動するまでほかのプレイヤーと同じ表示です
- 型そのものは出しません([プレイヤーリスト](プレイヤーリスト)と[プレイヤー情報](プレイヤー情報)に出ます)。滅妄心相晶と、上級ノードの型ごとの専用の効果も出しません
- ほかのプレイヤーの分は、その人が周りにいる間に届きます。パーティの情報では届きません
- プレイヤーリストから外れた人も、最後に分かった値を出したままにします。ログアウトすると消えます
- 履歴を開いている間は、その戦闘にいた人について、そのときの値で出します
