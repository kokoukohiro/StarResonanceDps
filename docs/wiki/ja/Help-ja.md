アプリのバージョンを確かめ、使い方などのページを開くタブです。

## 見方

- 上の欄: アプリの名前・バージョン・紹介。バージョンの後ろの括弧に、更新の確認の結果が出ます
- 「リンク」の欄: 押すと次のページを開きます

| 欄 | 開くページ |
|---|---|
| 使い方 | このWikiの[Home](Home-ja) |
| プラグインの作り方 | このWikiの[プラグイン開発](Plugin-Development-ja) |
| GitHub | GitHubのリポジトリのホームページ(README) |
| リリースノート | GitHubのリリースノート(バージョンごとの変更点) |

- 使い方・プラグインの作り方・GitHubは、アプリの言語のページを開きます。表は日本語のときの開く先で、ほかの言語ではWikiのその言語のページと、その言語のREADMEを開きます
- いちばん下: 著作権とライセンス。「ライセンス情報」を押すと、GitHubのライセンスの説明のページを開きます

## 操作

- 「更新を確認」を押すと、新しいバージョンがあるかを確かめます。あれば確認の窓が出ます([入れ方と更新](Installation-and-Updates-ja))
- 確認中はボタンが「キャンセル」に変わり、押すと確認をやめます
- 欄を押すと、ブラウザでそのページを開きます

## 注意

- 更新の確認とページを開くには、インターネットへの接続が必要です
- ライセンスの本文と、使っているライブラリのライセンスは、アプリのフォルダの`LICENSE`・`LICENSING.md`・`THIRD-PARTY-NOTICES.txt`にもあります
