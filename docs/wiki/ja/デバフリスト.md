![デバフリスト](images/ja/DebuffList1.png)

プレイヤー1人か敵1体に付いているデバフを、残り時間とゲージつきで1行ずつ並べるウィジェットです。作りは[バフリスト](バフリスト)と同じで、設定はバフリストと別々に持ちます。

## 開き方

- 「[ウィジェット](ウィジェット)」の「デバフリスト」のカードで、名前の欄の選択リストから相手を選び、起動のボタンを押します。並びはバフリストと同じです(既定は自分)
- [プレイヤーリスト](プレイヤーリスト)・[蘇生リスト](蘇生リスト)・[エンティティリスト](エンティティリスト)の行を右クリックして、「デバフリスト」を選んでも開けます。[エンティティ情報](エンティティ情報)のデバフの枠を押しても開きます
- 相手ごとに窓を開きます。同じ相手の窓が開いていれば、その窓を前に出します

## 見方

- タイトル: 「デバフリスト - 相手の名前」です
- 行の見方は[バフリスト](バフリスト)と同じです。敵の窓は既定では、プレイヤーが付けたデバフを付けた人ごとに1行にし、付けた人の名前を付けます(画像は、2人のプレイヤーがボスに付けたデバフ)
- 並び: 優先表示リストでオンのデバフが先頭(リストの順)で、残りは付いた順(新しいものが下)です

## 操作

- 行を押すと、そのデバフの[バフ・デバフカード](バフ・デバフカード)を開きます
- 行を右クリックすると、「デバフカード」「このデバフを優先表示」(優先表示中は「このデバフの優先表示をやめる」)「このデバフを非表示」を選べます。自分の窓では「グループに追加」「バフ・デバフカードのショートカットに追加」も出ます。働きはバフリストと同じです
- 行が窓に入りきらないときは、ホイールか右のスクロールバーで動かします

## 設定

ウィンドウ設定とテーマは[ウィジェットの共通設定](ウィジェットの共通設定)にあります。

### 表示設定

項目と入れられる文字は[バフリスト](バフリスト)と同じです。既定は、バフ名が`{BuffName}({CasterName})`、ゲージの長さが30秒、同種バフの表示がプレイヤーのみまとめる、付与者プレイヤー名の表示が他者付与のみです。

### 優先表示リスト

先頭に出すデバフです。スイッチでオン・オフし、行をドラッグで並べ替えます。既定は次の6行です。

| 行 | 既定 |
|---|---|
| 時間凝固 | オフ |
| 機械の故障 | オフ |
| 属性停滞 | オフ |
| 重傷 | オン |
| 回復禁止(「奥義！ヘルスラスト」のもの) | オン |
| 回復禁止(ロールスキル「ヘルスラスト」のもの) | オン |

行の右クリックの「このデバフを優先表示」で足せます。足した行はオフにして保存すると消えます。

### 非表示リスト

出さないデバフです。行の右クリックの「このデバフを非表示」で足します。スイッチをオフにして保存すると、一覧から消えて、また出るようになります。

### デバフカラー

ゲージの左側と右側の色(左から右へ変わります)と、デバフカラーの不透明度です(100%)。

## 注意

- 注意は[バフリスト](バフリスト)と同じです
- 優先表示と非表示はデバフの番号で決まります。同じ名前でも番号の違うデバフ(2つの「回復禁止」など)は、別々に扱います
