ゲームの中のできごとを、Windowsの通知か読み上げで知らせるタブです。項目ごとに、知らせるか・文章・知らせ方を決めます。

## 見方

- 中央: 通知の項目です。左のチェックが付いた項目だけを知らせます(既定はどれもオフ)
- 右上: 選んでいる項目の文章と、「プレビュー」(例の名前を入れた文)です
- 右下: 選んでいる項目の設定と、知らせ方です

## 操作

- 項目を押すと、その項目の文章と設定が右に出ます
- 文章: 知らせる文を書きます。選択リストで項目を選んで「挿入」を押すと、カーソルの位置に`{PlayerName}`などの文字が入り、知らせるときに名前などに置き換わります。空欄にすると既定の文で知らせます
- 変えた内容はその場で保存されます

![HP低下を選んだとき](images/ja/Notifications2.png)

### 項目

| 項目 | 知らせるとき | 既定の文 |
|---|---|---|
| 入場確認 | マッチングが成立したときと、パーティのメンバーがコンテンツへの入場を始めたとき(ゲームの入場確認の画面が開くとき) | {Content}に入ります |
| HP低下 | 「対象プレイヤー」のHPが「HP低下判定」の割合以下になった状態が、「通知条件」の秒数続いたとき。その間にHPが戻るか戦闘不能になったときは知らせません | {PlayerName}のHPが低下しました |
| プレイヤー出現 | 名前かUIDが対象に当たるプレイヤーが、周りに現れたとき | {PlayerName}が出現しました |
| エンティティ出現 | 名前かIDが対象に当たる敵が、周りに現れたとき | {EntityName}が出現しました |
| 狙われるプレイヤー | 「対象エンティティ」の敵が「対象プレイヤー」を狙っている状態が、「通知条件」の秒数続いたとき | {PlayerName}が{EntityName}に狙われました |
| バフ・デバフ効果切れ | 起動中の[バフ・デバフカード](バフ・デバフカード)か[バフ・デバフグループ](バフ・デバフグループ)に出ているバフ・デバフが、時間切れで消えたとき | {TargetName}の{BuffName}の効果が切れました |
| 薬剤・料理効果切れ | 薬剤・料理のバフの残りが、「通知条件」の時間を下回ったとき | {TargetName}の{BuffName}効果が切れそうです |
| 予兆技 | ボスの技のうち、ゲームで予告か警告が出る技が来るとき | {SkillName}が来ます |
| エンティティ詠唱 | HPバーのある敵が、名前かIDが対象に当たるスキルの詠唱を始めたとき | {EntityName}が詠唱中です |
| プライベートトーク | ほかのプレイヤーからプライベートトークが届いたとき。ゲームでその相手とのトークを開いているときは知らせません | {PlayerName}からプライベートトークが届きました |
| ワールドチャット | ワールドチャットの発言に、一致ワードが全部含まれているとき | {PlayerName}から募集がありました |

### 項目ごとの設定

- HP低下
  - 対象プレイヤー: すべて / パーティメンバーのみ / パーティメンバー以外 / 自分のみ(すべて)
  - HP低下判定: HP45% / HP35% / HP25% / HP15% / HP5%(HP15%)
  - 通知条件: 無条件 / HP低下状態1秒以上 / HP低下状態2秒以上 / HP低下状態3秒以上(HP低下状態3秒以上)
- プレイヤー出現
  - 対象プレイヤー名・対象プレイヤーUID: 知らせるプレイヤーです(空)。「|」で区切って複数入力できます。UIDを入力すると、名前より優先されます
- エンティティ出現
  - 対象エンティティ名・対象エンティティID: 知らせる敵です(空)。「|」で区切って複数入力できます。IDを入力すると、名前より優先されます。IDは全体設定の「内部ID」で表示でき、IDと名前は[タイムライン](タイムライン)からコピーできます
- 狙われるプレイヤー
  - 対象プレイヤー: すべて / パーティメンバー / 防御クラス以外 / 防御クラス以外のパーティメンバー(防御クラス以外)
  - 対象エンティティ: ボスのみ / ボスと精鋭 / すべて(ボスのみ)
  - 通知条件: 無条件 / 狙われ状態1秒以上 / 狙われ状態2秒以上 / 狙われ状態3秒以上(狙われ状態3秒以上)
- バフ・デバフ効果切れ
  - 知らせるバフ・デバフは、カードとグループの設定の「通知対象」で選びます。カードやグループの行の右クリックでも切り替えられます
- 薬剤・料理効果切れ
  - 通知条件: 効果1分以下 / 効果2分以下 / 効果5分以下 / 効果10分以下(効果2分以下)
- 予兆技
  - 通知条件: 発動時 / 発動1秒前 / 発動2秒前 / 発動3秒前(発動時)。予告のある技は、予告が終わって技が発動する時刻を基準に知らせます。警告だけが出る技は、通知条件に関係なく、技が始まったときに知らせます
- エンティティ詠唱
  - 対象スキル名・対象スキルID: 知らせるスキルです(空)。「|」で区切って複数入力できます。IDを入力すると、名前より優先されます
- ワールドチャット
  - 一致ワード: 知らせる発言に含まれる言葉です(空)。スペースで区切って複数入力すると、全部を含む発言だけを知らせます

### 知らせ方(どの項目も同じ)

- 通知方法: Windows通知 / 読み上げ(Windows通知)
- 通知音量: Windows通知の音と、読み上げの声の大きさです(100%)。0%にすると、Windows通知は音を鳴らさずに出し、読み上げは読みません
- 読み上げ方法: Windowsの音声 / VOICEVOX(Windowsの音声)。通知方法が読み上げのときに出ます
- 話者・スタイル: VOICEVOXの声を選びます。読み上げ方法がVOICEVOXのときに出ます(スタイルは、話者のスタイルが2つ以上のときだけ)

## 注意

- 「バフ・デバフ効果切れ」と、ほかのプレイヤーの「薬剤・料理効果切れ」は、ウィジェットを起動しているときだけ知らせます。ほかの項目は、ウィジェットを開いていなくても知らせます
- プレイヤー出現・エンティティ出現・エンティティ詠唱・ワールドチャットは、名前・ID・一致ワードを入れないと、オンにしても知らせません
- 名前には全体設定の「プレイヤー名」が効きます(「非表示」なら`*****`)
- ゲーム中は、Windowsの「応答不可を自動的にオンにする」によって、Windows通知が届かないことがあります。届かないときは、Windowsの設定の「通知」で、ゲームをプレイしているときと全画面のときの項目をオフにしてください
- 読み上げは届いた順に1件ずつ読み、重ねません
- Windowsの音声は、アプリの表示言語の声で読みます。Windowsにその言語の音声が入っていないと読めません
- VOICEVOXはアプリに入っていません。使うときは[VOICEVOX](https://voicevox.hiroshiba.jp/)を入れて、起動しておいてください([全体設定](全体設定)の「起動設定」で、アプリと一緒に起動できます)。日本語だけに対応しています
- VOICEVOXの声は、話者ごとの利用規約に従って使ってください。話者の行の「(話者名)の利用規約」で確かめられます
