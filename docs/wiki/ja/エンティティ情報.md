エンティティリストの敵1体の、HP・詠唱・狙っているプレイヤーとヘイト・バフとデバフをまとめて見るウィジェットです。

## 開き方

- [エンティティリスト](エンティティリスト)の行を押すか、行を右クリックして「エンティティ情報」を選びます
- 「[ウィジェット](ウィジェット)」の「エンティティ情報」のカードでも開けます。名前の欄の選択リストに、エンティティリストと同じ敵が同じ並びで出ます(既定は1番目の敵)。敵がいないときは、敵が現れるのを待つ空の窓を開き、現れた敵を映します
- 敵ごとに窓を開きます。同じ敵の窓が開いていれば、その窓を前に出します

## 見方

- タイトル: 「エンティティ情報 - 敵の名前」です
- 1行目: エンティティリストの行と同じです(得点は出ません)。詠唱中は、名前の右に技の名前、右端に詠唱のゲージが出ます。HPのバーの長さは窓の幅に合わせて変わります
- 2行目: いま狙っているプレイヤーと、ヘイトの多い順のプレイヤーです。印とゲージの見方はエンティティリストのヘイトの枠と同じです。入りきらないときは折り返します
- その下: 敵に付いているバフを並べ、行を変えてデバフを並べます。枠の上に名前(表示設定の「バフ名」)、絵に重ねて、重なっている数(2以上のとき)、絵の下に残りの秒が出ます
- バフとデバフの並び: 優先表示リストでオンのものが先頭(リストの順)で、残りは付いた順です
- 敵が周りにいない間(倒された・離れた)は、何も出しません。同じ敵が戻ると、また出します

## 操作

- バフの枠を押すとその敵の[バフリスト](バフリスト)、デバフの枠を押すと[デバフリスト](デバフリスト)を開きます
- 枠を右クリックすると、「バフリスト」「バフカード」「このバフを優先表示」(優先表示中は「このバフの優先表示をやめる」)「このバフを非表示」を選べます(デバフの枠は「デバフリスト」「デバフカード」「このデバフを…」)。優先表示と非表示は、その場で保存されます
- マウスを乗せると、バフとデバフの枠は名前、戦闘状態の印は「交戦中」、ヘイトの枠は「クラス(狙われている)」「クラス(ヘイト値: 数値)」がTIPSで出ます
- 窓を小さくしたときは、ホイールか右のスクロールバーで動かします

## 設定

ウィンドウ設定とテーマは[ウィジェットの共通設定](ウィジェットの共通設定)にあります。

### 表示設定

- エンティティ名: 名前の欄に出す内容を書きます。書き方は[エンティティリスト](エンティティリスト)の「エンティティ名」と同じで、値は別々に持ちます(`Lv.{Level} {EntityName}`)
- バフ名: バフとデバフの枠の名前に出す内容を書きます(`{BuffName}({CasterName})`)

| 項目 | 文字 | 出る内容 |
|---|---|---|
| バフ名 | `{BuffName}` | バフの名前 |
| 対象者名 | `{TargetName}` | 敵の名前 |
| 付与者プレイヤー名 | `{CasterName}` | バフを付けたプレイヤーの名前。全体設定の「プレイヤー名」で隠すと`*****` |
| レベル | `{Level}` | 敵のレベルの数値 |

- HP数値: バリア量加算表示 / バリア量個別表示 から選びます(バリア量加算表示)
- 戦闘状態: 戦闘状態の印を、表示 / 非表示 から選びます(表示)
- 狙われるプレイヤー: 2行目の左端に、いま狙っているプレイヤーを出すかです(表示)
- ヘイト値: 2行目に出す人数を、全員を表示 / 上位5人を表示 / 上位4人を表示 / 上位3人を表示 / 上位2人を表示 / ヘイト1位のみ表示 から選びます(全員を表示)
- 同種バフの表示: まとめない / まとめる から選びます。まとめないは、プレイヤーが付けたバフを付けた人ごとに別の枠にします(まとめない)
- 付与者プレイヤー名の表示: 表示 / 非表示 / 他者付与のみ から選びます(他者付与のみ)

### 優先表示リスト

先頭に出すバフとデバフです。スイッチでオン・オフし、行をドラッグで並べ替えます。既定は「重傷」と2つの「回復禁止」で、どれもオンです。枠の右クリックの「このバフを優先表示」で足せます。足した行はオフにして保存すると消えます。

### 非表示リスト

出さないバフとデバフです。枠の右クリックの「このバフを非表示」で足します。スイッチをオフにして保存すると、一覧から消えて、また出るようになります。

### アイコンカラー

種類のアイコンと、ヘイトの枠のクラスのアイコンの色を選びます。行と既定の色はエンティティリストと同じです。

## 注意

- 窓は開いたときの1体を追います
- バフとデバフは1秒ごとに読み直します
- アプリを起動する前から周りにいた敵や、敵の情報がまだ足りないときは、窓のタイトルの円が黄になります。その敵に近づき直すと直ります
- 窓の高さは、行の数に合わせて変わります
- 履歴を開いていても、今の敵を出します
