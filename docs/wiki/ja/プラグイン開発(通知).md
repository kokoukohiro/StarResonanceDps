「[通知](通知)」に項目を足し、プラグインで決めた時機に知らせるための説明です。どのプラグインにも要ることは、[プラグイン開発](プラグイン開発)にあります。

| アプリが持つもの | プラグインが渡すもの |
|---|---|
| 「通知」の一覧の行とチェック、文章の入力欄とプレビュー、通知方法・通知音量・読み上げ方法・話者、値の保存 | 項目の定義(名前・既定の文・差し込む項目・項目の設定)と、知らせる時機(`Notify`) |

## 作り方

入口のクラスに`IPluginNotificationProvider`を実装します。`IPluginWindowProvider`の窓が無いプラグインなら、`PluginGenre`は要りません。

次の例は、マップを移動したときに知らせます。

```csharp
using StarResonanceDps.PluginSdk;

[assembly: PluginRegistration(typeof(MyPlugin.Plugin), PluginSdkVersion.Current)]
[assembly: PluginDisplayName("ja-JP", "私のプラグイン")]
[assembly: PluginAuthor("YourName")]
[assembly: PluginVersion("1.0.0")]

namespace MyPlugin;

public sealed class Plugin : IStarResonancePlugin, IPluginNotificationProvider
{
    private const string MapEnteredId = "map-entered";

    private IPluginContext? _context;

    public void Initialize(IPluginContext context)
    {
        _context = context;
        context.GameData.MapEntered += OnMapEntered;
    }

    public IReadOnlyList<PluginNotificationDefinition> GetNotificationDefinitions()
    {
        return
        [
            new PluginNotificationDefinition
            {
                Id = MapEnteredId,
                Names = new Dictionary<string, string> { ["ja-JP"] = "マップ移動", ["en-US"] = "Map change" },
                DefaultTexts = new Dictionary<string, string> { ["ja-JP"] = "{MapName}に移動しました", ["en-US"] = "Moved to {MapName}" },
                Fields =
                [
                    new PluginNotificationField
                    {
                        Key = "MapName",
                        Names = new Dictionary<string, string> { ["ja-JP"] = "マップ名", ["en-US"] = "Map name" },
                        SampleValues = new Dictionary<string, string> { ["ja-JP"] = "アステルリーズ" },
                    },
                ],
            },
        ];
    }

    private void OnMapEntered(object? sender, EventArgs e)
    {
        if (_context is null || !_context.Notifications.IsEnabled(MapEnteredId))
        {
            return;
        }

        int? sceneId = _context.GameData.Session.SceneId;
        string? mapName = sceneId is int id ? _context.Names.GetSceneName(id) : null;
        _context.Notifications.Notify(MapEnteredId, new Dictionary<string, string> { ["MapName"] = mapName ?? string.Empty });
    }

    public void Shutdown()
    {
        if (_context is not null)
        {
            _context.GameData.MapEntered -= OnMapEntered;
        }
    }
}
```

| メンバー | 呼ばれる時機 | すること |
|---|---|---|
| `GetNotificationDefinitions` | `Initialize`の後に1回(ウィジェットの定義があれば、その後) | 足す項目の一覧を返します。返した順に「通知」に並びます。後から変えても反映されません |

- 空の一覧を返すと、「通知」には何も足されません

### 項目の定義(`PluginNotificationDefinition`)

| プロパティ | 必須か | 中身 |
|---|---|---|
| `Id` | 必須 | 項目のID。1〜128文字の英数字と「.」「-」「_」です。保存のキーなので、バージョンをまたいで変えません |
| `Names` | 必須 | 「通知」の一覧に出る項目名 |
| `DefaultTexts` | 必須 | 使う人が文章を書くまで使う文。差し込む項目は`{Key}`で書きます |
| `Fields` | 任意 | 差し込む項目(`PluginNotificationField`) |
| `Settings` | 任意 | 項目の設定。種類はウィジェットの設定と同じで、色(`PluginColorSetting`)だけは使えません([プラグイン開発(ウィジェット)](プラグイン開発(ウィジェット))の「設定」) |

| 差し込む項目(`PluginNotificationField`)のプロパティ | 必須か | 中身 |
|---|---|---|
| `Key` | 必須 | 1〜64文字の英字と数字(「.」「-」「_」は使えません)。文の中では`{Key}`と書きます |
| `Names` | 必須 | 「通知」で、差し込む項目の選択リストに出る名前 |
| `SampleValues` | 必須 | プレビューに入れる見本の値。空の辞書でもかまいません |

- 言語ごとの文字は、言語の名前(`ja-JP`など)をキーにした辞書で書きます。選ばれ方は属性と同じです([プラグイン開発](プラグイン開発)の「入口のクラスと属性」)
- 項目の`Id`はプラグインの中で、差し込む項目の`Key`と設定の`Id`は項目の中で、重ならないようにします。大文字と小文字は区別しません

## 知らせる

`IPluginContext.Notifications`(`IPluginNotificationService`)を使います。

| メンバー | 中身 |
|---|---|
| `IsEnabled(id)` | 使う人がその項目のチェックを付けているか |
| `Notify(id, values)` | 知らせます。`values`は、差し込む項目の`Key`と値です。省けます |
| `GetSettings(id)` | 項目の設定の今の値(`PluginSettingValues`)。読み方はウィジェットの設定と同じです |
| `SettingsChanged` | 項目のチェックか設定の値が変わったときに、UIスレッドで来るイベント。値は項目の`Id`です |

- `IsEnabled`・`Notify`・`GetSettings`は、どのスレッドから呼んでもかまいません
- 項目は`Initialize`の後に読むので、`Initialize`と`GetNotificationDefinitions`の中では、どの`Id`でも`ArgumentException`になります。`SettingsChanged`の購読はかまいません
- 定義に無い`Id`や、`Fields`に無い`Key`を渡すと、`ArgumentException`になります
- `Notify`は、知らせる時点でチェックが外れていれば何もしません。値を作るのに手間がかかるときは、先に`IsEnabled`を見ます
- 文は、使う人の文章か、無ければ表示言語の既定の文です。`{Key}`を値に置き換え、値を渡さなかった項目は空になります。定義に無い`{…}`はそのまま残ります。文が空なら知らせません
- 知らせたかどうかは返りません。Windows通知を出せない・声を使えないときも例外にはならず、アプリのログに残ります
- アプリは知らせる回数を間引きません。呼ぶたびに知らせ、読み上げと通知の音は1件ずつ順に鳴らします。短い間に何度も呼ばないよう、間隔や上限はプラグインで持ちます
- プラグインが止まった後は、`Notify`は何もしません

### 項目の設定

- 値は、「通知」で変えたときにその場で保存され、`SettingsChanged`が来ます。スイッチ・選択リストは変えたとき、数字は確定したとき(Enterか欄を離れたとき)、文字は打ち終わって0.3秒後、スライダーはつまみを手放したときです
- `SettingsChanged`は、その項目のチェックか設定の値が前と違うときだけ来ます。文章・通知方法・通知音量・声を変えたときは来ません
- アプリを起動したときは来ないので、最初の値は`IsEnabled`・`GetSettings`で読みます

## 「通知」での出方

- 一覧の、アプリの項目の後ろに、プラグインの名前の見出しを付けて並びます。プラグインは入れた順、プラグインの中は定義の順です
- 項目は最初はチェックが外れています。プラグインから最初にチェックを付けることはできません
- 右上の文章の欄の下の選択リストに、差し込む項目の名前が並び、「挿入」で`{Key}`を入れられます。プレビューには見本の値が入ります
- 右下には、項目の設定が通知方法の上に並びます
- Windows通知には、アプリの名前とアイコンが出ます。プラグインの名前は出ません
- 値は、アプリが`Data\AppSettings.json`に保存します(プラグインのフォルダの設定ファイルとは別)。プラグインが止まっても残り、削除すると消え、更新しても残ります
- 項目の`Id`かアセンブリ名を変えると別の項目になり、前の値は引き継がれません

## 誤りと例外

- 定義の誤り(IDやキーの形・重なり、数字やスライダーの範囲、色の設定など)では、プラグインが止まり、「[プラグイン](プラグイン)」の行のTIPSに「通知の項目の作りに誤りがあります」と出ます。理由は英語でログに出ます
- `GetNotificationDefinitions`と`SettingsChanged`の例外でも、プラグインが止まります
- 項目名・既定の文・差し込む項目の名前が空だと、ビルドが止まります(SRDPS014)
