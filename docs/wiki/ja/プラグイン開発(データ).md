プラグインでゲームのデータを読むための説明です。どのプラグインにも要ることは、[プラグイン開発](プラグイン開発)にあります。

| `IPluginContext`のメンバー | 中身 |
|---|---|
| `GameData`(`IPluginGameDataService`) | アプリが通信から作った値(接続とマップ・プレイヤー・周りの敵・バフ・戦闘の集計と記録・自分のモジュール)と集計の設定、変わったときのイベント |
| `Names`(`IPluginNameService`) | スキル・バフ・モンスター・クラス・マップ・アイテムの番号から名前を引く |
| `Packets`(`IPluginPacketService`) | ゲームのメッセージそのもの |
| `CombatEvents`(`IPluginCombatEventService`) | アプリが処理した戦闘のできごと(与ダメ・スキルや被ダメやタイムラインの記録・バフの付与と除去・モンスターのスキルとHP0)の流れ |
| `History`(`IPluginHistoryService`) | 保存した戦闘(履歴)を読む・開く、戦闘にプラグインの値を保存する([プラグイン開発(履歴)](プラグイン開発(履歴))) |

## ゲームのデータ(`GameData`)

次の例は、戦闘が終わったときに、全員の与ダメの合計をログに書きます。

```csharp
using StarResonanceDps.PluginSdk;

[assembly: PluginRegistration(typeof(MyPlugin.Plugin), PluginSdkVersion.Current)]
[assembly: PluginDisplayName("ja-JP", "私のプラグイン")]
[assembly: PluginAuthor("YourName")]
[assembly: PluginVersion("1.0.0")]

namespace MyPlugin;

public sealed class Plugin : IStarResonancePlugin
{
    private IPluginContext? _context;

    public void Initialize(IPluginContext context)
    {
        _context = context;
        context.GameData.EncounterClosed += OnEncounterClosed;
    }

    private void OnEncounterClosed(object? sender, PluginEncounterResult result)
    {
        foreach (PluginEncounterPlayer player in result.Totals.Players)
        {
            _context?.Logger.Info($"{player.CharacterId}: {player.Damage.Total}");
        }
    }

    public void Shutdown()
    {
        if (_context is not null)
        {
            _context.GameData.EncounterClosed -= OnEncounterClosed;
        }
    }
}
```

| メンバー | 中身 | 変わったときのイベント |
|---|---|---|
| `CurrentServer` | 今読んでいるゲームのサーバー(`PluginGameServer`の`Asia`・`China`・`Global`・`SoutheastAsia`)。判別できなければ`Unknown` | なし |
| `Session` | 接続とマップの状態(`PluginSessionState`) | `SessionChanged` |
| `Players` | プレイヤーの一覧(`PluginPlayer`) | `PlayersChanged` |
| `Entities` | 周りのモンスターの一覧(`PluginEntity`) | `EntitiesChanged` |
| `SelfModules` | 自分の所持モジュールと装着中の枠(`PluginModuleInventory`)。まだ受信していなければ`null` | `SelfModulesChanged` |
| `GetPlayerBuffs(characterId)` | その人に今付いているバフとデバフ(`PluginBuff`) | なし(読み直す) |
| `GetEntityBuffs(entityUuid)` | そのエンティティに今付いているバフとデバフ | なし(読み直す) |
| `GetPlayer(characterId)` | その人の行(`PluginPlayer`)。`Players`にいない人は、一覧から外れた後の最後の値か、名刺やチャットで受信した値です。どれも無ければ`null` | なし(読み直す) |
| `GetPlayerBuild(characterId)` | その人のビルド(`PluginPlayerBuild`、下の「ビルド」)。`GetPlayer`が`null`の人は`null` | なし(読み直す) |
| `GetEncounter()` | 「[DPSメーター](DPSメーター)」が映している戦闘の、全員の集計(`PluginEncounterSnapshot`) | なし(読み直す) |
| `GetSkillTotals(characterId, kind)` | 同じ戦闘の、その人のスキルごとの内訳(`PluginSkillTotals`)。`kind`は与ダメ(`Damage`)か回復(`Healing`) | なし(読み直す) |
| `GetShownEncounter()` | `GetEncounter`と同じ戦闘の読み口(`IPluginEncounterRecord`)。戦闘がまだ無ければ`null` | `ShownEncounterChanged` |
| `GetLiveEncounter()` | 今の戦闘の読み口。戦闘がまだ無ければ`null` | `EncounterStarted` |
| `AggregationSettings` | 全体設定の「集計設定」の値(`PluginAggregationSettings`) | `AggregationSettingsChanged` |

| イベント | 来るとき |
|---|---|
| `EncounterStarted` | アプリが新しい戦闘を作ったとき |
| `EncounterClosed` | 記録のある戦闘を閉じたとき。閉じた戦闘の集計と、全員のスキルごとの内訳(`PluginEncounterResult`)が渡ります |
| `EncounterSaved` | 戦闘を履歴に保存したとき。その戦闘の`EncounterKey`と履歴の番号(`HistoryId`)が渡ります(`PluginEncounterSaved`) |
| `MapEntered` | 別のマップかチャンネルへ移ったとき |
| `LoggedOut` | ゲームがログイン画面へ戻ったとき |

- 値はどのスレッドから読んでもかまいません。イベントはすべてUIスレッドで来ます
- `SessionChanged`・`PlayersChanged`・`EntitiesChanged`・`SelfModulesChanged`・`ShownEncounterChanged`・`AggregationSettingsChanged`は、短い間の変化を1回にまとめ、来たときの値で知らせます。他の5つは、起きるたびに来ます
- 値は書き換えられない写しで、後から新しくなりません。新しい値は読み直します。2つの値を続けて読むと、別の瞬間の値になることがあります。戦闘の読み口(`IPluginEncounterRecord`)は写しではなく、呼ぶたびに値を読みます(下の「戦闘の読み口」)
- `Players`・`Entities`・`SelfModules`と`EncounterClosed`の結果は、すべてのプラグインに同じものを渡しています。`IReadOnlyList`などを元の型に変えて書き換えないでください
- イベントの処理は、アプリの画面と同じUIスレッドで動きます。重い処理をすると、ウィジェットも止まります
- イベントの処理で例外を投げると、プラグインが止まります

### 接続とマップ(`Session`)

| プロパティ | 中身 |
|---|---|
| `SelfCharacterId` | 自分のキャラID。取得できるまでと、ログアウトの後は`null` |
| `SceneId` | 今のマップの番号。`Names.GetSceneName`に渡します |
| `SeasonId` | 今のシーズンの番号 |
| `DungeonState` | ダンジョンの外(`NotInDungeon`)・中(`InDungeon`)・終わった後(`Finished`) |
| `IsMidLaunch` | ゲームの通信を途中から読み始め、まだ自分の情報がそろっていない(ゲームの途中でアプリを起動したときなど)。マップを移動すると`false`になります |
| `SelfTargetEntityUuid` | 自分のターゲットの敵のUUID(「[ターゲット情報](ターゲット情報)」が映す敵)。自分が最後にスキルを向けた敵で、その敵が周りから消えると`null`になり、次にその敵へスキルを向けると戻ります |
| `DungeonFlowState`・`DungeonFlowChanges` | ダンジョンの進行の状態(`PluginDungeonFlowState`)と、マップに入ってからの状態の変化(`PluginDungeonFlowChange`: 状態と受信した時刻(UTC)、古い順)。受信していなければ`null`と空です |
| `DungeonTimer` | ゲームのダンジョンの時計(`PluginDungeonTimer`)。開始時刻(サーバーの時刻のUnix秒と、このPCの時刻に直したUTC)・制限時間・減っていくか・止まっていた秒の合計・止まっている間の表示の値です。時計を送らないダンジョンと、ダンジョンの外では`null`です |

- ゲームの途中でアプリを起動したときは、自分のキャラIDや所持モジュールが、マップを移動するまで取得できないことがあります
- ゲームのロックオンと、他のプレイヤーのターゲットは、ゲームが送らないので取得できません
- 進行の状態はゲームの値のままで、`Active`(ダンジョンのマップに入った)・`Ready`(開始の前)・`Playing`(開始)・`End`(終了)・`Settlement`(結果画面)・`Vote`(投票)の順に受信します。`None`はゲームの初期の値です。同じ状態を続けて受信しても、変化には足しません。マップを移動するか、ログアウトすると空になります

### プレイヤー(`Players`)

- 入るのは、自分・パーティのメンバー・周りのプレイヤーと、DPSメーターが映している戦闘に記録がある人です。「[プレイヤーリスト](プレイヤーリスト)」の元の一覧で、プレイヤーリストのフィルターと名前順の並べ替えは当てません
- 並びは、自分、パーティのメンバー(PT番号の順)、周りにもパーティにもいない人、戦闘中の人、その他の人の順です
- 名前は、全体設定の「プレイヤー名」に従います。非表示の人は`*****`です。取得できないときは空のこともあります

| プロパティ | 中身 |
|---|---|
| `CharacterId` | キャラID。名前を伏せていても本当の値です |
| `Name` | 名前 |
| `ProfessionId` | 職業の番号。取得できなければ0 |
| `SpecState`・`SpecId` | クラスの状態(`Unknown`・`NotEquipped`(クラスR1)・`Specialized`・`Transformation`(変身))。`Specialized`のときのみ`SpecId`に番号が入ります(`Names.GetClassSpecName`に渡す) |
| `Level`・`AbilityScore`・`SeasonStrength` | レベル・能力スコア・シーズン強度。取得できなければ0 |
| `CurrentHp`・`MaxHp`・`CurrentShield` | HPとバリアの量。バリアは自分と周りにいる人のみです |
| `PartyNumber` | パーティの番号。パーティの外なら`null` |
| `IsSelf`・`IsNpc`・`IsPartyMember`・`IsNearby` | 自分か・助っ人か・パーティのメンバーか・周りにいるか |
| `IsInCombat`・`IsIncapacitated` | 戦闘状態・戦闘不能。戦闘状態を取得できるのは自分と周りにいる人のみです |
| `PsychoscopeRootBuffId`・`IsPsychoscopeInactive` | 潜在心相晶の型(ルートバフの番号)と、無効か |
| `IsFromRecord` | 開いている集計の履歴にのみいる人。保存した戦闘の`GetPlayers`の行は、すべて`true` |

### ビルド(`GetPlayerBuild`)

- 「[アビリティ情報](アビリティ情報)」「[潜在心相晶情報](潜在心相晶情報)」「[モジュール情報](モジュール情報)」「[装備情報](装備情報)」と同じ出所の値です。呼ぶたびに新しい写しを作ります
- 集計の履歴を開いている間は、履歴にのみいる人はその戦闘の値、他の人は今の値です(プレイヤーのウィジェットと同じ)。保存した戦闘の値は、戦闘の読み口の`GetPlayerBuild`で読みます
- 一覧はどれも、受信していなければ`null`、受信して空なら空です。`PluginPlayerBuild`どうしを`==`で比べても一覧の中身は比べないので、中身を比べます

| `PluginPlayerBuild`のプロパティ | 中身 |
|---|---|
| `RootBuffIds` | 付いているルートバフ(アビリティ・潜在心相晶のノード効果と上級ノード効果・因子・モジュール効果)の番号。昇順です。その人のバフをすべて受信するまで`null` |
| `TalentNodeIds` | 今の職業で取ったアビリティの木のノードの番号。昇順です。自分のみで、他の人は`null` |
| `LastUsedReplaceableSkills` | バフを付けないアビリティでスキルが置き換わるものの、元のスキルの番号から、最後に使ったほう(元か置き換え後)のスキルの番号への対応。どれもまだ使っていなければ`null` |
| `Equipment` | 装備(`PluginEquipmentItem`: 部位`Slot`と装備の番号`EquipmentId`。名前は`Names.GetItemName`)。ゲームの値を読めなかったときは`IsReadable`が`false`で、一覧は空です |
| `SkillLevels` | スキルの番号・レベル・段階(`PluginSkillLevel`の`SkillId`・`Level`・`RemodelLevel`)。自分は今の職業の習得スキル・ロールスキル・選んだイマジン、他の人はゲームが送る一覧(イマジンは装備中の2つのみ)、周りにいないパーティのメンバーはパーティの同期で最後に受信した一覧です |
| `Factors` | 今のシーズンの、有効な型に付けている因子(枠の番号`SlotId`とアイテムの番号`ItemId`)。自分のみで、他の人は`null` |
| `ModuleEffects` | 装着中のモジュールの効果(`PluginModuleEffect`)。`LinkCount`は装着中のモジュールの和です。自分のみで、他の人は`null` |

### 周りの敵(`Entities`)

- 周りにいる、種類がモンスターであるもののみが入ります。「[エンティティリスト](エンティティリスト)」の元の一覧で、エンティティリストのフィルターと名前順の並べ替えは当てません
- 並びは、戦闘状態のもの、それ以外の順で、それぞれの中はボス・精鋭・普通・その他の順です

| プロパティ | 中身 |
|---|---|
| `EntityUuid` | エンティティのUUID。`GetEntityBuffs`に渡します |
| `MonsterId` | モンスターの番号(`Names.GetMonsterName`に渡す)。アプリの起動より前から周りにいたモンスターは、一度周りから外れて再び現れるまで`null`です |
| `CurrentHp`・`MaxHp` | HP |
| `IsInCombat` | 戦闘状態 |
| `Cast` | 詠唱しているスキル(`SkillId`・`StartedAtUtc`・`TotalSeconds`)。詠唱時間のあるスキルを始めたときに入り、次にスキルが変わるまで残ります。`TotalSeconds`を過ぎても残ることがあるので、終わりは時刻で決めます |
| `TargetCharacterId` | 狙っているプレイヤーのキャラID。ヘイトの1位とは限りません |
| `HateRanking` | ヘイトの一覧(プレイヤーのみ、値の大きい順) |
| `Level` | レベル(「[エンティティリスト](エンティティリスト)」と同じ値)。取得できなければ0 |
| `CurrentShield` | バリアの量 |

### バフ(`GetPlayerBuffs`・`GetEntityBuffs`)

- 今付いているものがすべて入ります。「[バフリスト](バフリスト)」のような表示するものの絞り込みやまとめは当てません
- 周りにいない人と敵の分は空です。マップを移動するとすべて消えます
- 集計の履歴を開いていても、今の値です

| プロパティ | 中身 |
|---|---|
| `BuffUuid` | バフ1つずつのUUID |
| `BuffId` | バフの番号(`Names.GetBuffName`に渡す) |
| `Level`・`Layer` | レベルと層(スタック数) |
| `DurationSeconds` | 効果時間の総量(延長で伸びます)。持続が無ければ`null` |
| `EndUtc` | 切れる時刻(UTC)。持続が無いか、残りを取得できなければ`null` |
| `IsRemainingUnknown` | 残りの時間を取得できない |
| `CasterEntityUuid`・`CasterCharacterId` | 付与したエンティティのUUID(取得できなければ0)と、付与者がプレイヤーならそのキャラID |

### 戦闘の集計(`GetEncounter`・`GetSkillTotals`)

- 読むのはDPSメーターが映している戦闘です。集計の履歴を開いていればその戦闘、全体設定の「次のイベントまで結果を保持」で前の戦闘を映していれば、その戦闘です
- 戦闘がまだ無ければ、`GetEncounter`は`EncounterKey`が0の空の集計です
- 同じ戦闘を読み口で読むのが`GetShownEncounter`、今の戦闘を読むのが`GetLiveEncounter`です(下の「戦闘の読み口」)

| `PluginEncounterSnapshot`のプロパティ | 中身 |
|---|---|
| `IsHistory` | 保存した履歴から読んだ戦闘。`GetEncounter`では、集計の履歴を開いている |
| `StartUtc` | 戦闘の時計が動き出した時刻(UTC)。まだなら`null`。通常は最初の戦闘のできごとの時刻で、ダンジョンの時計(`ClockOrigin`)の戦闘ではダンジョンの開始の時刻です |
| `Elapsed` | 戦闘の経過時間(自動一時停止の間と、ダンジョンの時計の戦闘ではゲームのダンジョンの時計が止まっていた間を除く) |
| `IsClosed` | 戦闘が終わった |
| `Players` | 与ダメ・回復・被ダメのどれかがあるプレイヤー(`PluginEncounterPlayer`)。パーティで絞らず、並びは決まっていません |
| `EncounterKey` | アプリを起動している間、戦闘を見分ける番号(1から)。戦闘が無ければ0。今の戦闘は保存した後も同じ番号です。履歴から読んだ戦闘は読むたびに新しい番号になるので、保存した戦闘は`HistoryId`で見分けます。アプリを起動し直すと、1から数え直します |
| `HistoryId` | 履歴の番号([プラグイン開発(履歴)](プラグイン開発(履歴)))。保存するまでと、記録が無く保存されない戦闘では`null`。`EncounterClosed`の結果ではいつも`null`で、番号は`EncounterSaved`で受け取ります |
| `LastCombatEventUtc` | 最後の戦闘のできごと(ダメージ・回復など)を受信した時刻(UTC)。まだなら`null`。戦闘の時計は、ここから`Info.AutoPauseSeconds`の秒数で止まります(0なら止まりません。下の「戦闘の値」) |
| `IsAggregationStopped` | 今の戦闘で、アプリが何も記録せず、戦闘の時計も動かさない(全体設定の「非戦闘エリアでの集計を停止」がオンで、非戦闘エリアにいる)。閉じた戦闘と、履歴から読んだ戦闘では`false` |
| `ClockOrigin` | 戦闘の時計の起点(`PluginClockOrigin`)。最初の戦闘のできごと・ダンジョンの開始を受信した時刻・ゲームのダンジョンの時計の開始時刻のどれかです。プラグインがダンジョンの時計を登録していなければ、最初の戦闘のできごとです([プラグイン開発(戦闘の区切り)](プラグイン開発(戦闘の区切り))) |
| `FirstCombatEventUtc` | 最初の戦闘のできごとを受信した時刻(UTC)。まだなら`null`。回復・ヘイト・ブレイクは、この時刻から記録します。ダンジョンの時計の戦闘でなければ`StartUtc`と同じです |
| `BenchmarkFirstTargetEntityUuid` | 計測で最初に攻撃した敵のみを集計するとき、自分が最初にダメージを与えた敵のUUID。この敵へのダメージ・ヘイト・ブレイクのみを数えます。決まるまでと、他の戦闘と、履歴から読んだ戦闘では`null` |

- `PluginEncounterPlayer`は、`CharacterId`と、与ダメ(`Damage`)・回復(`Healing`)・被ダメ(`DamageTaken`)の合計(`PluginCombatTotals`)を持ちます
- `PluginCombatTotals`は、合計(`Total`)・秒間値(`PerSecond`、DPSメーターと同じ)・その人の有効な時間での秒間値(`ActivePerSecond`、スキル詳細と同じ)・ヒット数(`Hits`)・会心と幸運の合計と数です
- `PluginSkillTotals`は、スキル詳細と同じ行で、行のキー(`RowKey`)・行の名前(`Name`、無ければ`null`)・合計・秒間値・ヒット数・会心率(`CritRate`)・その人の合計に占める割合(`Share`)を持ちます。合計の大きい順です
- `EncounterStarted`は、マップの移動・ダンジョンの開始・「進行で自動リセット」の区切り・手動のリセット・計測の開始と停止・ログアウトと、プラグインの区切りの要求と規則([プラグイン開発(戦闘の区切り)](プラグイン開発(戦闘の区切り)))で来ます。1回のマップ移動で何回か来ることがあります
- 戦闘の時計が動き出したときのイベントはありません。`GetEncounter().StartUtc`を読みます
- `EncounterClosed`は、記録のある戦闘を閉じて次の戦闘を作るときに来ます。アプリを閉じるときの最後の戦闘では来ません。閉じた戦闘を`GetEncounter`で読めるのは、メーターがその戦闘を映している間のみなので、要る値は受け取った結果からその場で持っておきます。保存された後は、`EncounterSaved`の`HistoryId`で[プラグイン開発(履歴)](プラグイン開発(履歴))の`LoadAsync`から読み直せます
- `EncounterSaved`は、アプリが戦闘を履歴に保存するたびに1回、同じ戦闘の`EncounterClosed`の後、次の`EncounterStarted`の前に来ます。記録の無い戦闘は保存しないので来ません。アプリを閉じるときの最後の戦闘でも来ません
- `ShownEncounterChanged`は、`GetEncounter`と`GetShownEncounter`が読む戦闘が替わった後に来ます。履歴を開いたとき(使う人が開いたときも、`OpenAsync`のときも)、今の戦闘に戻ったとき(自動で戻ったときも)、新しい戦闘を映し始めたとき、映していた前の戦闘をやめたときです。同じ履歴を開き直しても来ます。前の戦闘を映している間に新しい戦闘を作ったときと、履歴を開けなかったときは来ません

### 戦闘の読み口(`GetShownEncounter`・`GetLiveEncounter`)

- `GetShownEncounter`は`GetEncounter`と同じ戦闘を、`GetLiveEncounter`は今の戦闘を、読み口(`IPluginEncounterRecord`)で返します。戦闘がまだ無ければ`null`です
- `GetLiveEncounter`は、集計の履歴を開いている間と、前の戦闘を映している間も、今の戦闘を返します
- 読み口は、作られたときの戦闘を読み続けます。アプリが次の戦闘に移った後も、同じ戦闘を読みます
- 読み口を持っている間は、その戦闘がメモリに残ります。必要な間のみ持ちます
- どのスレッドから呼んでもかまいません。今の戦闘の値は呼ぶたびにその時の値を読むので、2つを続けて呼ぶと、別の瞬間の値になることがあります。履歴から読んだ戦闘は、プラグインの値を除いて変わりません
- 保存した戦闘も、同じ読み口で読めます([プラグイン開発(履歴)](プラグイン開発(履歴))の`LoadAsync`)

### 戦闘の値(`Info`)

| `AutoPauseSeconds` | アプリが戦闘を作ったときの、全体設定の「自動一時停止」の秒数。戦闘の時計は、最後の戦闘のできごとからこの秒数で止まります。止めない設定のとき・計測の戦闘・ダンジョンの時計の戦闘では0 |

- 今の戦闘では、チャンネル・難易度・`IsWipe`が変わることがあるので、要るときに`Info`を読み直します

### 戦闘の経過時間(`ToCombatOffset`)

- 時刻を、アプリのグラフとタイムラインの横軸と同じ、戦闘の経過時間に直します。`StartUtc`からの時間から、それより前の止まっていた間(自動一時停止と、ダンジョンの時計の戦闘ではゲームのダンジョンの時計が止まっていた間)を除いたものです
- 止まっている間の時刻は、止まった時点の経過時間になります
- 戦闘の時計が動き出す前は`null`、`StartUtc`より前の時刻は負の値です
- UTCの時刻を渡します。`DateTime.Kind`を見て変換することはしません
- 今の戦闘では、最後の戦闘のできごとより後の時刻の値は、戦闘が続くと変わることがあります

### 記録の決まり

アプリが戦闘に記録するものの決まりです。集計と、`GetMonsters`の詠唱は、この決まりで記録したものです。

- `IsAggregationStopped`が`true`の戦闘では、何も記録しません
- 回復・ヘイト・ブレイクは、最初の戦闘のできごとの後(`FirstCombatEventUtc`から)のみ記録します
- 計測の戦闘(`Info.BenchmarkSeconds`が0より大きい)では、`StartUtc`から計測時間がたつまでのできごとのみを記録します。その中でも、自分のできごとと、どのプレイヤーのものでもないできごと(敵の詠唱・ボスのスキルの予告・敵の行動)のみです
- `Info.BenchmarkFirstTargetOnly`が`true`のときは、ダメージ・ヘイト・ブレイクは、自分が最初にダメージを与えた敵(`BenchmarkFirstTargetEntityUuid`)へのもののみを数えます。その敵が決まる前のヘイトとブレイクは数えません

### 保存した戦闘のプレイヤー(`GetPlayers`)

- 履歴から読んだ戦闘(`IsHistory`が`true`)でのみ返し、今の戦闘では`null`です。今の戦闘のプレイヤーは`Players`で読みます
- 入るのは、その戦闘に与ダメ・回復・ヘイト・ブレイク・被ダメのどれかか、タイムラインの記録がある人です。並びは決まっていません
- 行は`Players`と同じ`PluginPlayer`(上の「プレイヤー」)です。値は戦闘と一緒に保存したもの(保存したときにアプリが表示していた値)のみで、今のパーティやアプリが今持っている値は使わないので、`Players`の同じ人の行と違うことがあります
- `IsFromRecord`は`true`、`CurrentHp`は`MaxHp`と同じ、`CurrentShield`は0、`PartyNumber`は`null`、`IsPartyMember`・`IsNearby`・`IsInCombat`・`IsIncapacitated`は`false`です
- `IsSelf`は呼んだときにログインしているキャラです。名前は、呼んだときの全体設定の「プレイヤー名」に従います

### 戦闘のモンスター(`GetMonsters`)

- 今の戦闘では、周りのモンスターと、周りから外れたモンスターのうち、ボスか「[タイムライン](タイムライン)」か「[被ダメログ](被ダメログ)」に載るものです。呼ぶたびにその時の値を読みます
- 履歴から読んだ戦闘では、戦闘と一緒に保存したモンスターです。保存されるのは、詠唱の記録があるもの、タイムラインの敵の行動に載るもの、プレイヤーにダメージを与えたものです。記録の無いボスは保存されません
- 並びは決まっていません

| `PluginRecordedMonster`のプロパティ | 中身 |
|---|---|
| `EntityUuid` | エンティティのUUID。周りにいる間は、`Entities`の`EntityUuid`と同じです |
| `MonsterId` | モンスターの番号(`Names.GetMonsterName`に渡す)。受信していなければ`null` |
| `Hp`・`MaxHp` | 最後に受信したHPと最大HP。履歴から読んだ戦闘では、保存したときの値です。受信していなければ0 |
| `Casts` | そのモンスターの詠唱(`PluginRecordedCast`)を、受信した順に。詠唱時間のあるスキルと、戦闘の画面に警告が表示されるスキルです |

- `PluginRecordedCast`は、スキルの番号(`SkillId`、`Names.GetSkillName`に渡す)・始まりを受信した時刻(`StartedAtUtc`、UTC)・警告が表示されるスキルか(`IsWarning`)です
- 自分の名前を持たない、召喚されたエンティティの詠唱は、召喚したモンスターの詠唱として記録します
- 詠唱は、上の「記録の決まり」で記録しているときのみ記録します

### バフの区間(`GetPlayerBuffIntervals`)

- 「[バフ稼働率](バフ稼働率)」のためにアプリが記録している区間です。バフリストに表示されるバフ(デバフは除く)で、プレイヤーのみです。計測の戦闘では自分のみで、`IsAggregationStopped`が`true`の戦闘では何も記録しません
- その人の記録が無いときと、戦闘の時計が動き出す前は`null`です
- 時刻は、`StartUtc`から戦闘の時計の終わりまでの間です。戦闘の時計が動き出す前から付いていたバフは、`StartUtc`から始まります。今の戦闘では、付いたままのバフは今の戦闘の時計の終わりまで伸びます
- 外れたことを受信しなかったバフは、効果時間が切れた時刻で終わります
- グラフの横軸に合わせるときは、`ToCombatOffset`で戦闘の経過時間に直します

| プロパティ | 中身 |
|---|---|
| `Buffs` | バフの番号ごとの区間(`PluginBuffInterval`)。その戦闘で最初に付いた順です |
| `PresentIntervals` | その人の値を受信していた(周りにいた)区間。古い順です。この区間の外のバフは取得できません。周りから外れると、付いていたバフの区間もそこで終わります |
| `PluginBuffInterval.BuffId` | バフの番号(`Names.GetBuffName`に渡す)。受信した番号のままで、「バフ稼働率」で1行にまとめるバフもまとめません |
| `PluginBuffInterval.IsPermanent` | 最後の区間が始まったとき(付いていない状態から付いたとき)のバフに、効果時間が無かった(常駐バフ) |
| `PluginBuffInterval.Intervals` | バフが1つ以上付いていた区間。古い順で、重なりません |

- 区間(`PluginTimeInterval`)は、始まり(`StartUtc`)と終わり(`EndUtc`)のUTCの時刻です

### 戦闘の記録(`GetSkillActivations`・`GetTakenHits`・`GetCombatLog`)

- アプリが戦闘に記録したものを、記録した順(古い順)に、`startIndex`番目から後を返します。前に読んだ数を`startIndex`に渡すと、増えた分のみを読めます
- `startIndex`が負か、呼んだときの記録の数より大きいと`ArgumentOutOfRangeException`です。`GetSkillActivations`の数は人ごとです
- 上の「記録の決まり」で記録したものです。`GetSkillActivations`には、戦闘の時計が動き出す前のものも入ります
- 履歴から読んだ戦闘でも、同じように読めます
- 時刻(`ArrivalTimeUtc`)は受信した時刻(UTC)です。予告の終わりの記録は、予告のバーが終わった時刻です。グラフの横軸に合わせるときは`ToCombatOffset`で直します
- 被ダメの記録とタイムラインの記録は、共通の通し番号(`Sequence`)を持ちます。2つを合わせて並べるときは、この番号の順に並べます

| メソッド | 1件の中身 |
|---|---|
| `GetSkillActivations` | `PluginSkillActivation`: スキルの番号(`SkillId`)・アイコンの枠(`Frame`)・受信した時刻。自分はゲームがスキルを受け付けたとき、他のプレイヤーはスキルを使い始めたときに記録します。名前は`Names.GetSkillActivationName`で引きます |
| `GetTakenHits` | `PluginTakenHit`: 被ダメを受けたプレイヤー(`CharacterId`)・ダメージを与えたエンティティ(`Attacker`)・ダメージの元(`Source`と`SourceId`)・値・属性・タイプ・戦闘不能になったか(`IsLethal`)。値が0の被ダメは入りません。自分のスキル・落下・プレイヤーからの被ダメも入ります |
| `GetCombatLog` | `PluginCombatLogRecord`から派生した型: 敵の詠唱(`PluginCastRecord`)・ボスのスキルの予告と予告の終わり(`PluginAnnouncementRecord`)・ダメージの無い戦闘不能(`PluginPlayerDeathRecord`)・敵の回復(`PluginEnemyHealRecord`)・敵から敵へのダメージ(`PluginEnemyDamageRecord`)・敵が付けたバフ(`PluginEnemyBuffRecord`) |

- `Frame`は、「[DPS推移グラフ](DPS推移グラフ)」などでスキルのアイコンの後ろに表示する枠です(`Imagine`: イマジン、`Ultimate`: 究極スキルで、どちらもそこから派生するスキルを含みます。`Standard`: その他のスキル)
- 記録に含まれるエンティティ(`PluginCombatParty`)は、UUID(`EntityUuid`)・種類(`Kind`: `Player`・`Monster`・`System`・`Other`)・プレイヤーならキャラ番号(`CharacterId`)・モンスターならモンスターの番号(`MonsterId`、受信していなければ`null`)です。`System`は、タイムラインで「システム」と表示する、プレイヤーでもモンスターでもないゲームの仕掛けです
- 召喚されたエンティティの行動は、判別できるときは、召喚したプレイヤーかモンスターの行動として記録します(「タイムライン」と同じ)
- ダメージの元(`Source`)はスキル・弾・バフ・落下などで、`SourceId`はその番号です。バフや召喚されたエンティティのダメージでは、元のスキル(`BuffSourceSkillId`・`SummonSourceSkillId`)も入ります

### 1秒ごとの合計(`GetPerSecondTotals`)

- その人の与ダメ(`Damage`)か回復(`Healing`)の、戦闘の時計の1秒ごとの合計です。「[DPS推移グラフ](DPS推移グラフ)」「[HPS推移グラフ](HPS推移グラフ)」と同じ値です
- `Totals[i]`は、戦闘の経過時間のi秒からi+1秒まで(i+1秒を含む)の合計です。遅れて受信したダメージも、その時刻の秒に入ります
- 今の戦闘では、満ちた秒のみが入ります。閉じた戦闘(`IsClosed`)では、最後の1秒未満の分も入ります。`Elapsed`は読んだときの戦闘の経過時間です
- その人が戦闘にいないときと、戦闘の時計が動き出す前は`null`です
- 呼ぶたびにすべての秒を数え直します。変わったときのイベントは無いので、決まった間隔で読み直します

### 自分のモジュール(`SelfModules`)

- `Modules`は所持モジュール(`PluginModuleItem`: `Uuid`・アイテムの番号の`ConfigId`・`Quality`・効果の`Effects`)、`EquippedUuidBySlot`は装着中の枠の番号とモジュールの`Uuid`です
- 効果(`PluginModuleEffect`)は、効果の番号(`EffectId`)とリンク数(`LinkCount`、受信していなければ`null`)です
- マップに入るたびに、中身が同じでも`SelfModulesChanged`が来ます
- ログアウトの後と、全体設定の「ネットワークアダプター」「ゲーム実行ファイル」を変えた後は、次にマップを移動するまで`null`です

### 集計の設定(`AggregationSettings`)

- 全体設定の「集計設定」の値で、使う人の設定のままです。全体設定で保存して値が変わると、`AggregationSettingsChanged`が来ます

| `PluginAggregationSettings`のプロパティ | 全体設定の項目 |
|---|---|

| `AutoPauseSeconds` | 自動一時停止の秒数。止めないときは0。変えた後に作った戦闘から効きます(戦闘ごとの値は`Info.AutoPauseSeconds`) |

| `BenchmarkSeconds` | 計測時間(秒)。次の計測から効きます(計測の戦闘の値は`Info.BenchmarkSeconds`) |

## ゲームのメッセージ(`Packets`)

`ReadAsync`に受ける種類を渡し、受信したメッセージを`await foreach`で読みます。

```csharp
private static async Task ReadMessagesAsync(IPluginContext context, IReadOnlyCollection<PluginPacketType> types)
{
    await foreach (PluginPacketMessage message in context.Packets.ReadAsync(types).ConfigureAwait(false))
    {
        context.Logger.Info($"{message.Kind} {message.ServiceId}/{message.MethodId}: {message.Payload.Length} bytes");
    }
}
```

- `Initialize`の中で`_ = ReadMessagesAsync(context, types);`のように、待たずに始めます
- 受ける種類(`PluginPacketType`)は、種類(`Kind`)・サービスの番号・メソッドの番号の組で、1つ以上渡します。3つとも一致したメッセージのみを受信します
- 種類は、サーバーからの通知(`Notify`)・ゲームからサーバーへの呼び出し(`Call`)・呼び出しへの応答(`Return`)です。`Return`の番号は、答えている呼び出しの番号です
- `await foreach`を始めたときから受信したメッセージを、受信した順に渡します。前のものは渡しません。繰り返しを抜けると、受けるのをやめます
- 中身(`Payload`)はprotobufのバイト列です。`Notify`と`Return`は解凍した後で、`Return`は応答を包んだ形のままです。`Call`は解凍していません
- `Payload`はアプリが写したものなので、いつまで持っていてもかまいません
- まだ取っていない中身の合計が、下の「戦闘のできごと」と合わせて、プラグイン1つにつき64MBを超えると、プラグインが止まり、「[プラグイン](プラグイン)」の行が「エラー」になります(「プラグインエラー」のウィンドウが表示され、次の起動で再度読み込みます)。受ける種類を絞り、受信したものはすぐ取ります
- `Initialize`はUIスレッドで呼ばれるので、`ConfigureAwait(false)`を付けないと、繰り返しの中身がUIスレッドで動きます
- アプリがプラグインを止めると、繰り返しは終わります。`Stopping`を渡していなければ例外なしで、渡していれば`OperationCanceledException`で終わります
- ゲームのメッセージの番号と中身の形は、このWikiでは説明しません

## 戦闘のできごと(`CombatEvents`)

`ReadAsync`に受ける種類を渡し、アプリが処理した戦闘のできごとを`await foreach`で読みます。

```csharp
private static async Task ReadCombatEventsAsync(IPluginContext context)
{
    PluginCombatEventKinds kinds = PluginCombatEventKinds.SkillActivation | PluginCombatEventKinds.MonsterHpZero;
    await foreach (PluginCombatEvent combatEvent in context.CombatEvents.ReadAsync(kinds).ConfigureAwait(false))
    {
        if (combatEvent is PluginSkillActivationEvent activation)
        {
            context.Logger.Info($"{activation.CharacterId}: {context.Names.GetSkillActivationName(activation.Record.SkillId)}");
        }
        else if (combatEvent is PluginMonsterHpZeroEvent { IsZero: true, MonsterId: { } monsterId })
        {
            context.Logger.Info($"{context.Names.GetMonsterName(monsterId)}: 0 HP");
        }
    }
}
```

| 種類 | 型 | 来るとき |
|---|---|---|
| `Damage` | `PluginDamageEvent` | プレイヤーと、プレイヤーが召喚したエンティティが敵にダメージを与え、アプリが「[DPSメーター](DPSメーター)」に足したとき |
| `SkillActivation` | `PluginSkillActivationEvent` | スキルの記録を足したとき(`GetSkillActivations`と同じ記録) |
| `TakenHit` | `PluginTakenHitEvent` | 被ダメの記録を足したとき(`GetTakenHits`と同じ記録) |
| `CombatLog` | `PluginCombatLogEvent` | タイムラインの記録を足したとき(`GetCombatLog`と同じ記録) |
| `PlayerBuff` | `PluginBuffEvent` | プレイヤーのバフの付与・変化・除去を受信したとき |
| `MonsterBuff` | `PluginBuffEvent` | モンスターのバフの付与・変化・除去を受信したとき |
| `MonsterSkill` | `PluginMonsterSkillEvent` | モンスターが使っているスキルを受信したとき(使い始めと、使い終わり) |
| `MonsterHpZero` | `PluginMonsterHpZeroEvent` | モンスターのHPが0になったとき、0から戻ったとき |

- `Initialize`の中で`_ = ReadCombatEventsAsync(context);`のように、待たずに始めます。`ConfigureAwait(false)`と、アプリがプラグインを止めたときの終わり方は「ゲームのメッセージ」と同じです
- 種類は`|`で組み合わせて、1つ以上渡します。`None`か、定義に無い値を含むと`ArgumentException`です
- `await foreach`を始めたときからのできごとを、アプリが処理した順に渡します。前のものは渡しません
- 時刻(`ArrivalTimeUtc`)は、そのできごとを運んだメッセージを受信した時刻(UTC)です。予告の終わりの記録は、予告のバーが終わった時刻です
- `SequenceNumber`は、ゲームのメッセージ(`Packets`)と共通の通し番号です。メッセージから起きたできごとは、そのメッセージより後の番号です
- 記録の種類(`SkillActivation`・`TakenHit`・`CombatLog`)は、記録した戦闘の`EncounterKey`と記録の番号(`RecordIndex`)を持ちます。`GetLiveEncounter()`の`EncounterKey`が同じなら、`RecordIndex + 1`を`startIndex`に渡して続きを読めます
- `Damage`は、上の「記録の決まり」で記録したもののみ来ます。他の種類の`IsRecorded`は、そのときのアプリの今の戦闘が、記録の決まりで記録しているかです
- `PluginDamageEvent`の`RowKey`は、`GetSkillTotals`の行(`PluginSkillTotals.RowKey`)と同じです。`IsImmune`のダメージは、メーターに足しません
- `PluginBuffEvent`の`Kind`は、付与(`Added`)・層か効果時間の変化(`Changed`)・除去(`Removed`)・その時点で付いていたバフ(`Present`)・その一覧の終わり(`AppearListEnd`)です
  - `Present`は、周りに入ったエンティティのバフの一覧と、マップを移動した後にゲームが自分のバフをすべて付け直したときに来ます。続けて`AppearListEnd`が1件来ます。それまで付いていて一覧に無いバフは、見ていない間に外れたものです。ゲームが一覧を送らない出現では、どちらも来ません
  - `Changed`と`Removed`のバフの番号・付与者・付与元(`SourceType`・`SourceConfigId`)は、付与を受信したときの値です。付与を受信していないバフ(マップに入る前から付いていたものなど)では、番号は0です
  - 受信したメッセージが運ばなかった値(`Level`・`Layer`・`DurationMilliseconds`・`ServerCreateTimeUtc`)は`null`です
- `PluginMonsterSkillEvent`は、使い終わったときに`SkillId`が0で来ます。同じスキルをもう一度受信したときも来ます。周りに入ったときに使っていたスキルは来ません
- `PluginMonsterHpZeroEvent`は、最大HPが0のエンティティ(HPバーの無い仕掛けなど)でも来ます。周りに入ったときにHPが0だったモンスターは、`IsOnAppear`が`true`で来ます
- ダンジョンの結果と投票の画面の間は、アプリがバフ・ダメージ・回復を処理しないので、`Damage`・`TakenHit`・`PlayerBuff`・`MonsterBuff`と、`CombatLog`の敵の回復・敵から敵へのダメージ・敵が付けたバフは来ません
- まだ取っていないできごとは、ゲームのメッセージと合わせて、プラグイン1つにつき64MBを超えるとプラグインが止まります(上の「ゲームのメッセージ」と同じ)。受ける種類を絞り、受信したものはすぐ取ります
- 渡す値は書き換えられない写しで、すべてのプラグインに同じものを渡しています

## データを読むときの決まり

- ウィンドウの中身・ウィジェットの本体とフッターで付けたイベントは、`Dispose`で外します。外さないと、閉じたウィンドウの中身がイベントを受け続け、メモリにも残ります
- `Initialize`で付けたイベントは`Shutdown`で外します。アプリも`Shutdown`の前に外すので、止まった後に処理が呼ばれることはありません
- バフ・戦闘の集計・`GetPlayer`・`GetPlayerBuild`には変わったときのイベントが無いので、タイマーで読み直します。バフが付いた・外れた瞬間は`CombatEvents`で受けられます

## 渡していないもの

- 装備の詳しい値・能力値・スキルの枠・クールタイム・ダンジョンの目標と得点・チャットなどは渡していません。要るときは、ゲームのメッセージを読みます。装備の部位と番号・アビリティ・スキルのレベルは`GetPlayerBuild`、敵の詠唱と戦闘の画面に警告が表示されるスキルは戦闘の読み口の`GetMonsters`、ボスのスキルの予告は`GetCombatLog`で読めます
