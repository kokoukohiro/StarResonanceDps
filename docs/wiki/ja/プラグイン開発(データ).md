プラグインでゲームのデータを読むための説明です。どのプラグインにも要ることは、[プラグイン開発](プラグイン開発)にあります。

| `IPluginContext`のメンバー | 中身 |
|---|---|
| `GameData`(`IPluginGameDataService`) | アプリが通信から作った値(接続とマップ・プレイヤー・周りの敵・バフ・戦闘の集計・自分のモジュール)と、変わったときのイベント |
| `Names`(`IPluginNameService`) | スキル・バフ・モンスター・クラス・マップ・アイテムの番号から名前を引く |
| `Packets`(`IPluginPacketService`) | ゲームのメッセージそのもの |

## ゲームのデータ(`GameData`)

次の例は、戦闘が終わったときに、全員の与ダメの合計をログに書きます。

```csharp
using StarResonanceDps.PluginSdk;

[assembly: PluginRegistration(typeof(MyPlugin.Plugin), PluginSdkVersion.Current)]
[assembly: PluginDisplayName("ja-JP", "私のプラグイン")]
[assembly: PluginAuthor("YourName")]
[assembly: PluginVersion("1.0.0")]

namespace MyPlugin;

public sealed class Plugin : IStarResonancePlugin
{
    private IPluginContext? _context;

    public void Initialize(IPluginContext context)
    {
        _context = context;
        context.GameData.EncounterClosed += OnEncounterClosed;
    }

    private void OnEncounterClosed(object? sender, PluginEncounterResult result)
    {
        foreach (PluginEncounterPlayer player in result.Totals.Players)
        {
            _context?.Logger.Info($"{player.CharacterId}: {player.Damage.Total}");
        }
    }

    public void Shutdown()
    {
        if (_context is not null)
        {
            _context.GameData.EncounterClosed -= OnEncounterClosed;
        }
    }
}
```

| メンバー | 中身 | 変わったときのイベント |
|---|---|---|
| `CurrentServer` | 今読んでいるゲームのサーバー(`PluginGameServer`の`Asia`・`China`・`Global`・`SoutheastAsia`)。分からなければ`Unknown` | なし |
| `Session` | 接続とマップの状態(`PluginSessionState`) | `SessionChanged` |
| `Players` | プレイヤーの一覧(`PluginPlayer`) | `PlayersChanged` |
| `Entities` | 周りのモンスターの一覧(`PluginEntity`) | `EntitiesChanged` |
| `SelfModules` | 自分の所持モジュールと装着中の枠(`PluginModuleInventory`)。まだ届いていなければ`null` | `SelfModulesChanged` |
| `GetPlayerBuffs(characterId)` | その人に今付いているバフとデバフ(`PluginBuff`) | なし(読み直す) |
| `GetEntityBuffs(entityUuid)` | そのエンティティに今付いているバフとデバフ | なし(読み直す) |
| `GetEncounter()` | 「[DPSメーター](DPSメーター)」が映している戦闘の、全員の集計(`PluginEncounterSnapshot`) | なし(読み直す) |
| `GetSkillTotals(characterId, kind)` | 同じ戦闘の、その人のスキルごとの内訳(`PluginSkillTotals`)。`kind`は与ダメ(`Damage`)か回復(`Healing`) | なし(読み直す) |

| イベント | 来るとき |
|---|---|
| `EncounterStarted` | アプリが新しい戦闘を作ったとき |
| `EncounterClosed` | 記録のある戦闘を閉じたとき。閉じた戦闘の集計と、全員のスキルごとの内訳(`PluginEncounterResult`)が渡ります |
| `MapEntered` | 別のマップかチャンネルへ移ったとき |
| `LoggedOut` | ゲームがログイン画面へ戻ったとき |

- 値はどのスレッドから読んでもかまいません。イベントは全部UIスレッドで来ます
- `SessionChanged`・`PlayersChanged`・`EntitiesChanged`・`SelfModulesChanged`は、短い間の変化を1回にまとめ、来たときの値で知らせます。ほかの4つは、起きるたびに来ます
- 値は書き換えられない写しで、後から新しくなりません。新しい値は読み直します。2つの値を続けて読むと、別の瞬間の値になることがあります
- `Players`・`Entities`・`SelfModules`と`EncounterClosed`の結果は、全部のプラグインに同じものを渡しています。`IReadOnlyList`などを元の型に変えて書き換えないでください
- イベントの処理は、アプリの画面と同じUIスレッドで動きます。重い処理をすると、ウィジェットも止まります
- イベントの処理で例外を出すと、プラグインが止まります

### 接続とマップ(`Session`)

| プロパティ | 中身 |
|---|---|
| `SelfCharacterId` | 自分のキャラID。分かるまでと、ログアウトの後は`null` |
| `SceneId` | 今のマップの番号。`Names.GetSceneName`に渡します |
| `SeasonId` | 今のシーズンの番号 |
| `DungeonState` | ダンジョンの外(`NotInDungeon`)・中(`InDungeon`)・終わった後(`Finished`) |
| `IsMidLaunch` | ゲームの通信を途中から読み始め、まだ自分の情報がそろっていない(ゲームの途中でアプリを起動したときなど)。マップを移動すると`false`になります |

- ゲームの途中でアプリを起動したときは、自分のキャラIDや所持モジュールが、マップを移動するまで分からないことがあります

### プレイヤー(`Players`)

- 入るのは、自分・パーティのメンバー・周りのプレイヤーと、DPSメーターが映している戦闘に記録がある人です。「[プレイヤーリスト](プレイヤーリスト)」の元の一覧で、プレイヤーリストのフィルターと名前順の並べ替えは当てません
- 並びは、自分、パーティのメンバー(PT番号の順)、周りにもパーティにもいない人、戦闘中の人、そのほかの人の順です
- 名前は、全体設定の「プレイヤー名」に従います。非表示の人は`*****`です。分からないときは空のこともあります

| プロパティ | 中身 |
|---|---|
| `CharacterId` | キャラID。名前を伏せていても本当の値です |
| `Name` | 名前 |
| `ProfessionId` | 職業の番号。分からなければ0 |
| `SpecState`・`SpecId` | クラスの状態(`Unknown`・`NotEquipped`(クラスR1)・`Specialized`・`Transformation`(変身))。`Specialized`のときだけ`SpecId`に番号が入ります(`Names.GetClassSpecName`に渡す) |
| `Level`・`AbilityScore`・`SeasonStrength` | レベル・能力スコア・シーズン強度。分からなければ0 |
| `CurrentHp`・`MaxHp`・`CurrentShield` | HPとバリアの量。バリアは自分と周りにいる人だけです |
| `PartyNumber` | パーティの番号。パーティの外なら`null` |
| `IsSelf`・`IsNpc`・`IsPartyMember`・`IsNearby` | 自分か・助っ人か・パーティのメンバーか・周りにいるか |
| `IsInCombat`・`IsIncapacitated` | 戦闘状態・戦闘不能。戦闘状態が分かるのは自分と周りにいる人だけです |
| `PsychoscopeRootBuffId`・`IsPsychoscopeInactive` | 潜在心相晶の型(ルートバフの番号)と、無効か |
| `IsFromRecord` | 開いている集計の履歴にだけいる人 |

### 周りの敵(`Entities`)

- 周りにいる、種類がモンスターのものだけが入ります。「[エンティティリスト](エンティティリスト)」の元の一覧で、エンティティリストのフィルターと名前順の並べ替えは当てません
- 並びは、戦闘状態のもの、それ以外の順で、それぞれの中はボス・精鋭・普通・その他の順です

| プロパティ | 中身 |
|---|---|
| `EntityUuid` | エンティティのUUID。`GetEntityBuffs`に渡します |
| `MonsterId` | モンスターの番号(`Names.GetMonsterName`に渡す)。アプリの起動より前から周りにいたモンスターは、一度周りから外れてまた出てくるまで`null`です |
| `CurrentHp`・`MaxHp` | HP |
| `IsInCombat` | 戦闘状態 |
| `Cast` | 詠唱しているスキル(`SkillId`・`StartedAtUtc`・`TotalSeconds`)。詠唱時間のあるスキルを始めたときに入り、次にスキルが変わるまで残ります。`TotalSeconds`を過ぎても残ることがあるので、終わりは時刻で決めます |
| `TargetCharacterId` | 狙っているプレイヤーのキャラID。ヘイトの1位とは限りません |
| `HateRanking` | ヘイトの一覧(プレイヤーだけ、値の大きい順) |

### バフ(`GetPlayerBuffs`・`GetEntityBuffs`)

- 今付いているものが全部入ります。「[バフリスト](バフリスト)」のような出すものの絞り込みやまとめは当てません
- 周りにいない人と敵の分は空です。マップを移動すると全部消えます
- 集計の履歴を開いていても、今の値です

| プロパティ | 中身 |
|---|---|
| `BuffUuid` | バフ1つずつのUUID |
| `BuffId` | バフの番号(`Names.GetBuffName`に渡す) |
| `Level`・`Layer` | レベルと層(スタック数) |
| `DurationSeconds` | 効果時間の総量(延長で伸びます)。持続が無ければ`null` |
| `EndUtc` | 切れる時刻(UTC)。持続が無いか、残りが分からなければ`null` |
| `IsRemainingUnknown` | 残りの時間が分からない |
| `CasterEntityUuid`・`CasterCharacterId` | 付けたエンティティのUUID(分からなければ0)と、付けたのがプレイヤーならそのキャラID |

### 戦闘の集計(`GetEncounter`・`GetSkillTotals`)

- 読むのはDPSメーターが映している戦闘です。集計の履歴を開いていればその戦闘、全体設定の「次のイベントまで結果を保持」で前の戦闘を映していれば、その戦闘です

| `PluginEncounterSnapshot`のプロパティ | 中身 |
|---|---|
| `IsHistory` | 集計の履歴を開いている |
| `StartUtc` | 戦闘の時計が動き出した時刻(UTC)。まだなら`null` |
| `Elapsed` | 戦闘の経過時間(自動一時停止の間を除く) |
| `IsClosed` | 戦闘が終わった |
| `Players` | 与ダメ・回復・被ダメのどれかがあるプレイヤー(`PluginEncounterPlayer`)。パーティで絞らず、並びは決まっていません |

- `PluginEncounterPlayer`は、`CharacterId`と、与ダメ(`Damage`)・回復(`Healing`)・被ダメ(`DamageTaken`)の合計(`PluginCombatTotals`)を持ちます
- `PluginCombatTotals`は、合計(`Total`)・秒間値(`PerSecond`、DPSメーターと同じ)・その人の有効な時間での秒間値(`ActivePerSecond`、スキル詳細と同じ)・ヒット数(`Hits`)・会心と幸運の合計と数です
- `PluginSkillTotals`は、スキル詳細と同じ行で、行のキー(`RowKey`)・行の名前(`Name`、無ければ`null`)・合計・秒間値・ヒット数・会心率(`CritRate`)・その人の合計に占める割合(`Share`)を持ちます。合計の大きい順です
- `EncounterStarted`は、マップの移動・ダンジョンの開始・「進行で自動リセット」の区切り・手動のリセット・計測の開始と停止・ログアウトで来ます。1回のマップ移動で何回か来ることがあります
- 戦闘の時計が動き出したときのイベントはありません。`GetEncounter().StartUtc`を読みます
- `EncounterClosed`は、記録のある戦闘を閉じて次の戦闘を作るときに来ます。アプリを閉じるときの最後の戦闘では来ません。閉じた戦闘の値は、受け取った結果をその場で持っておきます

### 自分のモジュール(`SelfModules`)

- `Modules`は所持モジュール(`PluginModuleItem`: `Uuid`・アイテムの番号の`ConfigId`・`Quality`・効果の`Effects`)、`EquippedUuidBySlot`は装着中の枠の番号とモジュールの`Uuid`です
- 効果(`PluginModuleEffect`)は、効果の番号(`EffectId`)とリンク数(`LinkCount`、届いていなければ`null`)です
- マップに入るたびに、中身が同じでも`SelfModulesChanged`が来ます
- ログアウトの後と、全体設定の「ネットワークアダプター」「ゲーム実行ファイル」を変えた後は、次にマップを移動するまで`null`です

## 名前を引く(`Names`)

| メソッド | 引く名前 |
|---|---|
| `GetSkillName(skillId)` | スキル |
| `GetBuffName(buffId)` | バフ |
| `GetMonsterName(monsterId)` | モンスター |
| `GetClassSpecName(specId)` | クラス(`PluginPlayer.SpecId`) |
| `GetSceneName(sceneId, dungeonDifficulty)` | マップ。難易度の名前があれば「マップ名-難易度名」。`dungeonDifficulty`は省けます |
| `GetItemName(itemId)` | アイテム(装備を含む) |

- 名前はアプリの表示言語の名前です。その言語の名前が無ければ中国語の名前、どちらも無ければ`null`です
- アプリの画面と違い、内部名や内部IDは付けません。全体設定の「内部ID」「名前のないスキルとバフ」も効きません
- クラスR1・変身の名前は無いので、`GetClassSpecName`は`null`です
- 職業・潜在心相晶の型・シーズン・モジュールの効果の名前を引くメソッドはありません
- どのスレッドから呼んでもかまいません。表示言語が変わったら、`Localization.CultureChanged`の中で引き直します

## ゲームのメッセージ(`Packets`)

`ReadAsync`に受ける種類を渡し、届いたメッセージを`await foreach`で読みます。

```csharp
private static async Task ReadMessagesAsync(IPluginContext context, IReadOnlyCollection<PluginPacketType> types)
{
    await foreach (PluginPacketMessage message in context.Packets.ReadAsync(types).ConfigureAwait(false))
    {
        context.Logger.Info($"{message.Kind} {message.ServiceId}/{message.MethodId}: {message.Payload.Length} bytes");
    }
}
```

- `Initialize`の中で`_ = ReadMessagesAsync(context, types);`のように、待たずに始めます
- 受ける種類(`PluginPacketType`)は、種類(`Kind`)・サービスの番号・メソッドの番号の組で、1つ以上渡します。3つとも合ったメッセージだけが届きます
- 種類は、サーバーからの通知(`Notify`)・ゲームからサーバーへの呼び出し(`Call`)・呼び出しへの応答(`Return`)です。`Return`の番号は、答えている呼び出しの番号です
- `await foreach`を始めたときから届いたメッセージを、届いた順に渡します。前のものは渡しません。繰り返しを抜けると、受けるのをやめます
- 中身(`Payload`)はprotobufのバイト列です。`Notify`と`Return`は解凍した後で、`Return`は応答を包んだ形のままです。`Call`は解凍していません
- `Payload`はアプリが写したものなので、いつまで持っていてもかまいません
- まだ取っていない中身の合計が、プラグイン1つにつき64MBを超えると、プラグインが止まり、「[プラグイン](プラグイン)」の行が「エラー」になります(「プラグインエラー」のウィンドウが表示され、次の起動で再度読み込みます)。受ける種類を絞り、届いたものはすぐ取ります
- `Initialize`はUIスレッドで呼ばれるので、`ConfigureAwait(false)`を付けないと、繰り返しの中身がUIスレッドで動きます
- アプリがプラグインを止めると、繰り返しは終わります。`Stopping`を渡していなければ例外なしで、渡していれば`OperationCanceledException`で終わります
- ゲームのメッセージの番号と中身の形は、このWikiでは説明しません

## データを読むときの決まり

- ウィンドウの中身・ウィジェットの本体とフッターで付けたイベントは、`Dispose`で外します。外さないと、閉じたウィンドウの中身がイベントを受け続け、メモリにも残ります
- `Initialize`で付けたイベントは`Shutdown`で外します。アプリも`Shutdown`の前に外すので、止まった後に処理が呼ばれることはありません
- バフと戦闘の集計には変わったときのイベントが無いので、タイマーで読み直します

## 渡していないもの

- 装備・能力値・タレント・スキルの枠・クールタイム・ダンジョンの目標と得点・予兆技・チャットなどは渡していません。要るときは、ゲームのメッセージを読みます
