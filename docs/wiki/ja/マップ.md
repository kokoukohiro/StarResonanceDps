自分のいるマップの地図に、自分と周りのプレイヤー・敵・パーティメンバーの位置を表示するウィジェットです。

## 開き方

- 「[ウィジェット](ウィジェット)」の「マップ」のカードで、起動のボタンを押します。ウィンドウは1枚だけです
- [プレイヤー情報](プレイヤー情報)の現在地に下線があるときは、押すとウィンドウを開いてその人を中心に表示します。ほかのマップにいるパーティメンバーなら、そのマップを表示します
- [チャット](チャット)の位置を共有したリンクを押すと、ウィンドウを開いてその場所に位置のマークを置きます

## 見方

- 地図: 自分のいるマップの地図を、自分を中心にして表示します。マップを移動すると、移動先の地図に替わります。階層のあるマップでは、自分のいる階層の地図を表示します。地図の画像が無いマップでは、アイコンだけを表示します
- プレイヤー: クラスのアイコンで表示します。戦闘中のプレイヤーは、白い縁の小さい円で表示します。自分は、向いている方向を指す白い縁の三角形です(表示設定の「交戦中のプレイヤーを簡略化表示」)。表示設定の「自分を常に簡略化表示」で、自分だけは戦闘中でなくても三角形にできます
- 敵: ボスはボスのアイコン、ほかの敵は縁の無い小さい円で表示します。色はすべてアイコンカラーの「エンティティ」の色です
- 得点: 空間調査で得点を集めているダンジョンでは、戦闘中でない敵の円の上に、その敵の得点(「60pt」など)を表示します。ボスの得点は、アイコンの中央に表示します
- 名前: アイコンの下に表示します。表示する相手は表示設定で選びます。名前を表示しないアイコンも、マウスを乗せると名前がTIPSで表示されます
- フィールドマーク: ダンジョンでリーダーが置いた1〜6のマークを、ゲームと同じ画像で表示します。階層に関係なく表示します
- 位置のマーク: チャットのリンクで共有された場所に表示します
- フッター: 左が表示しているマップの名前(チャンネルがあれば「ch12」の形で付きます)、右が「エンティティ」と「プレイヤー」の数です。数は、表示設定で絞った後の、そのマップにいる相手の数です(ウィンドウの外にいる相手も数えます)。空間調査で得点を集めている間は、「交戦中」(戦闘中の敵の得点の合計)と「現在」(今の得点)になります

![空間調査で得点を集めているとき](images/ja/Map2.png)

## 操作

- ホイール: 地図を拡大・縮小します。いちばん拡大するとウィンドウの短い辺が20m、いちばん縮小すると地図の全体が入ります。開いたときは200mで、拡大の度合いは保存しません
- 地図を掴んで動かすと、表示する場所を変えられます(地図がウィンドウからはみ出している向きだけ)。自分が動くと、自分を中心に戻ります
- アイコンの無い所をダブルクリックすると、すぐに自分を中心に戻ります
- プレイヤーのアイコンを押すと、その人の[プレイヤー情報](プレイヤー情報)を開きます。敵のアイコンを押すと、[ターゲット情報](ターゲット情報)にその敵を表示します
- ほかのマップや、リンクで共有されたほかの階層を表示している間は、ヘッダーに「自分のいるマップに戻る」が表示されます。押すと、自分のいるマップと階層に戻ります
- 右クリックすると、「自分のいるマップに戻る」(ほかのマップや階層を表示している間)と「位置のマークを消す」(位置のマークがあるとき)を選べます
- リンクで共有されたほかのマップや階層を表示している間は、自分が動いても、地図を掴んで動かしても、ダブルクリックしても、その場所を表示したままにします。戻るのは「自分のいるマップに戻る」を押したときと、マップを移動したときです

## 設定

ウィンドウ設定とテーマは[ウィジェットの共通設定](ウィジェットの共通設定)にあります。

### 表示設定

- プレイヤー: 表示するプレイヤーを、すべて表示 / パーティメンバーのみ / パーティメンバー以外 / 自分のみ から選びます(すべて表示)
- エンティティ: すべて表示 / オブジェクト以外 から選びます。オブジェクト以外は、ゲームでHPバーが見えない敵を表示しません(オブジェクト以外)
- プレイヤー名: 名前を表示するプレイヤーを、すべて表示 / パーティメンバーのみ表示 / パーティメンバー以外表示 / 自分のみ表示 から選びます。名前を表示しないプレイヤーはアイコンだけです(すべて表示)
- エンティティ名: 敵の名前を、表示 / 非表示 から選びます(非表示)
- 交戦中の名前非表示: 戦闘中の相手の名前を表示しない対象を、すべて / プレイヤーのみ / エンティティのみ / 非表示しない から選びます(すべて)
- 交戦中のプレイヤーを簡略化表示: 戦闘中のプレイヤーを、白い縁の小さい円(自分は三角形)で表示します。オフにすると、戦闘中もクラスのアイコンです(オン)
- 自分を常に簡略化表示: 自分を、戦闘中でなくても白い縁の三角形で表示します(オフ)
- マップの不透明度: 地図の画像の濃さを0〜100%で選びます。ウィンドウの不透明度に関係なく、この濃さで表示します(100%)

### アイコンカラー

1行目の「エンティティ」は、敵のアイコンと円の色です(既定は2つ目の枠のオレンジ)。続くクラスの行(変身を含む)と「不明」(クラスの判別できないプレイヤー)は、プレイヤーのアイコンと円の色です。

## 注意

- 周りのプレイヤーと敵は、自分の近く(約90m以内)にいる相手だけを表示します
- パーティメンバーは、離れていても同じマップにいれば表示します。戦闘中かどうかは近くにいる間だけ判別できるので、離れているパーティメンバーはいつも戦闘中でない表示です
- フィールドマークは、マークを置いた人が近くにいる間だけ表示します。マップを移動すると消えます
- 位置のマークは、新しいリンクを押したとき、「位置のマークを消す」を選んだとき、ログアウトしたときに消えます。マップを移動しても消えません
- アプリをゲームの途中で起動したときは、自分が動くまで何も表示しないことがあります
- 履歴を開いていても、今の位置を表示します
