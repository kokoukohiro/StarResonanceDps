![バフリスト](images/ja/BuffList1.png)

プレイヤー1人か敵1体に付いているバフを、残り時間とゲージつきで1行ずつ並べるウィジェットです。

## 開き方

- 「[ウィジェット](ウィジェット)」の「バフリスト」のカードで、名前の欄の選択リストから相手を選び、起動のボタンを押します。自分・パーティメンバー・プレイヤーリストに載るほかの人・[エンティティリスト](エンティティリスト)の敵の順に並びます(既定は自分)
- [プレイヤーリスト](プレイヤーリスト)と[蘇生リスト](蘇生リスト)の行を右クリックして、「バフリスト」を選んでも開けます
- [エンティティリスト](エンティティリスト)の行を右クリックして「バフリスト」を選ぶと、その敵のウィンドウが開きます。[エンティティ情報](エンティティ情報)のバフの枠を押しても開きます
- 相手ごとにウィンドウを開きます。同じ相手のウィンドウが開いていれば、そのウィンドウを前に出します

## 見方

- タイトル: 「バフリスト - 相手の名前」です
- 行: 左から、バフのアイコン・名前(表示設定の「バフ名」)・残り時間です。重なっている数が2以上のときは、アイコンに数を重ねます。アイコンのファイルが無いバフは、はてなになります
- 残り時間: 「12秒」の形で、秒は切り上げです。残りの分からないバフは「??秒」で、効果時間の無いバフは何も出しません
- ゲージ: 残りが表示設定の「ゲージの長さ」より長い間は満タンで、それより短くなると残りに合わせて縮みます。残りの分からないバフと効果時間の無いバフは、ずっと満タンです
- 名前: 料理と薬剤は、そのバフを付ける料理・薬剤の名前です。本人以外のプレイヤーが付けたバフには、名前の後ろに付けた人の名前が付きます(召喚物が付けたものは、召喚した人の名前)
- 出るバフ: ゲームの画面のバフの欄に出るものに、アプリで足したもの(装備効果・因子の効果など)を加えたものです。アビリティ・潜在心相晶・モジュールのように常に効いている効果は、[アビリティ情報](アビリティ情報)・[潜在心相晶情報](潜在心相晶情報)・[モジュール情報](モジュール情報)で見ます
- 並び: 優先表示リストでオンのバフが先頭(リストの順)で、残りは付いた順(新しいものが下)です

## 操作

- 行を押すと、そのバフの[バフ・デバフカード](バフ・デバフカード)を開きます。料理と薬剤の行は、料理・薬剤のカードを開きます
- 行を右クリックすると、次の項目を選べます
  - 「バフカード」: 行を押したときと同じです
  - 「このバフを優先表示」: 優先表示リストに足します。優先表示中は「このバフの優先表示をやめる」になります
  - 「このバフを非表示」: 非表示リストに足します
  - 「グループに追加」: [バフ・デバフグループ](バフ・デバフグループ)に足します。自分のウィンドウだけで、グループにまだ入っていないバフに出ます
  - 「バフ・デバフカードのショートカットに追加」: バフ・デバフカードのショートカットに足します。出る条件は「グループに追加」と同じです
- 右クリックで変えた内容は、その場で保存されます
- 行がウィンドウに入りきらないときは、ホイールか右のスクロールバーで動かします

## 設定

ウィンドウ設定とテーマは[ウィジェットの共通設定](ウィジェットの共通設定)にあります。

### 表示設定

- バフ名: 行の名前に出す内容を書きます。選択リストで項目を選んで「挿入」を押すと、その文字が入ります(`{BuffName}({CasterName})`)

| 項目 | 文字 | 出る内容 |
|---|---|---|
| バフ名 | `{BuffName}` | バフの名前 |
| 対象者名 | `{TargetName}` | ウィンドウの相手の名前 |
| 付与者プレイヤー名 | `{CasterName}` | バフを付けたプレイヤーの名前。プレイヤー以外が付けたときと、下の「付与者プレイヤー名の表示」で出さないときは空 |
| レベル | `{Level}` | ウィンドウの相手のレベルの数値 |

- ゲージの長さ: 自動 / 10秒 / 20秒 / 30秒 から選びます。自動は、そのバフの効果時間です。延長すると、残り時間と一緒に伸びます(10秒)
- 同種バフの表示: 同じバフを何人ものプレイヤーが付けているときに、1行にまとめるかを選びます。まとめない / プレイヤーのみまとめる / エンティティのみまとめる / すべてまとめる で、「プレイヤーのみ」はプレイヤーのウィンドウだけ、「エンティティのみ」は敵のウィンドウだけをまとめます。まとめた行は、残り時間の一番長いものを出します。まとめない行は、付けたプレイヤーごとに1行です(プレイヤーのみまとめる)
- 付与者プレイヤー名の表示: 表示 / 非表示 / 他者付与のみ から選びます。他者付与のみは、本人が付けたバフに名前を付けません(他者付与のみ)

値が空になって残った括弧は消えます。

### 優先表示リスト

先頭に出すバフです。スイッチでオン・オフし、行をドラッグで並べ替えます。既定は「リキャスト短縮」「機械の力」「高原血統」で、どれもオフです。行の右クリックの「このバフを優先表示」で足せます。足した行はオフにして保存すると消えます。

### 非表示リスト

出さないバフです。行の右クリックの「このバフを非表示」で足します。スイッチをオフにして保存すると、一覧から消えて、また出るようになります。

### バフカラー

ゲージの左側と右側の色(左から右へ変わります)と、バフカラーの不透明度です(100%)。

## 注意

- ほかのプレイヤーのバフは、その人が周りにいる間だけ出ます。パーティメンバーでも、周りにいなければ空です
- 敵のウィンドウは、開いたときの1体を追います。その敵が倒された・離れたときは空になります
- マップを移動すると一度空になり、ゲームがバフを付け直すと戻ります。ホームガーデンでは、ゲームが料理と薬剤以外のバフを付けません
- アプリを起動する前から周りにいた人と敵のバフは、近づき直すまで足りないことがあります(ウィンドウのタイトルの円が黄)。ゲームの途中でアプリを起動したときは、マップを移動するまで自分のバフが足りないことがあります(円が赤)
- 履歴を開いていても、今のバフを出します
- 1秒ごとに読み直します
