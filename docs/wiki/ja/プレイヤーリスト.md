![プレイヤーリスト](images/ja/PlayerList1.png)

自分・パーティメンバー・周りのプレイヤーを1人1行で並べるウィジェットです。クラス・HP・イマジンとロールスキルの状態が分かります。

## 開き方

「[ウィジェット](ウィジェット)」の「プレイヤーリスト」のカードで、起動のボタンを押します。

## 見方

- 並ぶ人: 自分・パーティメンバー・周りにいるプレイヤー(助っ人のNPCを含む)です。今の戦闘の記録(DPSメーター・HPSメーター・ヘイトメーター・ブレイクメーター・タイムライン・被ダメログ)に出てくる人は、周りにいなくなっても残ります
- 行: 左から、クラスのアイコン・潜在心相晶の型・プレイヤー名とHP・スキルの枠です
  - クラスのアイコン: 下にクラス(雷刃など)が出ます。アビリティを付けていなければ「クラスR1」、分かるまでは「不明」、変身中は変身の名前です
  - 潜在心相晶の型: クラスのアイコンの右下のアイコンです。有効にしていなければ枠だけ、分かるまでははてなです
  - 上の段: PT番号(パーティメンバーだけ)・戦闘状態のアイコン(戦闘中の人だけ)・プレイヤー名です。自分の行は名前が黄色になります(表示設定の「自分の強調表示」)
  - 下の段: HPのバーです。緑がHP、右の明るい灰色がバリアで、数字は「HP+バリア/最大HP」です(表示設定の「HP数値」)。戦闘不能で蘇生できない間は「蘇生不可(秒)」になります
  - スキルの枠: イマジン2つと、ロールスキルです。使った後の待ち時間(秒)と、回数のあるスキルは残りの回数が出ます。右上にそのスキルで付いたデバフ、右下にバフのアイコンと残り秒が出ます
- HPのバーが灰色の行: 周りにもパーティにもいない人です。値は最後に見たときのものです。助っ人のNPCの行も、HPのバーが灰色になります
- 並び: 自分が先頭で、次にほかのパーティメンバーがPT番号の順で並びます。その後に、パーティ外の人が、周りにもパーティにもいない人 → 戦闘中の人 → そのほかの人の順に並びます
- フッター: 左が今いるマップ(チャンネルがあれば「ch12」の形で付きます)、右が「交戦中」と「付近」の人数です。付近は周りにいる人(自分を含む)、交戦中はそのうち戦闘中の人です

## 操作

- 行を押すと、その人の[プレイヤー情報](プレイヤー情報)を開きます
- 行を右クリックすると、その人の「プレイヤー情報」「ステータス詳細」(自分の行だけ)「装備情報」「アビリティ情報」「潜在心相晶情報」「モジュール情報」「バフリスト」「デバフリスト」を選んで開けます
- マウスを乗せると、スキルの枠はスキルの名前、潜在心相晶の型は型の名前、戦闘状態のアイコンは「交戦中」、バフとデバフのアイコンはその名前がTIPSで出ます
- 行がウィンドウに入りきらないときは、ホイールか右のスクロールバーで動かします

## 設定

ウィンドウ設定とテーマは[ウィジェットの共通設定](ウィジェットの共通設定)にあります。

### 表示設定

- プレイヤー名: 名前の欄に出す内容を書きます。選択リストで項目を選んで「挿入」を押すと、その項目の文字が入ります。入力欄の下のプレビューで確かめられます(`{PlayerName}({PowerLevel}-{SeasonStrength})`)

| 項目 | 文字 | 出る内容 |
|---|---|---|
| プレイヤー名 | `{PlayerName}` | 名前。全体設定の「プレイヤー名」で隠すと`*****` |
| クラス | `{Spec}` | クラス(雷刃など)。分かるまでは「不明」、アビリティを付けていなければ「クラスR1」 |
| 潜在心相晶 | `{Psych}` | 潜在心相晶の型。有効にしていなければ「無効」、分かるまでは「不明」 |
| 能力スコア | `{PowerLevel}` | 能力スコアの数値 |
| シーズン強度 | `{SeasonStrength}` | シーズン強度の数値 |
| レベル | `{SeasonLevel}` | シーズンレベルの数値 |
| プレイヤーUID | `{Uid}` | プレイヤーUIDの数値 |

- HP数値: バリア量加算表示(「HP+バリア/最大HP」)/ バリア量個別表示(「HP(バリア)/最大HP」。バリアが無いときは括弧を出しません)(バリア量加算表示)
- フィルター設定: 出す人を、すべて表示 / パーティメンバーのみ / パーティメンバー以外 / 自分のみ から選びます(すべて表示)。パーティメンバーのみは自分を含み、パーティメンバー以外は自分を含みません
- 並び替え: パーティ外の人の並びを、発見順 / 名前順 から選びます(発見順)
- 自分の強調表示: 自分の行の名前を黄色にします(オン)
- 潜在心相晶を表示: 潜在心相晶の型のアイコンを出します。オフにすると、アイコンのために空けた幅もなくなります(オン)
- 戦闘状態: 戦闘状態のアイコンを、表示 / 非表示 / 自分のみ表示 から選びます(表示)

### ロールスキル

ほかのプレイヤーの行に出すロールスキルを、スイッチで選びます。既定でオンなのは、サンダーコール・ヘルスラスト・ライフブレス・復活の祈りです。自分の行には効きません(自分はアクションバーの4枠をそのまま出します)。

### アイコンカラー

クラスのアイコンと潜在心相晶の型のアイコンの色を、クラスごと(変身と不明を含む)・型ごと(不明を含む)に選びます。

## 注意

- ほかのプレイヤーのロールスキルは、装備中のものではなく習得済みのものを出します。装備中のロールスキルはゲームから届かないためです。イマジンは装備中の2つです
- ほかのプレイヤーの待ち時間は、スキルを使ったのを見た時刻からの推定です。自分の待ち時間はゲームの値です
- 戦闘状態とバリアは、自分と周りにいる人の分だけ分かります
- ほかのプレイヤーのクラス・潜在心相晶・スキルの段階は、その人が周りに来たときに分かります。それまでは「不明」で、ウィンドウのタイトルの円が黄になります
- 周りにいないパーティメンバーのHPは、パーティの情報で届くので、遅れて変わることがあります。待ち時間とバフ・デバフのアイコンは出ません
- 5人パーティのPT番号は、パーティに入った順です。20人パーティでゲームの途中でアプリを起動したときは、パーティ画面を開くまでPT番号が「？」になります
- 履歴を開いている間は、その戦闘にいた人が、HPのバーが灰色の行で加わります(HPは最大値)。ほかの行のHP・スキル・バフは今の値のままです
