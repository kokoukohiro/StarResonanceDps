![ウィジェット](images/ja/Widgets1.png)

ゲームの画面に重ねて出す窓(ウィジェット)を、起動・停止したり、ピン留めしたりするタブです。アプリを開くと最初にこの画面が出ます。

## 見方

- 上の段: 左から、検索欄・並べ替え・三点のメニューです
- カード: ウィジェットごとに1枚です。左の円が状態、右のボタンが左から順に、お気に入り・ピン留め・クリック透過・設定・起動/停止です

| 円の色 | 状態 |
|---|---|
| 灰 | 窓が開いていません(停止) |
| 緑 | 窓が開いていて、足りない情報が見つかっていません |
| 黄 | 窓が開いていて、一部の情報が足りません |
| 赤 | 窓が開いていて、マップを移動するかログインし直すまで情報を受け取れません(データを読み込めないときも赤) |

- 窓が2枚以上開いているときは、一番悪い色が出ます。理由は窓のタイトルの左の円で確かめられます([ウィジェットの共通設定](Common-Widget-Settings-ja))
- 相手ごとに窓を開くウィジェット(プレイヤー情報など)は、窓が1枚以上開いていると、円の代わりに開いている窓の数が出ます
- 相手ごとに窓を開くウィジェットは、選べる相手がいるとき、名前の欄が相手を選ぶ選択リストになります。欄には、選んでいる相手で開く窓のタイトルが出ます
- カードの並び(デフォルト): [プレイヤーリスト](Player-List-ja)・[エンティティリスト](Entity-List-ja)・[プレイヤー情報](Player-Info-ja)・[エンティティ情報](Entity-Info-ja)・[ステータス詳細](Status-ja)・[装備情報](Equipment-Info-ja)・[アビリティ情報](Talent-Info-ja)・[潜在心相晶情報](Deep-Slumber-Psychoscope-Info-ja)・[モジュール情報](Module-Info-ja)・[バフリスト](Buff-List-ja)・[デバフリスト](Debuff-List-ja)・[バフ・デバフカード](Buff-&-Debuff-Card-ja)・[バフ・デバフグループ](Buff-&-Debuff-Group-ja)・[蘇生リスト](Revive-List-ja)・[タイムライン](Timeline-ja)・[DPSメーター](DPS-Meter-ja)・[HPSメーター](HPS-Meter-ja)・[被ダメログ](Damage-Taken-Log-ja)・[スキル詳細(与ダメ)](Skill-Details-(Damage)-ja)・[与ダメ詳細](Damage-Details-ja)・[DPS推移グラフ](DPS-Trend-Graph-ja)・[スキル詳細(ヒール)](Skill-Details-(Healing)-ja)・[ヒール詳細](Healing-Details-ja)・[HPS推移グラフ](HPS-Trend-Graph-ja)・[被ダメ詳細](Damage-Taken-Details-ja)・[チャット](Chat-ja)。プラグインのウィジェットはその後ろに並びます

## 操作

- 検索欄: 入力した文字を名前の欄に含むカードだけを出します。大文字と小文字は区別しません
- 並べ替え: デフォルト / 名前順 / お気に入り / 起動状態 / ピン留め / クリック透過(デフォルト)。「お気に入り」から「クリック透過」までは、それが付いているカードが上に来ます
- 三点のメニュー: お気に入りを起動 / すべてを停止 / 起動中をピン留め / ピン留めをすべて解除 / ピン留めをクリック透過 / クリック透過をすべて解除
- カードのボタン
  - お気に入り: 印を付けます。三点のメニューの「お気に入りを起動」で、まとめて起動するウィジェットになります
  - ピン留め: 窓を動かせず、大きさも変えられないようにします。窓を押してもアクティブにならないので、ゲームの操作を邪魔しません。既定では、ピン留めしている間はヘッダーが隠れます
  - クリック透過: 窓へのマウスの操作を受けず、下の画面(ゲームなど)へそのまま通します
  - 設定: そのウィジェットの設定の窓を開きます
  - 起動/停止: 窓を開きます。開いているときは閉じます。相手ごとに窓を開くウィジェットは、選んでいる相手の窓だけを開け閉めします
- 名前の欄の選択リスト: 選ぶと、選んだ相手が欄に出ます。窓を開くのは起動のボタンを押したときです

## 注意

- お気に入り・ピン留め・クリック透過は保存されます。検索・並べ替え・選択リストで選んだ相手は保存されません
- 起動中のままアプリを閉じたウィジェットは、次の起動でまた開きます。窓の×か停止のボタンで閉じたウィジェットは停止になります
- クリック透過の窓では、窓のボタンやスクロールも使えません。解除は、カードのボタン・三点のメニュー・[ホットキー](Hotkeys-ja)で行います
- 三点のメニューの操作は、[ホットキー](Hotkeys-ja)でも行えます(既定はCtrl+F8・Ctrl+F7・Ctrl+F6)。ホットキーが使えるときは、メニューの項目の後ろにキーが出ます
- 窓をいつも最前面に出すか、ピン留めした窓だけ最前面に出すかは、[全体設定](Settings-ja)の「ウィジェットウィンドウ」で選べます
- 窓の動かし方・大きさの変え方・設定の窓の共通の項目は、[ウィジェットの共通設定](Common-Widget-Settings-ja)にあります
