「[集計](集計)」の履歴(保存した戦闘)をプラグインで読み、プラグインの値を戦闘と一緒に保存するための説明です。どのプラグインにも要ることは[プラグイン開発](プラグイン開発)、読んだ戦闘の値の読み方は[プラグイン開発(データ)](プラグイン開発(データ))の「戦闘の読み口」にあります。

## 履歴(`History`)

`IPluginContext.History`(`IPluginHistoryService`)を使います。次の例は、戦闘が履歴に保存されたときに、その戦闘へ保存した時刻を書き、戦闘を読み直して、全員の与ダメの合計と書いた値をログに書きます。

```csharp
using System.Text;
using StarResonanceDps.PluginSdk;

[assembly: PluginRegistration(typeof(MyPlugin.Plugin), PluginSdkVersion.Current)]
[assembly: PluginDisplayName("ja-JP", "私のプラグイン")]
[assembly: PluginAuthor("YourName")]
[assembly: PluginVersion("1.0.0")]

namespace MyPlugin;

public sealed class Plugin : IStarResonancePlugin
{
    private const string NoteKey = "my.note";

    private IPluginContext? _context;

    public void Initialize(IPluginContext context)
    {
        _context = context;
        context.GameData.EncounterSaved += OnEncounterSaved;
    }

    private async void OnEncounterSaved(object? sender, PluginEncounterSaved saved)
    {
        IPluginContext? context = _context;
        if (context is null)
        {
            return;
        }

        byte[] note = Encoding.UTF8.GetBytes(DateTime.UtcNow.ToString("O"));
        PluginHistoryStatus status = await context.History.SetSavedEncounterDataAsync(saved.HistoryId, NoteKey, note);
        if (status != PluginHistoryStatus.Succeeded)
        {
            context.Logger.Warning($"{saved.HistoryId}: {status}");
            return;
        }

        PluginHistoryLoadResult loaded = await context.History.LoadAsync(saved.HistoryId);
        IPluginEncounterRecord? encounter = loaded.Encounter;
        if (encounter is null)
        {
            context.Logger.Warning($"{saved.HistoryId}: {loaded.Status}");
            return;
        }

        foreach (PluginEncounterPlayer player in encounter.GetTotals().Players)
        {
            context.Logger.Info($"{player.CharacterId}: {player.Damage.Total}");
        }

        if (encounter.GetPluginData(NoteKey) is ReadOnlyMemory<byte> stored)
        {
            context.Logger.Info(Encoding.UTF8.GetString(stored.Span));
        }
    }

    public void Shutdown()
    {
        if (_context is not null)
        {
            _context.GameData.EncounterSaved -= OnEncounterSaved;
        }
    }
}
```

| メンバー | 中身 |
|---|---|
| `GetEntriesAsync()` | 保存した戦闘の一覧(下の「一覧」) |
| `LoadAsync(historyId)` | 保存した戦闘を、開かずに読む(下の「開かずに読む」) |
| `OpenAsync(historyId)` | 保存した戦闘を、アプリで開く(下の「アプリで開く」) |
| `ReturnToLiveAsync()` | アプリを今の戦闘に戻す(下の「アプリで開く」) |
| `KeepHistoryOpen()` | 開いた履歴から、自動で今の戦闘に戻らないようにする(下の「開いた履歴を保つ」) |
| `HasOpenFailed`・`OpenFailedChanged` | 最後に開こうとした戦闘を読めなかったかと、変わったときのイベント(下の「開けなかったとき」) |
| `TrySetEncounterData(encounterKey, key, data)` | まだ保存していない戦闘に、プラグインの値を入れる(下の「戦闘への保存」) |
| `SetSavedEncounterDataAsync(historyId, key, data)` | 保存した戦闘の、プラグインの値を書き換える(下の「戦闘への保存」) |

- どのスレッドから呼んでもかまいません。`OpenFailedChanged`はUIスレッドで来ます
- `GetEntriesAsync`・`LoadAsync`・`SetSavedEncounterDataAsync`は、裏のスレッドで履歴を読み書きします。プラグイン1つにつき1つずつ順に動き、前に呼んだものが終わるまで待ちます
- この3つの`cancellationToken`は省けます。読み書きの前(`GetEntriesAsync`・`LoadAsync`は読んだ後も)に見て、キャンセルされていれば、タスクが`OperationCanceledException`で終わります。読み書きの途中では止まりません
- 保存した戦闘は履歴の番号(`HistoryId`)で、保存する前の戦闘は`EncounterKey`で指します([プラグイン開発(データ)](プラグイン開発(データ))の「戦闘の集計」)
- プラグインが止まった後(`Shutdown`の中も)は、どのメソッドも何もしません。タスクを返すメソッドは`Unavailable`で終わり(`ReturnToLiveAsync`はそのまま終わります)、`TrySetEncounterData`は`false`を、`KeepHistoryOpen`は何も保たない`IDisposable`を返します。止まる前に`OpenAsync`で頼み、まだ開いていない履歴は開きません
- アプリを閉じ始めた後も、`GetEntriesAsync`・`LoadAsync`・`OpenAsync`・`ReturnToLiveAsync`・`SetSavedEncounterDataAsync`は同じく何もしません

| `PluginHistoryStatus` | 終わり方 |
|---|---|
| `Succeeded` | できた |
| `NotFound` | その番号の保存した戦闘が無い(全体設定の「履歴の最大保持数」で消えたなど) |
| `Failed` | 履歴を読めなかったか、書けなかった。理由はアプリのログに書きます |
| `Unavailable` | プラグインが止まった後か、アプリを閉じ始めた後なので、何もしなかった |

### 一覧(`GetEntriesAsync`)

```csharp
private static async Task LogHistoryAsync(IPluginContext context)
{
    PluginHistoryListResult list = await context.History.GetEntriesAsync().ConfigureAwait(false);
    foreach (PluginHistoryEntry entry in list.Entries)
    {
        string? sceneName = entry.Info.SceneId is int sceneId
            ? context.Names.GetSceneName(sceneId, entry.Info.DungeonDifficulty)
            : null;
        context.Logger.Info($"{entry.HistoryId}: {entry.Info.CreatedUtc:O} {sceneName} {entry.Elapsed}");
    }
}
```

- 保存した戦闘を、「集計」の履歴と同じく新しい順に返します。開かないので、アプリの表示は変わりません
- 結果(`PluginHistoryListResult`)の`Entries`に入るのは、`Status`が`Succeeded`のときのみです
- アプリは、戦闘を保存したときとアプリを閉じるときに、全体設定の「履歴の最大保持数」を超えた古い戦闘を消します

| `PluginHistoryEntry`のプロパティ | 中身 |
|---|---|
| `HistoryId` | 履歴の番号。`LoadAsync`・`OpenAsync`・`SetSavedEncounterDataAsync`に渡します |
| `Info` | マップ・サーバー・計測などの値(`PluginEncounterInfo`、[プラグイン開発(データ)](プラグイン開発(データ))の「戦闘の値」)。`BenchmarkFirstTargetOnly`は`null`です |
| `StartUtc` | 戦闘の時計が動き出した時刻(UTC)。動き出さなかった戦闘は`null` |
| `Elapsed` | 戦闘の経過時間(自動一時停止の間を除く) |

### 開かずに読む(`LoadAsync`)

- 保存した戦闘を1つ読みます。開かないので、ウィジェット・「集計」・`GetEncounter`は変わりません
- 結果(`PluginHistoryLoadResult`)の`Encounter`が、読んだ戦闘の読み口(`IPluginEncounterRecord`)です。`Status`が`Succeeded`でなければ`null`です
- 読み口の読み方は[プラグイン開発(データ)](プラグイン開発(データ))の「戦闘の読み口」にあります。`IsHistory`は`true`で、その戦闘にいたプレイヤーは`GetPlayers`で読めます
- 読んだ戦闘は後から変わりません。読んだ後に`SetSavedEncounterDataAsync`で書いた値も入らないので、要るときは読み直します
- `EncounterKey`は読むたびに新しい番号になります。同じ戦闘かは`HistoryId`で比べます
- 読み口を持っている間は、読んだ戦闘がメモリに残ります。必要な間のみ持ちます

### アプリで開く(`OpenAsync`・`ReturnToLiveAsync`)

- `OpenAsync`は、「集計」で履歴の行を押したときと同じく、保存した戦闘を開きます。DPSメーターなどのウィジェットと`GetEncounter`が、その戦闘になります(「[集計](集計)」)
- 戦闘は裏のスレッドで読み、表示を予約するとタスクが`Opened`で終わります。表示されると`GameData.ShownEncounterChanged`が来ます
- 読んでいる間に別の戦闘か今の戦闘が選ばれると、`Superseded`で終わります。`Opened`の後、表示される前に選ばれたときも表示されません。表示されているかは`GameData.GetShownEncounter()`で確かめます
- 全体設定の「履歴表示を自動解除」がオンなら、今の戦闘でできごとが起きたときと、集計が区切られたときに、アプリが今の戦闘に戻します。戻さないようにするには`KeepHistoryOpen`を使います
- `ReturnToLiveAsync`は、「集計」で開いている履歴の行をもう一度押したときと同じく、今の戦闘に戻します。戻した後にタスクが終わります。今の戦闘を映していれば何も変わりません
- 戻す処理でアプリに例外が起きたときは、タスクがその例外で終わります(アプリのログにも書きます)

| `PluginHistoryOpenResult` | 終わり方 |
|---|---|
| `Opened` | 戦闘を読み、表示を予約した |
| `NotFound` | その番号の保存した戦闘が無い。表示は変わらない |
| `Superseded` | 読んでいる間に、別の戦闘か今の戦闘が選ばれた。表示しない |
| `Failed` | 戦闘を読めなかった(理由はアプリのログ)。表示は変わらない |
| `Unavailable` | プラグインが止まった後か、アプリを閉じ始めた後なので、何もしなかった |

### 開いた履歴を保つ(`KeepHistoryOpen`)

- 返った`IDisposable`を`Dispose`するまで、全体設定の「履歴表示を自動解除」がオンでも、今の戦闘のできごとや集計の区切りで今の戦闘に戻しません
- `ReturnToLiveAsync`のとき、「集計」で開いている履歴の行をもう一度押したとき、ログアウトのときは、今の戦闘に戻ります
- 呼ぶたびに新しい`IDisposable`を返します。同じものを2回`Dispose`しても、2回目は何もしません
- すべてのプラグインの`IDisposable`が`Dispose`されると、次のできごとから、設定のとおり今の戦闘に戻ります
- プラグインが止まると、アプリがそのプラグインの分を`Dispose`します

### 開けなかったとき(`HasOpenFailed`)

- `HasOpenFailed`は、「集計」で選んだときも含めて、最後に開こうとした戦闘をアプリが読めなかったとき(例外か、その番号の戦闘が無い)に`true`です。表示は前のままです
- 戦闘を開いたときと、今の戦闘に戻ったときに`false`になります。`LoadAsync`では変わりません
- 変わると`OpenFailedChanged`が来ます。短い間の変化は1回にまとめます

## 戦闘への保存

プラグインの値をバイト列で戦闘と一緒に保存し、後で履歴から読み直せます。

| メソッド | 書く戦闘 | 結果 |
|---|---|---|
| `TrySetEncounterData(encounterKey, key, data)` | まだ保存していない戦闘(今の戦闘か、閉じた後で保存する前の戦闘)。`encounterKey`は戦闘の`EncounterKey`です | 入れられれば`true` |
| `SetSavedEncounterDataAsync(historyId, key, data)` | 保存した戦闘。`historyId`は履歴の番号です | `PluginHistoryStatus` |

- 値はキーごとに持ちます。キーは1〜128文字の英数字と「.」「-」「_」で、大文字と小文字は区別しません
- 読み書きできるのは、このプラグインの値のみです。読むのは戦闘の読み口の`GetPluginData(key)`で、無ければ`null`です
- 1つの戦闘に保存できるのは、プラグイン1つにつき、キー32個(`PluginEncounterDataLimits.MaxKeys`)・合計4MiB(`PluginEncounterDataLimits.MaxTotalBytes`)までです
- 空の値を書くと、そのキーを消します。値はアプリが写すので、渡した後に書き換えても保存した値は変わりません
- キーが決まりに合わないときと、値が4MiBを超えるときは、呼んだ時点で`ArgumentException`になります。`GetPluginData`も、キーが決まりに合わなければ`ArgumentException`です
- キーの数か合計が上限を超えるときは、書かずに`InvalidOperationException`になります(`SetSavedEncounterDataAsync`は、タスクがこの例外で終わります)
- 値は戦闘と一緒に消えます(全体設定の「履歴の最大保持数」)。プラグインを削除しても残り、同じアセンブリ名のプラグインを入れ直すと読めます。アセンブリ名を変えると、前の値は読めません

### まだ保存していない戦闘(`TrySetEncounterData`)

- 今の戦闘(`GameData.GetLiveEncounter()`の`EncounterKey`)などに値を入れておくと、アプリが戦闘を保存するときに一緒に保存します
- 保存した後の戦闘には入れられず、`false`を返します。`GameData.EncounterSaved`の後は`SetSavedEncounterDataAsync`で書きます
- `GameData.EncounterClosed`の処理の中で入れた値は、戦闘と一緒に保存されるとは限りません。閉じた戦闘の最後の値は、`EncounterSaved`を受けてから`SetSavedEncounterDataAsync`で書きます
- 記録の無い戦闘は保存されず、入れた値も一緒に捨てます
- アプリを閉じるときは、最後の戦闘を保存してからプラグインを止めるので、`Shutdown`の中では`false`です

### 保存した戦闘(`SetSavedEncounterDataAsync`)

- 保存した戦闘の、そのキーの値を置き換えます
- その番号の戦闘が無ければ`NotFound`、書けなければ`Failed`(理由はアプリのログ)で終わります
- 「集計」で開いている戦闘と、前の戦闘を映している間のその戦闘には、新しい値が入ります。前に`LoadAsync`で読んだ戦闘と、アプリがもう映していない戦闘の読み口には入りません
- 書いている間に同じ戦闘を開くと、開いた戦闘に新しい値が入らないことがあります。履歴には入っているので、`LoadAsync`で読み直せます
