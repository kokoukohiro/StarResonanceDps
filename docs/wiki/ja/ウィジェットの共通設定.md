どのウィジェットにも共通の、窓の決まりと設定の窓です。ウィジェットごとの設定は、それぞれのページにあります。

## ウィジェットの窓

- ヘッダー: 窓の上の段です。左から、状態の円・タイトル・閉じるボタン(×)です。ウィジェットによっては、閉じるボタンの左に操作のボタン(DPSメーターの「計測」など)があります
- フッター: 窓の下の段です。プレイヤーリスト・エンティティリスト・DPSメーター・HPSメーター・被ダメログにあります
- 動かすとき: ヘッダーのタイトルのあたりを掴んで動かします
- 大きさを変えるとき: 窓の縁を掴んで動かします
- 位置と大きさは保存され、次に開くときも同じ所に出ます。プレイヤー情報の大きさと装備情報の高さは保存せず、開くたびに既定の大きさになります
- ステータス詳細・バフ・デバフグループ・与ダメ詳細・ヒール詳細・被ダメ詳細・エンティティ情報は、行の数が変わると、窓の高さが中身に合わせて変わります
- 閉じるボタンを押すと、その窓を閉じます。窓がすべて閉じたウィジェットは停止になります

## 状態の円

窓のタイトルの左の円です。ウィジェットに出す情報が足りているかを色で表します。

| 色 | 状態 |
|---|---|
| 緑 | 足りない情報が見つかっていません |
| 黄 | 一部の情報が足りません。パーティ画面を開く・プレイヤーをクリックする・近づき直すなどで直ります |
| 赤 | マップを移動するかログインし直すまで、情報を受け取れません(データを読み込めないときも赤) |

黄と赤のときは、円かタイトルにマウスを乗せると理由が出ます。

| 理由 | 色 |
|---|---|
| データを読み込めません | 赤 |
| マップを移動するかログインし直すまで、情報を受け取れません | 赤 |
| ログインし直すまで、過去のチャットを受け取れません | 黄 |
| パーティ画面を開くまで、一部の情報を受け取れません | 黄 |
| 該当プレイヤーをクリックするまで、一部の情報を受け取れません | 黄 |
| 該当プレイヤーに近づき直すまで、一部の情報を受け取れません | 黄 |
| 該当の敵に近づき直すまで、一部の情報を受け取れません | 黄 |

- 円を出すかは、[全体設定](全体設定)の「ウィジェット状態」で選べます
- アプリをゲームの途中で起動すると、マップを移動するまで赤や黄になることがあります

## ピン留めとクリック透過

どちらも「[ウィジェット](ウィジェット)」のカードのボタンで切り替え、そのウィジェットの窓すべてに効きます。

- ピン留め: 窓を動かせず、大きさも変えられなくなります。窓を押してもアクティブにならないので、ゲームの操作を邪魔しません。下の「ウィンドウ設定」で、ヘッダーとフッターを隠せます
- クリック透過: 窓へのマウスの操作を受けず、下の画面(ゲームなど)へそのまま通します。窓のボタンやスクロールも使えなくなります
- 最前面: 既定では、ウィジェットの窓はいつも最前面に出ます。全体設定の「ウィジェットウィンドウ」で「ピン留め時のみ最前面」を選ぶと、ピン留めした窓だけが最前面に出ます

## 設定の窓

「ウィジェット」のカードの設定のボタン(歯車)で開きます。

- 左の一覧を押すと、その節まで動きます。節はウィジェットによって違い、「ウィンドウ設定」と「テーマ」はどのウィジェットにもあります
- 変えた項目は、その場でウィジェットの窓に出ます。設定はウィジェットごとで、同じウィジェットの窓すべてに効きます
- 「保存」で確定して窓を閉じます。保存せずに閉じると確認の窓が出て、「はい」で元に戻ります
- 「初期化」を押して確認の窓で「はい」を押すと、この窓の全部の項目が初期値になります。確定するのは「保存」を押したときです

## ウィンドウ設定

- ピン留め中ヘッダーを隠す: ピン留めしている間、ヘッダーを見えなくし、その部分のクリックを下の画面へ通します(オン)
- ピン留め中フッターを隠す: フッターのあるウィジェットだけにあります。ピン留めしている間、フッターを同じように隠します(オフ)
- ウィンドウの不透明度: 窓の背景の濃さです。文字・数値・バー・アイコンは薄くなりません。窓を押してアクティブにしている間は、50%より低くしていても50%で出ます(50%)

![テーマ](images/ja/WidgetSettings2.png)

## テーマ

- ウィンドウの色: 窓の背景の色です。「ウィジェット」のカードもこの色になります(黒)
- 背景画像: 窓の背景に画像を出します。「画像を選択」で選びます。画像を出している間は、ウィンドウの色は選んでいない表示になります。色を選ぶと画像は外れます(なし)

## 色の選び方

ウィンドウの色と、クラスカラーなどの色の節はどれも同じ作りです。

- 並んだ色の丸を押すと、その色になります
- 「色を選択」を押すと、カラーピッカーが開きます。「OK」で選んだ色は並びの右に足されます(5つまで。超えると左端の色が外れます)
- カラーピッカーでは、四角で明るさと鮮やかさを、縦のバーで色合いを選びます。#で始まる6桁の色の番号でも入力できます。「最近使用した色」からも選べます
