![タイムライン](images/ja/Timeline1.png)

ボスのスキルの予告と、敵の行動(回復・敵へのダメージ・バフとデバフを付けたこと)を、戦闘の経過時間の順に1行ずつ出すウィジェットです。プレイヤーが受けたダメージは[被ダメログ](被ダメログ)に出ます。

## 開き方

「[ウィジェット](ウィジェット)」の「タイムライン」のカードで、起動のボタンを押します。ウィンドウは1枚だけ開きます。

## 見方

- 左の時刻: 戦闘の経過時間です(「00:00:34」の形)。[DPSメーター](DPSメーター)の経過時間と同じ時計で、自動一時停止で止まっていた間は数えません。同じ時刻の行が続くときは、最初の行だけに時刻を出します
- 行の種類

| 行 | 出るとき |
|---|---|
| 敵がスキルを構えている | ゲームの画面に、ボスのスキルの予告が出たとき |
| 敵のスキル(予告の後) | 予告の時間が終わったとき |
| 敵がスキルを唱えている | 戦闘の画面に警告が出るスキルの詠唱を始めたとき。そのほかの詠唱は、詠唱から回復・ダメージ・バフが起きたときだけ、詠唱を始めた時刻の位置に出ます |
| 敵のスキル | 敵のスキルで、下の行の回復・ダメージ・バフが起きたとき |
| 相手のHPを12345回復 | 敵が敵やプレイヤーを回復したとき(実際に増えたHP) |
| 相手に12345ダメージ | 敵が敵にダメージを与えたとき |
| 相手にバフ名(10秒) | 敵が敵やプレイヤーにバフ・デバフを付けたとき(後ろは効果時間) |

- 回復・ダメージ・バフの行は、起こしたスキルの行の下に、相手ごとに並びます。同じ相手への回復とダメージは1行にまとめて値を足します
- 同じ時刻の中は、予告と詠唱の行(構えている・予告の後・唱えている) → ダメージ → 回復 → バフ の順です
- 相手がプレイヤーの行は、名前の前にクラスのアイコンが出ます。マウスを乗せると、クラス(雷刃など)がTIPSで出ます
- 色: 敵の名前・スキルの名前・プレイヤー名・バフの名前と秒・回復とダメージの値は、テキストカラーの色です
- 名前: プレイヤー名は全体設定の「プレイヤー名」に従います。名前の無い、HPバーの見える敵は「敵」、何者か分からない敵(アプリを起動する前からいた敵など)は「未知の敵」です
- 名前の無いスキルとバフは、全体設定の「名前のないスキルとバフ」で、空欄(「何か」「攻撃」などと出ます)か内部名(中国語)を選べます(内部名で表示)
- 予告の行は予告の名前、唱えている行はスキルの名前を出すので、同じスキルでも名前が違うことがあります(画像の「雪崩」は、唱えている行では「アバランチ」)

## 操作

- 文字をなぞると、行をまたいで選べます。Shift+クリックで広げ、クリックで解除します。なぞったままウィンドウの上下の外へ出すか、ホイールを回すと流れます
- 選んだ文字があるときに右クリックすると、「コピー」を選べます。ウィンドウがアクティブなときは、Ctrl+Cでもコピーできます
- コピーした文字は、1行ずつ改行され、時刻の後ろに本文が続きます
- ホイールか右のスクロールバーで動かします。一番下を見ている間は、新しい行に付いていきます

## 設定

ウィンドウ設定とテーマは[ウィジェットの共通設定](ウィジェットの共通設定)にあります。

### 表示設定

- 敵の回復: 敵の回復の行を、表示 / 非表示 から選びます(表示)

### アイコンカラー

クラスのアイコンの色を、クラスごとに選びます(変身と不明を含む)。既定はプレイヤーリストと同じ色です。

### テキストカラー

エンティティ名・スキル名・プレイヤー名・効果・HP数値の文字の色です。

## 注意

- 出すのは、モンスターの行動だけです。プレイヤー・NPC・設置物などの行動と、プレイヤーが受けたダメージは出ません
- バフは付いた瞬間だけ出します。延長・重なり・消えたことは出ません。プレイヤーが付けたバフから広がったバフも出ません
- 敵の回復は、[HPSメーター](HPSメーター)には入りません
- 履歴を開くと、その回のタイムラインを出します。記録は回と一緒に保存されます
- 全体設定の「非戦闘エリアでの集計を停止」がオン(既定)のときは、アステルリーズ・ホームガーデン・ホームハウスでは記録しません
- 予告の行と同じ予告を、[通知](通知)の「予兆技」で知らせられます。通知はこのウィンドウを開いていなくても知らせます
