This tab lets you check the app version and open pages such as the usage guide.

## What it shows

- Top section: The app name, version, and description. The result of the update check appears in parentheses after the version.
- "Links" section: Click a link to open the following page.

| Link | Page it opens |
|---|---|
| How to use | [Home](Don't-Check-My-DPS-Wiki) of this wiki |
| Making plugins | [Plugin Development](Plugin-Development) of this wiki |
| GitHub | The home page of the GitHub repository (README) |
| Release notes | The release notes on GitHub (changes in each version) |

- "How to use" and "Making plugins" open the page in the app's language. The table shows where they open when the app is in English. In other languages, they open the wiki page in that language. The README on GitHub is in Japanese, and the links at the top open the README in other languages.
- Bottom: The copyright and license. Click "License" to open the page on GitHub that explains the license.

## Controls

- Click "Check for updates" to check whether a new version is available. If there is one, a confirmation window appears ([Installation and Updates](Installation-and-Updates)).
- While checking, the button changes to "Cancel", and clicking it stops the check.
- Click a link to open that page in your browser.

## Notes

- Checking for updates and opening pages require an internet connection.
- The license text and the licenses of the libraries used are also in `LICENSE`, `LICENSING.md`, and `THIRD-PARTY-NOTICES.txt` in the app folder.
