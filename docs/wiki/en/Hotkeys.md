This feature lets you start or pin widgets, run benchmarks, and more by pressing keys. Keys are set in "Hotkeys" in [Settings](Settings).

## Actions

| Item | Default key | What it does |
|---|---|---|
| Show/Hide Player Names | Ctrl+F11 | Switches "Player name" in Settings. If it is "Show", it changes to "Hide"; otherwise, it changes to "Show". |
| Start favorites/Stop all | Ctrl+F8 | If any widgets are running, stops all of them; otherwise, starts your favorite widgets. |
| Pin running/Unpin all | Ctrl+F7 | If any widgets are pinned, unpins all of them; otherwise, pins all running widgets. |
| Make pinned click-through/Disable all click-through | Ctrl+F6 | If any widgets are click-through, turns it off for all of them; otherwise, makes all pinned widgets click-through. |
| Always on Top/On Top Only While Pinned | Ctrl+F5 | Switches "Widget Windows" in Settings. |
| Benchmark | Ctrl+F10 | The same as "Benchmark" in "[Aggregation](Aggregation)" (while a benchmark is running, it stops the benchmark). |
| Reset | Ctrl+F9 | The same as "Reset" in "[Aggregation](Aggregation)". |

## Setting keys

1. In "Hotkeys" in Settings, click the field of the item to change. "Press a key" appears in the field.
2. Press the key to assign. You can also combine it with Ctrl, Alt, and Shift.
3. Click "Save" to confirm.

- Any other item that was assigned the same key becomes empty.
- Keys used by other apps cannot be assigned. The "Hotkey error" window appears, and the previous key remains.
- If you click outside the field while "Press a key" is shown, the change is canceled and the previous key returns.
- Any key pressed while "Press a key" is shown, including Esc and Delete, is assigned. There is no way to make an assignment empty.
- You can return to the default keys with "Reset" in Settings.

## Notes

- Hotkeys work only while the game or this app is in the foreground. The keys you press then do not reach the game. While another app is in the foreground, the keys reach that app as usual.
- A helper program is needed to receive hotkeys. The helper program starts when the app starts, and a User Account Control prompt appears. If you select "No", the "Hotkey error" window appears, and hotkeys cannot be used until the app is restarted.
- While the helper program is not running, "Hotkeys" does not appear in Settings. If you do not use hotkeys, turn off "Launch hotkey helper at app startup" in "Startup" in Settings.
- The key for each action is also shown after the items in the three-dot menu of "[Widgets](Widgets)".
