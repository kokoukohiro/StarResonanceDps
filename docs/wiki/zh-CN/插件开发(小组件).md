这是用插件在“[小组件](小组件)”中添加卡片，并制作小组件窗口内容的说明。所有插件都需要的内容，请参阅[插件开发](插件开发)。

## 2种形式

| 形式 | 入口类实现的接口 | 窗口 |
|---|---|---|
| 只有1个窗口的小组件 | `IPluginWidgetProvider` | 1个小组件1个 |
| 按对象打开窗口的小组件 | `IPluginMultiWidgetProvider` | 每个对象1个。在卡片的下拉列表中选择对象 |

- 一个插件中可以同时实现两者。小组件的`Id`在两者之间不要重复。卡片按只有1个窗口的形式、按对象的形式的顺序，以定义的顺序排列
- 没有`IPluginWindowProvider`窗口的插件不需要`PluginGenre`

| 应用负责的内容 | 插件提供的内容 |
|---|---|
| 卡片(收藏、固定、鼠标穿透、设置、启动)、窗口的框和标题栏(状态圆点、标题、关闭)、设置窗口的“窗口设置”和“主题”、位置和大小的保存 | 小组件的定义(名称、默认大小、有无底栏、设置的部分)和窗口的内容(主体、底栏、标题栏的按钮) |

## 只有1个窗口的小组件

```csharp
using System.Windows;
using System.Windows.Controls;
using StarResonanceDps.PluginSdk;

[assembly: PluginRegistration(typeof(MyPlugin.Plugin), PluginSdkVersion.Current)]
[assembly: PluginDisplayName("ja-JP", "私のプラグイン")]
[assembly: PluginAuthor("YourName")]
[assembly: PluginVersion("1.0.0")]

namespace MyPlugin;

public sealed class Plugin : IStarResonancePlugin, IPluginWidgetProvider
{
    public void Initialize(IPluginContext context)
    {
    }

    public IReadOnlyList<PluginWidgetDefinition> GetWidgetDefinitions()
    {
        return
        [
            new PluginWidgetDefinition
            {
                Id = "hello",
                Names = new Dictionary<string, string> { ["ja-JP"] = "あいさつ", ["en-US"] = "Hello" },
                DefaultWidth = 240,
                DefaultHeight = 80,
            },
        ];
    }

    public PluginWidgetContent CreateWidget(string widgetId, IPluginWidgetContext context)
    {
        var text = new TextBlock { Text = "Hello", Margin = new Thickness(8) };
        text.SetResourceReference(FrameworkElement.StyleProperty, PluginResourceKeys.Text.WidgetWindow);
        return new PluginWidgetContent { Body = text };
    }

    public void Shutdown()
    {
    }
}
```

| 成员 | 调用时机 | 作用 |
|---|---|---|
| `GetWidgetDefinitions` | `Initialize`之后立即调用1次 | 返回要添加的小组件的定义列表。卡片按返回的顺序排列。之后更改也不会反映 |
| `CreateWidget` | 每次打开窗口时(UI线程) | 返回窗口的内容。`widgetId`为定义的`Id` |

### 定义(`PluginWidgetDefinition`)

| 属性 | 是否必需 | 内容 |
|---|---|---|
| `Id` | 必需 | 小组件的ID。为1～128个字符的英文字母、数字和“.”“-”“_”。这是保存用的键，因此不要在版本之间更改 |
| `Names` | 必需 | 显示在卡片、窗口标题和设置窗口标题中的名称 |
| `DefaultWidth`、`DefaultHeight` | 必需 | 首次打开时的窗口大小。最小为240×60，高度包括标题栏(30)和底栏(30) |
| `HasFooter` | 可选(默认为无) | 是否创建底栏的行 |
| `ScrollsVertically` | 可选(默认为否) | 是否用纵向滚动条移动主体 |
| `SettingSections` | 可选 | 添加到设置窗口中的部分(下面的“设置”) |

- 各语言的文字像`Names`一样，用以语言名称(`ja-JP`等)为键的字典书写。选择方式与特性相同([插件开发](插件开发)的“入口类和特性”)
- 卡片中只显示小组件的名称。不显示插件的名称和图标
- 有一次保存过的窗口大小时，不使用`DefaultWidth`、`DefaultHeight`

### 内容(`PluginWidgetContent`)

| 属性 | 是否必需 | 内容 |
|---|---|---|
| `Body` | 必需 | 窗口的主体 |
| `Footer` | `HasFooter`时必需，否则为`null` | 底栏。高度为30，使用窗口的全部宽度 |
| `HeaderButtons` | 可选 | 标题栏中的文字按钮(`PluginWidgetHeaderButton`)。排列在标题的右侧、关闭按钮的左侧 |

- `ScrollsVertically`为`false`时，主体使用标题栏和底栏之间的全部空间。为`true`时，主体随窗口的宽度展开，高度为主体所需的高度，放不下时会出现纵向滚动条
- 主体和底栏的`DataContext`为`null`。使用绑定时请自己设置
- 窗口没有设置文字颜色。小组件的白色文字和阴影，需要加上`Text.WidgetWindow`的样式来显示
- 设置中的“窗口不透明度”作用于窗口的背景和框，主体和底栏不会变淡
- 标题栏的按钮在更改`Text`后文字会变化，点击后`Click`会在UI线程上触发。按钮保持创建内容时的列表，不会增加也不会减少。通过设置中的“固定时隐藏标题栏”隐藏标题栏期间，按钮也会隐藏
- 主体和底栏为`IDisposable`时，会在窗口关闭后调用`Dispose`。请在其中取消事件的订阅和停止计时器

### 创建内容时接收的内容(`IPluginWidgetContext`)

| 成员 | 内容 |
|---|---|
| `WidgetId` | 定义的`Id` |
| `Settings` | 此小组件的设置的当前值(下面的“设置”) |
| `SettingsChanged` | 设置变化时在UI线程上触发的事件 |

- 每个窗口创建1个。关闭窗口后，`SettingsChanged`不再触发
- 只是打开窗口不会触发事件，因此请在`CreateWidget`中从`Settings`读取初始值

## 设置

在定义的`SettingSections`中写入部分后，会显示在小组件设置窗口的“窗口设置”和“主题”之间。

```csharp
SettingSections =
[
    new PluginWidgetSettingSection
    {
        Names = new Dictionary<string, string> { ["ja-JP"] = "表示", ["en-US"] = "Display" },
        Icon = PluginResourceKeys.Icons.Settings,
        IconStyle = PluginResourceKeys.Icons.FillStyle,
        Settings =
        [
            new PluginSwitchSetting
            {
                Id = "showTime",
                Names = new Dictionary<string, string> { ["ja-JP"] = "時刻を表示", ["en-US"] = "Show time" },
                DefaultValue = true,
            },
        ],
    },
],
```

```csharp
bool showTime = context.Settings.GetSwitch("showTime");
```

| 部分(`PluginWidgetSettingSection`)的属性 | 内容 |
|---|---|
| `Names` | 部分的名称 |
| `Icon` | 左侧列表的图标。`PluginResourceKeys.Icons`的形状键(`Icon.Settings`等) |
| `IconStyle` | 图标的绘制方式。`Icon.Stroke`(线条)或`Icon.Fill`(填充) |
| `Settings` | 行的列表(1个以上) |

行的种类(都必需`Id`和`Names`，可以在`Notes`中加上注意事项)：

| 类型 | 画面 | 读取方法 |
|---|---|---|
| `PluginSwitchSetting` | 开关 | `GetSwitch(id)` → `bool` |
| `PluginChoiceSetting` | 下拉列表。从`Options`的`PluginChoiceOption`中选择，默认为`DefaultOptionId` | `GetChoice(id)` → 所选选项的`Id` |
| `PluginNumberSetting` | 数字输入框。`Minimum`～`Maximum`之间的0以上的整数 | `GetNumber(id)` → `long` |
| `PluginTextSetting` | 1行的文字输入框 | `GetText(id)` → `string` |
| `PluginSliderSetting` | 滑块。`Minimum`～`Maximum`之间以`Step`为单位 | `GetSlider(id)` → `double` |
| `PluginColorSetting` | 颜色圆点和“选择颜色”。在`DefaultColors`中写入1～5个`#RRGGBB` | `GetColor(id)` → `Color` |

- 值变化的时机：开关和颜色在点击时，下拉列表在选择时，数字在确定时(按Enter或离开输入框时)，文字在每输入1个字符时，滑块在拖动期间
- 打开设置窗口期间，更改的值会立即进入`Settings`，并触发`SettingsChanged`(保存前的预览)。点击“初始化”和“保存”时，以及不保存就关闭而恢复原来的值时也会触发。值相同时也会触发
- 值由应用保存在`Data\WidgetSettings.json`中(与插件文件夹中的设置文件分开)。删除插件后会被删除，更新后会保留
- 保存的值无法读取时，以及选项不存在时为默认值，范围外的值为较近一端的值
- 行的`Id`是保存用的键，因此不要在版本之间更改。在小组件中跨部分也不要重复
- 读取定义中没有的`id`时为`KeyNotFoundException`，用不同种类的方法读取时为`InvalidOperationException`
- 无论同一小组件有多少个窗口，设置都只有1组

## 按对象打开窗口的小组件

```csharp
public sealed class Plugin : IStarResonancePlugin, IPluginMultiWidgetProvider
{
    public void Initialize(IPluginContext context)
    {
    }

    public IReadOnlyList<PluginWidgetDefinition> GetMultiWidgetDefinitions()
    {
        return
        [
            new PluginWidgetDefinition
            {
                Id = "slot",
                Names = new Dictionary<string, string> { ["ja-JP"] = "枠", ["en-US"] = "Slot" },
                DefaultWidth = 240,
                DefaultHeight = 80,
            },
        ];
    }

    public IReadOnlyList<PluginWidgetTarget> GetWidgetTargets(string widgetId)
    {
        return
        [
            new PluginWidgetTarget { Id = "a", Names = new Dictionary<string, string> { ["ja-JP"] = "A" }, IsDefault = true },
            new PluginWidgetTarget { Id = "b", Names = new Dictionary<string, string> { ["ja-JP"] = "B" } },
        ];
    }

    public PluginWidgetContent CreateWidget(string widgetId, string targetId, IPluginWidgetContext context)
    {
        var text = new TextBlock { Text = targetId, Margin = new Thickness(8) };
        text.SetResourceReference(FrameworkElement.StyleProperty, PluginResourceKeys.Text.WidgetWindow);
        return new PluginWidgetContent { Body = text };
    }

    public void Shutdown()
    {
    }
}
```

| 成员 | 调用时机 | 作用 |
|---|---|---|
| `GetMultiWidgetDefinitions` | `Initialize`之后立即调用1次 | 返回定义的列表 |
| `GetWidgetTargets` | 打开卡片的下拉列表时，以及重新选择默认对象期间(UI线程) | 返回对象的列表 |
| `CreateWidget` | 每次打开对象的窗口时(UI线程) | 返回该对象窗口的内容 |

- 对象(`PluginWidgetTarget`)具有`Id`(1～128个字符的英文字母、数字和“.”“-”“_”，在列表中不重复)、`Names`、`IsDefault`
- 在用户手动选择之前，会选择`IsDefault`的对象，没有时选择列表中的第1个。之后出现`IsDefault`的对象时，会切换到该对象
- 在下拉列表中选择不会打开窗口。用启动按钮打开或关闭所选对象的窗口。同一对象的窗口只有1个
- 列表为空时，点击启动按钮会由应用显示空窗口(不调用插件)。之后列表中出现对象时，内容会放入该窗口
- 对象从列表中消失，窗口也不会关闭
- 在运行状态下关闭应用后，下次启动时会重新打开同一对象的窗口。即使对象不在列表中，也会用保存的ID调用`CreateWidget`
- 每个窗口各自拥有的是对象、位置和大小、内容。设置、主题、收藏、固定、鼠标穿透由该小组件的所有窗口共享
- `GetWidgetTargets`可能每秒被调用多于1次，因此请不要进行繁重的处理
- 总是返回空列表时，生成会停止(SRDPS013)。如果另有返回内容的`return`，暂时返回空列表的`return`没有问题

## 应用的外观键

- `Text.WidgetWindow`(白色文字和阴影)、`Text.WidgetWindowSubtitle`(相同文字，大小为13)是用于小组件深色背景的文字。即使更改小组件的颜色也保持白色
- `Brush.*`和使用它们的样式(`Button.Text`等)以应用整体的主题颜色绘制，而不是小组件的颜色
- `ScrollViewer.WidgetWindow`的滚动条颜色会跟随小组件的颜色和不透明度。只在小组件窗口中有效
- `ToolTip.WidgetWindowInfo`的提示的背景和边框为小组件的颜色。带提示的元素的`Tag`中没有放入小组件窗口(`Window`)的`DataContext`时，不会应用颜色
- 键的列表请参阅[插件开发(窗口)](插件开发(窗口))的“应用的外观键”

## 错误和异常

- 定义有误(ID的形式和重复、大小、图标、设置值的范围等)时，插件会停止，“[插件](插件)”中行的提示会显示“小组件的结构有误”。原因会以英语写入日志
- 内容有误(`Body`为`null`，`HasFooter`与`Footer`不一致)以及`CreateWidget`的异常会使插件停止，该窗口不会打开，下次启动时也不会打开
- `SettingsChanged`、标题栏按钮的`Click`、`Dispose`、`GetWidgetTargets`中的异常也会使插件停止
- 插件停止后，已打开的窗口会关闭。窗口的状态会保留，因此下次启动时会重新打开
- 名称等必需的文字为空时，生成会停止(SRDPS014)
