这是用于确认应用版本、打开使用方法等页面的页面。

## 查看方式

- 上方一栏：应用的名称、版本、简介。版本后面的括号中会显示检查更新的结果
- “链接”一栏：点击后打开以下页面

| 栏 | 打开的页面 |
|---|---|
| 使用方法 | 本Wiki的[Home](别查我DPS-Wiki) |
| 插件开发 | 本Wiki的[插件开发](插件开发) |
| 更新日志 | GitHub的Releases(各版本的更改) |
| 支持开发 | GitHub Sponsors |

- 使用方法和插件开发会打开应用语言的页面。表中为应用语言是简体中文时打开的页面，其他语言时会打开Wiki中该语言的页面
- 最下方：版权和许可证。点击“许可证信息”会打开GitHub上说明许可证的页面

## 操作

- 点击“检查更新”，会确认是否有新版本。如果有，会出现确认窗口([安装与更新](安装与更新))
- 检查期间按钮会变为“取消”，点击即可停止检查
- 点击栏会在浏览器中打开该页面

## 注意

- 检查更新和打开页面需要连接互联网
- 许可证的正文和所用库的许可证，也可以在应用文件夹的`LICENSE`、`LICENSING.md`、`THIRD-PARTY-NOTICES.txt`中查看
