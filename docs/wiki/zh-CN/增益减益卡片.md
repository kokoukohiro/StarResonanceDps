![增益减益卡片](images/zh-CN/BuffDebuffCard1.png)

这是选择玩家或敌人身上的一个增益或减益，放大显示其名称、图标和剩余时间的小组件。

## 打开方式

- 在“[小组件](小组件)”的“增益减益卡片”卡片中，从名称栏的下拉列表中选择项目，然后点击启动按钮。按以下顺序排列
  1. 在设置的“快捷方式”中开启的行(对象为自己)
  2. 在“增益列表”卡片的名称栏中选择的对象的增益
  3. 在“减益列表”卡片的名称栏中选择的对象的减益
  4. 已打开的窗口中不在上面的项目
- 默认项目为快捷方式的第1个，默认设置下为“增益卡片(料理) - 自己的名称”
- 没有可排列的项目时，名称栏只显示“增益减益卡片”。此时点击启动按钮，会打开自己的增益列表(没有则为减益列表)第1行的卡片。如果也没有，会打开空窗口，并变为最先附加的项目的卡片
- 点击[增益列表](增益列表)和[减益列表](减益列表)的行，或右键点击行并选择“增益卡片”“减益卡片”，会打开该增益或减益的卡片
- 也可以通过[实体信息](实体信息)的栏位和[增益减益分组](增益减益分组)的行的右键菜单打开。分组的行点击也可以打开
- 按对象和增益的组合打开窗口。同一组合的窗口已打开时，会将该窗口显示到前台

## 查看方式

- 标题：“增益卡片(增益名称) - 对象的名称”或“减益卡片(减益名称) - 对象的名称”。料理和药剂为“增益卡片(料理)”“增益卡片(药剂)”
- 主体：从上到下依次为名称行(显示设置的“增益名称”)、图标、剩余时间。层数为2以上时，会在图标上叠加显示数字。剩余时间的显示方式与增益列表相同
- 料理和药剂按种类追踪。即使重新食用而换成了其他料理或药剂，也会显示在同一窗口中
- 同一增益由多人附加时，显示剩余时间最长的一个
- 效果结束后只保留名称行。同一增益再次附加时会再次显示
- 标题栏：关闭按钮左侧有“缩小”“放大”按钮

## 操作

- 缩小、放大：以25%为单位，在100～1000%的范围内改变主体的大小(200%)。窗口的大小不变。倍率按卡片(料理和药剂按种类，敌人按敌人的种类)保存，下次打开同一卡片时也会使用
- 右键点击可以选择以下项目。没有可显示的项目时不会打开菜单
  - “添加至分组”：添加到[增益减益分组](增益减益分组)。在自己的卡片中，对尚未加入分组的增益显示
  - “添加到增益减益卡片快捷方式”：添加到快捷方式。在自己的卡片中，对尚未加入快捷方式的增益显示
  - “将此增益设为通知目标”“从通知目标中移除此增益”(减益为“将此减益设为通知目标”“从通知目标中移除此减益”)：切换通知目标。所有卡片都会显示
- 通过右键更改的内容会立即保存

## 设置

窗口设置和主题在[小组件通用设置](小组件通用设置)中。

### 显示设置

- 增益名称：填写名称行中显示的内容。在下拉列表中选择项目并点击“插入”，会插入该文字(`{BuffName}({TargetName})`)

| 项目 | 文字 | 显示的内容 |
|---|---|---|
| 增益名称 | `{BuffName}` | 增益的名称。料理和药剂为“料理”“药剂” |
| 目标名称 | `{TargetName}` | 卡片对象的名称 |
| 施加者玩家名称 | `{CasterName}` | 附加所显示增益的玩家的名称。由玩家以外附加时为空 |
| 等级 | `{Level}` | 卡片对象等级的数值 |
| 换行 | `{NewLine}` | 换行 |

数值为空而剩下的括号会被删除。所有卡片使用相同的写法。

### 快捷方式

显示在卡片名称栏下拉列表最前面的行。用开关开启或关闭，拖动行可以调整顺序。默认为以下7行。

| 行 | 默认 |
|---|---|
| 料理 | 开 |
| 药剂 | 开 |
| 时间凝滞 | 开 |
| 机械故障 | 开 |
| 元素凝滞 | 开 |
| 力竭·烈焰焚身 | 开 |
| 虚弱·祈愿禁止 | 关 |

可以通过自己的增益列表、减益列表的行和自己的卡片的右键菜单中的“添加到增益减益卡片快捷方式”添加。添加的行关闭后保存会被删除。

### 通知目标

打开卡片期间，通过[通知](通知(简体中文))的“增益减益效果结束”通知效果结束的增益和减益。默认的行和开关与快捷方式相同。可以通过卡片右键菜单的“将此增益设为通知目标”添加。所有卡片使用相同的列表。

## 注意

- 其他玩家的卡片在该玩家不在附近期间只显示名称行。敌人的卡片在该敌人被击倒或离开时只显示名称行
- 增益列表的隐藏列表对卡片无效
- 即使打开历史记录，也会显示当前的增益
- 每秒重新读取一次
- 在运行状态下关闭应用的卡片，下次启动时会以相同的对象和增益重新打开。敌人的卡片会在同种类的敌人出现时显示该敌人
