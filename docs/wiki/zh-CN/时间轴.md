![时间轴](images/zh-CN/Timeline1.png)

这是将首领技能的预告和敌人的行动(治疗、对敌人造成的伤害、附加增益和减益)按战斗经过时间的顺序每行一条显示的小组件。玩家受到的伤害显示在[承伤日志](承伤日志)中。

## 打开方式

在“[小组件](小组件)”的“时间轴”卡片中点击启动按钮。窗口只能打开1个。

## 查看方式

- 左侧的时间：战斗的经过时间(“00:00:34”的形式)。与[DPS计量器](DPS计量器)的经过时间是同一个时钟，自动暂停而停止的期间不计算在内。相同时间的行连续时，只在第一行显示时间
- 行的类型

| 行 | 显示时机 |
|---|---|
| 敌人正在准备技能 | 游戏画面上显示首领技能的预告时 |
| 敌人的技能(预告之后) | 预告时间结束时 |
| 敌人正在咏唱技能 | 开始咏唱战斗画面上会显示警告的技能时。其他咏唱只在因咏唱而发生治疗、伤害、增益时，才显示在开始咏唱的时间位置 |
| 敌人的技能 | 因敌人的技能发生下方各行的治疗、伤害、增益时 |
| 目标恢复12345HP | 敌人治疗敌人或玩家时(实际增加的HP) |
| 对目标造成12345伤害 | 敌人对敌人造成伤害时 |
| 目标获得增益名称(10秒) | 敌人对敌人或玩家附加增益或减益时(后面为效果时间) |

- 治疗、伤害、增益的行按目标排列在引发它们的技能的行下方。对同一目标的治疗和伤害合并为1行，数值相加
- 同一时间内，按预告和咏唱的行(正在准备、预告之后、正在咏唱) → 伤害 → 治疗 → 增益的顺序排列
- 目标为玩家的行，名称前面会显示职业图标。将鼠标悬停在上面会以提示显示职业流派(居合斩等)
- 颜色：敌人的名称、技能的名称、玩家名称、增益的名称和秒数、治疗和伤害的数值为文本颜色的颜色
- 名称：玩家名称遵循设置中的“玩家名称”。没有名称但能看到HP条的敌人显示为“敌方”，无法确定是谁的敌人(启动应用之前就在的敌人等)显示为“未知敌人”
- 没有名称的技能和增益，可以通过设置中的“无名称技能和Buff”选择留空(显示为“某个技能”“攻击”等)或内部名称(中文)(以内部名称显示)
- 预告的行显示预告的名称，咏唱的行显示技能的名称，因此同一技能的名称可能不同

## 操作

- 拖动文字可以跨行选择。Shift+点击可以扩大选择范围，点击可以取消选择。拖动时移出窗口的上下边缘或转动滚轮，会滚动内容
- 有选中的文字时右键点击，可以选择“复制”。窗口处于激活状态时，也可以用Ctrl+C复制
- 复制的文字每行换行一次，时间后面接着正文
- 用滚轮或右侧的滚动条移动。查看最底部期间，会跟随新的行

## 设置

窗口设置和主题在[小组件通用设置](小组件通用设置)中。

### 显示设置

- 敌方治疗：从显示 / 隐藏中选择敌人治疗的行的显示方式(显示)

### 图标颜色

按职业选择职业图标的颜色(包括变身和未知)。默认与玩家列表的颜色相同。

### 文本颜色

实体名称、技能名称、玩家名称、效果、HP数值的文字颜色。

## 注意

- 只显示怪物的行动。不显示玩家、NPC、放置物等的行动，以及玩家受到的伤害
- 增益只在附加的瞬间显示。不显示延长、层数叠加和消失。也不显示由玩家附加的增益扩散出的增益
- 敌人的治疗不计入[HPS计量器](HPS计量器)
- 打开历史记录后，会显示该次战斗的时间轴。记录会与战斗一起保存
- 设置中的“在非战斗区域停止统计”开启(默认)时，在阿斯特里斯、家园庭院、家园房屋中不进行记录
- 与预告的行相同的预告，可以通过[通知](通知(简体中文))的“预兆技能”告知。即使不打开此窗口也会通知
