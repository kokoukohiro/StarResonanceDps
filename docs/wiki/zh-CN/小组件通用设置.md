这是所有小组件通用的窗口规则和设置窗口。各小组件的设置在各自的页面中。

## 小组件的窗口

- 标题栏：窗口上方的一栏。从左到右依次为状态圆点、标题、关闭按钮(×)。部分小组件在关闭按钮的左侧有操作按钮(DPS计量器的“测量”等)
- 底栏：窗口下方的一栏。玩家列表、实体列表、DPS计量器、HPS计量器、承伤日志有底栏
- 移动时：按住标题栏的标题附近拖动
- 调整大小时：按住窗口边缘拖动
- 位置和大小会保存，下次打开时也会显示在相同的位置。玩家信息的大小和装备信息的高度不保存，每次打开时都是默认大小
- 属性详情、增益减益分组、伤害详情、治疗详情、承伤详情、实体信息在行数变化时，窗口的高度会随内容变化
- 点击关闭按钮会关闭该窗口。窗口全部关闭的小组件会变为停止状态

## 状态圆点

窗口标题左侧的圆点。用颜色表示小组件要显示的信息是否充足。

| 颜色 | 状态 |
|---|---|
| 绿色 | 未发现缺少的信息 |
| 黄色 | 部分信息不足。打开队伍界面、点击玩家、重新靠近等即可恢复 |
| 红色 | 在切换地图或重新登录前无法接收信息(无法读取数据时也为红色) |

黄色和红色时，将鼠标悬停在圆点或标题上会显示原因。

| 原因 | 颜色 |
|---|---|
| 无法读取数据 | 红色 |
| 切换地图或重新登录前无法接收信息 | 红色 |
| 重新登录前无法接收过往聊天 | 黄色 |
| 打开队伍界面前无法接收部分信息 | 黄色 |
| 点击该玩家前无法接收部分信息 | 黄色 |
| 重新靠近该玩家前无法接收部分信息 | 黄色 |
| 重新靠近该敌人前无法接收部分信息 | 黄色 |

- 是否显示圆点，可以在[设置](设置)的“小组件状态”中选择
- 在游戏途中启动应用时，在切换地图之前圆点可能会变为红色或黄色

## 固定和鼠标穿透

两者都通过“[小组件](小组件)”中卡片的按钮切换，对该小组件的所有窗口生效。

- 固定：窗口无法移动，也无法改变大小。点击窗口也不会将其激活，因此不会妨碍游戏操作。可以在下面的“窗口设置”中隐藏标题栏和底栏
- 鼠标穿透：窗口不接收鼠标操作，直接传给下方的画面(游戏等)。窗口的按钮和滚动也无法使用
- 置顶：默认情况下，小组件的窗口始终置顶。在设置的“小组件窗口”中选择“仅固定时置顶”后，只有固定的窗口会置顶

## 设置窗口

通过“小组件”中卡片的设置按钮(齿轮)打开。

- 点击左侧的列表会跳转到对应的部分。各部分因小组件而异，“窗口设置”和“主题”所有小组件都有
- 更改的项目会立即反映到小组件的窗口中。设置按小组件保存，对同一小组件的所有窗口生效
- 点击“保存”确定更改并关闭窗口。不保存就关闭时会出现确认窗口，点击“是”会恢复原样
- 点击“初始化”并在确认窗口中点击“是”后，此窗口中的所有项目都会变为初始值。点击“保存”时才会确定

## 窗口设置

- 固定时隐藏标题栏：固定期间隐藏标题栏，该部分的点击会传给下方的画面(开)
- 固定时隐藏底栏：只有带底栏的小组件才有。固定期间同样隐藏底栏(关)
- 窗口不透明度：窗口背景的浓度。文字、数值、条和图标不会变淡。点击窗口使其处于激活状态期间，即使设置得低于50%，也会以50%显示(50%)

## 主题

- 窗体颜色：窗口背景的颜色。“小组件”中的卡片也会使用这个颜色(黑色)
- 背景图像：在窗口背景中显示图像。通过“选择图像”选择。显示图像期间，窗体颜色会显示为未选择的状态。选择颜色后图像会被移除(无)

## 颜色的选择方法

窗体颜色和职业颜色等颜色部分的结构都相同。

- 点击排列的颜色圆点，即可使用该颜色
- 点击“选择颜色”会打开取色器。用“确定”选择的颜色会添加到排列的右侧(最多5个。超过后最左边的颜色会被移除)
- 在取色器中，用方框选择亮度和鲜艳度，用竖条选择色调。也可以输入以#开头的6位颜色代码。也可以从“最近使用的颜色”中选择
