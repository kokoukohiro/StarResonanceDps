这是用插件制作点击“[插件](插件)”中的行时打开的窗口的说明。所有插件都需要的内容，请参阅[插件开发](插件开发)。

## 制作方法

在入口类中实现`IPluginWindowProvider`。有窗口的插件需要`PluginGenre`。

```csharp
using System.Windows;
using System.Windows.Controls;
using StarResonanceDps.PluginSdk;

[assembly: PluginRegistration(typeof(MyPlugin.Plugin), PluginSdkVersion.Current)]
[assembly: PluginDisplayName("ja-JP", "私のプラグイン")]
[assembly: PluginGenre("ja-JP", "ツール")]
[assembly: PluginAuthor("YourName")]
[assembly: PluginVersion("1.0.0")]

namespace MyPlugin;

public sealed class Plugin : IStarResonancePlugin, IPluginWindowProvider
{
    public void Initialize(IPluginContext context)
    {
    }

    public FrameworkElement CreateContent()
    {
        var text = new TextBlock { Text = "Hello", Margin = new Thickness(16) };
        text.SetResourceReference(TextBlock.ForegroundProperty, PluginResourceKeys.Brushes.TextPrimary);
        return text;
    }

    public PluginWindowOptions? GetWindowOptions()
    {
        return new PluginWindowOptions(width: 720, height: 640, minWidth: 480, minHeight: 320);
    }

    public void Shutdown()
    {
    }
}
```

| 成员 | 作用 |
|---|---|
| `CreateContent` | 返回窗口的内容。每次打开窗口都会被调用，因此每次都新建并返回。返回的不是`Window`，而是`UserControl`等元素 |
| `GetWindowOptions` | 返回打开窗口时的大小和最小大小。省略或返回`null`时为应用的默认大小 |

- `CreateContent`返回`null`时，插件会停止
- `PluginWindowOptions`的值都要大于0，大小要不小于最小大小。不符合时会发生`ArgumentOutOfRangeException`，插件会停止
- 内容为`IDisposable`时，会在窗口关闭后调用`Dispose`。请在其中取消事件的订阅和停止计时器
- `CreateContent`、`GetWindowOptions`、`Dispose`在UI线程上被调用。抛出异常时，插件会停止

## 窗口的行为

- 窗口的框和上方一栏(图标、插件名称、最小化、最大化、关闭)由应用制作。内容为上方一栏以下的全部，没有边距和滚动
- 一个插件只有1个窗口。窗口打开时点击行，会将该窗口显示到前台(不调用`CreateContent`)
- 窗口显示在主界面左上角附近。大小和位置不保存。是否打开也不保存，因此下次启动时不会打开
- 窗口不置顶，显示在任务栏中
- 关闭主界面后，插件的窗口也会关闭
- 应用停止插件时，会先关闭窗口并对内容执行`Dispose`，然后取消`Stopping`并调用`Shutdown`

## 外观

- 内容的外观可以自由制作。窗口的背景为设置中“主题”的“窗体颜色”
- 窗口没有设置文字颜色和字体。请为内容中的文字加上应用的颜色(`Brush.TextPrimary`等)和字体(`Font.ProjectDefault`)
- 内容的`DataContext`继承了应用的值。使用绑定时请自己设置

### 应用的外观键

应用的外观可以通过`PluginResourceKeys`的键使用。这里列出的键的名称不会改变。这里没有的键属于应用，可能会在不经预告的情况下更改。

```xml
<TextBlock Text="Hello"
           Foreground="{DynamicResource Brush.TextPrimary}"
           FontFamily="{DynamicResource Font.ProjectDefault}" />
<Button Content="OK" Style="{StaticResource Button.Text}" />
```

- 用`DynamicResource`引用画刷时，会跟随主题颜色的变化。用`StaticResource`引用的画刷会保持变化前的颜色
- 在代码中设置时，使用`SetResourceReference`(上面制作方法中的示例)

| 分组(`PluginResourceKeys`下) | 键 |
|---|---|
| 颜色(`Brushes`) | `Brush.WindowSurface`、`Brush.PanelBackground`、`Brush.Border`、`Brush.BorderSoft`、`Brush.ControlBackground`、`Brush.ControlActiveBackground`、`Brush.InputBackground`、`Brush.InputHoverBackground`、`Brush.TextPrimary`、`Brush.TextSecondary`、`Brush.TextMuted`、`Brush.Success` |
| 文字(`Text`) | `Font.ProjectDefault`、`Text.WidgetWindow`、`Text.WidgetWindowSubtitle`、`Effect.WidgetWindowTextShadow` |
| 按钮和链接(`Buttons`) | `Button.Text`、`Button.Icon`、`Hyperlink.Base`、`Hyperlink.Inline` |
| 输入(`Inputs`) | `Input.PathBox`、`Input.MultilineTextBox`、`Input.SearchBox`、`Input.SelectBox`、`Input.SettingsComboBox`、`Input.SettingsComboBoxItem`、`Input.Switch`、`Input.ValueSlider` |
| 框(`Panels`) | `Surface.RoundedOutline`、`Surface.RoundedButtonOutline`、`Panel.Root`、`Panel.SettingSection`、`Panel.SettingField`、`Panel.SettingFieldLast` |
| 滚动(`Scrolling`) | `ScrollViewer.WidgetList`、`ScrollBar.WidgetList`、`ScrollViewer.WidgetWindow`、`ScrollBar.WidgetWindow` |
| 提示(`ToolTips`) | `ToolTip.Info`、`ToolTip.WidgetWindowInfo`、`ToolTipOwner.Default`、`ToolTipOwner.KeepsOnClick` |
| 尺寸(`Sizes`) | `Radius.Default`、`Radius.Button`、`Padding.Card` |
| 图标(`Icons`) | 绘制方式`Icon.Stroke`(线条)、`Icon.Fill`(填充)，以及形状`Icon.Search`、`Icon.Add`、`Icon.ChevronDown`、`Icon.ChevronRight`、`Icon.Copy`、`Icon.Settings`、`Icon.Filter`、`Icon.Sort`、`Icon.EyeOff`、`Icon.MoreVertical`、`Icon.Help`、`Icon.Wrench`、`Icon.Sliders` |

- 所有键的外观可以在[SampleWindow](https://github.com/kokoukohiro/StarResonanceDps/tree/main/StarResonanceDps.Plugins.Samples/SampleWindow)的窗口中排列查看
- `Text.WidgetWindow`、`Text.WidgetWindowSubtitle`、`Effect.WidgetWindowTextShadow`是用于小组件深色背景的白色文字和阴影
- `ToolTip.WidgetWindowInfo`、`ScrollViewer.WidgetWindow`会读取小组件窗口的颜色，因此只在小组件中使用([插件开发(小组件)](插件开发(小组件)))
- 图标是在`Path`的`Style`中放入绘制方式的键，在`Data`中放入形状的键(`Style="{StaticResource Icon.Stroke}" Data="{DynamicResource Icon.Search}"`)

### 提示

- 要使用与应用相同的提示时，在带提示的元素的`Style`中加上`ToolTipOwner.Default`(点击后会发生某些操作的元素)或`ToolTipOwner.KeepsOnClick`(点击后什么也不会发生的元素)，并在`ToolTip`中放入`ToolTip.Info`的提示
- 一个元素只能有1个`Style`，因此不能用于已加上`Button.Text`等样式的元素

### 无法使用的内容

- 应用的行排序，以及跨行的文字选择和复制，是使用应用类型的机制，因此插件中无法使用
- 没有让用户选择“是”“否”的窗口(消息窗口请参阅[插件开发](插件开发)的“消息”)
