这是只将自己的增益和减益中选择的项目按固定的顺序显示的小组件。没有附加的项目也会显示为“暂无效果”。

## 打开方式

在“[小组件](小组件)”的“增益减益分组”卡片中点击启动按钮。这是只显示自己的窗口，只能打开1个。

## 查看方式

- 标题：“增益减益分组”
- 行：按设置的“增益减益”中开启的行的顺序显示。从左到右依次为图标、名称、剩余时间。层数为2以上时，会在图标上叠加显示数字
- 已附加的行：显示剩余时间和进度条。进度条的颜色，增益的行为增益颜色，减益的行为减益颜色。剩余时间和进度条的查看方式与[增益列表](增益列表)相同
- 未附加的行：在最右边显示“暂无效果”，不显示进度条。时间到时和被解除时也显示“暂无效果”
- 料理和药剂的行，无论附加的是哪种料理或药剂，都显示为“料理”“药剂”1行
- 同一增益由多人附加时，显示剩余时间最长的一个。不显示附加者的名称
- 默认的行中料理和药剂以外的，是在幻想的奥义技能等之后附加的减益。附加期间无法进行以下操作

| 行 | 附加期间 |
|---|---|
| 时间凝滞 | 无法再次受到“奥义！时间法令”的效果 |
| 机械故障 | 无法再次发动“奥义！超导波动” |
| 元素凝滞 | 无法再次受到“奥义！绝命螺旋”的效果 |
| 力竭·烈焰焚身 | 无法再次使用“奥义！烈焰之心” |
| 虚弱·祈愿禁止 | 无法再次受到“奥义！生命祈愿”和职责技能“复苏祷言”的效果 |

## 操作

- 点击行会打开该行的[增益减益卡片](增益减益卡片)。未附加的行也可以打开
- 右键点击行，可以选择以下项目
  - “增益卡片”(减益的行为“减益卡片”)：与点击行时相同
  - “从分组中删除此增益”(减益的行为“从分组中删除此减益”)：移除行。默认的行会变为关闭并保留在设置的列表中，添加的行会从列表中删除
  - “将此增益设为通知目标”“从通知目标中移除此增益”(减益的行为“将此减益设为通知目标”“从通知目标中移除此减益”)：切换通知目标
- 通过右键更改的内容会立即保存
- 按住行拖动可以调整顺序。不拖动直接松开会打开卡片。在窗口外松开或按Esc可以取消
- 添加行时，右键点击自己的[增益列表](增益列表)、[减益列表](减益列表)的行或自己的增益减益卡片，选择“添加至分组”。添加的行会放在最下方
- 缩小窗口时，用滚轮或右侧的滚动条移动

## 设置

窗口设置和主题在[小组件通用设置](小组件通用设置)中。

### 显示设置

- 进度条长度：从自动 / 10秒 / 20秒 / 30秒中选择。自动为该增益的效果时间(自动)

### 增益减益

显示的行。用开关开启或关闭，拖动行可以调整顺序(也可以按住窗口中的行调整顺序)。默认为以下7行。

| 行 | 默认 |
|---|---|
| 料理 | 开 |
| 药剂 | 开 |
| 时间凝滞 | 开 |
| 机械故障 | 开 |
| 元素凝滞 | 开 |
| 力竭·烈焰焚身 | 开 |
| 虚弱·祈愿禁止 | 关 |

添加的行关闭后保存会被删除。默认的行即使关闭也会保留在列表中。

### 通知目标

打开窗口期间，通过[通知](通知(简体中文))的“增益减益效果结束”通知效果结束的增益和减益。默认的行和开关与“增益减益”相同。可以通过行右键菜单的“将此增益设为通知目标”添加。“增益减益”中关闭的行不会通知。

### 增益颜色

增益行的进度条左侧和右侧的颜色(从左到右渐变)，以及增益颜色不透明度(100%)。

### 减益颜色

减益行的进度条左侧和右侧的颜色，以及减益颜色不透明度(100%)。

## 注意

- 在游戏途中启动应用时，在切换地图之前，启动前就已附加的项目可能不完整(窗口标题的圆点为红色)
- 即使打开历史记录，也会显示当前的增益和减益
- 每秒重新读取一次
- 窗口的高度会随行数变化
