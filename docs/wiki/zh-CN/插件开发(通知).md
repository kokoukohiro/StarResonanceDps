这是用插件在“[通知](通知(简体中文))”中添加项目，并在插件决定的时机发出通知的说明。所有插件都需要的内容，请参阅[插件开发](插件开发)。

| 应用负责的内容 | 插件提供的内容 |
|---|---|
| “通知”列表中的行和勾选、文本输入框和预览、通知方式、通知音量、朗读方式、说话人、值的保存 | 项目的定义(名称、默认文本、插入项目、项目的设置)和通知的时机(`Notify`) |

## 制作方法

在入口类中实现`IPluginNotificationProvider`。没有`IPluginWindowProvider`窗口的插件不需要`PluginGenre`。

以下示例在切换地图时发出通知。

```csharp
using StarResonanceDps.PluginSdk;

[assembly: PluginRegistration(typeof(MyPlugin.Plugin), PluginSdkVersion.Current)]
[assembly: PluginDisplayName("ja-JP", "私のプラグイン")]
[assembly: PluginAuthor("YourName")]
[assembly: PluginVersion("1.0.0")]

namespace MyPlugin;

public sealed class Plugin : IStarResonancePlugin, IPluginNotificationProvider
{
    private const string MapEnteredId = "map-entered";

    private IPluginContext? _context;

    public void Initialize(IPluginContext context)
    {
        _context = context;
        context.GameData.MapEntered += OnMapEntered;
    }

    public IReadOnlyList<PluginNotificationDefinition> GetNotificationDefinitions()
    {
        return
        [
            new PluginNotificationDefinition
            {
                Id = MapEnteredId,
                Names = new Dictionary<string, string> { ["ja-JP"] = "マップ移動", ["en-US"] = "Map change" },
                DefaultTexts = new Dictionary<string, string> { ["ja-JP"] = "{MapName}に移動しました", ["en-US"] = "Moved to {MapName}" },
                Fields =
                [
                    new PluginNotificationField
                    {
                        Key = "MapName",
                        Names = new Dictionary<string, string> { ["ja-JP"] = "マップ名", ["en-US"] = "Map name" },
                        SampleValues = new Dictionary<string, string> { ["ja-JP"] = "アステルリーズ" },
                    },
                ],
            },
        ];
    }

    private void OnMapEntered(object? sender, EventArgs e)
    {
        if (_context is null || !_context.Notifications.IsEnabled(MapEnteredId))
        {
            return;
        }

        int? sceneId = _context.GameData.Session.SceneId;
        string? mapName = sceneId is int id ? _context.Names.GetSceneName(id) : null;
        _context.Notifications.Notify(MapEnteredId, new Dictionary<string, string> { ["MapName"] = mapName ?? string.Empty });
    }

    public void Shutdown()
    {
        if (_context is not null)
        {
            _context.GameData.MapEntered -= OnMapEntered;
        }
    }
}
```

| 成员 | 调用时机 | 作用 |
|---|---|---|
| `GetNotificationDefinitions` | `Initialize`之后调用1次(有小组件的定义时在其之后) | 返回要添加的项目的列表。按返回的顺序排列在“通知”中。之后更改也不会反映 |

- 返回空列表时，“通知”中不会添加任何内容

### 项目的定义(`PluginNotificationDefinition`)

| 属性 | 是否必需 | 内容 |
|---|---|---|
| `Id` | 必需 | 项目的ID。为1～128个字符的英文字母、数字和“.”“-”“_”。这是保存用的键，因此不要在版本之间更改 |
| `Names` | 必需 | 显示在“通知”列表中的项目名称 |
| `DefaultTexts` | 必需 | 在用户填写文本之前使用的文本。插入项目写为`{Key}` |
| `Fields` | 可选 | 插入项目(`PluginNotificationField`) |
| `Settings` | 可选 | 项目的设置。种类与小组件的设置相同，只有颜色(`PluginColorSetting`)不能使用([插件开发(小组件)](插件开发(小组件))的“设置”) |

| 插入项目(`PluginNotificationField`)的属性 | 是否必需 | 内容 |
|---|---|---|
| `Key` | 必需 | 1～64个字符的英文字母和数字(不能使用“.”“-”“_”)。在文本中写为`{Key}` |
| `Names` | 必需 | 在“通知”中显示在插入项目下拉列表中的名称 |
| `SampleValues` | 必需 | 放入预览中的示例值。空字典也可以 |

- 各语言的文字用以语言名称(`ja-JP`等)为键的字典书写。选择方式与特性相同([插件开发](插件开发)的“入口类和特性”)
- 项目的`Id`在插件中，插入项目的`Key`和设置的`Id`在项目中，都不要重复。不区分大小写

## 发出通知

使用`IPluginContext.Notifications`(`IPluginNotificationService`)。

| 成员 | 内容 |
|---|---|
| `IsEnabled(id)` | 用户是否勾选了该项目 |
| `Notify(id, values)` | 发出通知。`values`为插入项目的`Key`和值。可以省略 |
| `GetSettings(id)` | 项目的设置的当前值(`PluginSettingValues`)。读取方法与小组件的设置相同 |
| `SettingsChanged` | 项目的勾选或设置的值变化时在UI线程上触发的事件。值为项目的`Id` |

- `IsEnabled`、`Notify`、`GetSettings`可以从任何线程调用
- 项目在`Initialize`之后读取，因此在`Initialize`和`GetNotificationDefinitions`中，任何`Id`都会成为`ArgumentException`。订阅`SettingsChanged`没有问题
- 传入定义中没有的`Id`或`Fields`中没有的`Key`时，会成为`ArgumentException`
- 在通知的时刻取消了勾选时，`Notify`什么也不做。生成值比较费事时，请先查看`IsEnabled`
- 文本为用户的文本，没有时为显示语言的默认文本。`{Key}`会被替换为值，没有传入值的项目为空。定义中没有的`{…}`会保持原样。文本为空时不会通知
- 不会返回是否已通知。无法显示Windows通知或无法使用语音时也不会成为异常，会记录在应用的日志中
- 应用不会减少通知的次数。每次调用都会通知，朗读和通知声音逐条依次播放。为了不在短时间内多次调用，请在插件中设置间隔和上限
- 插件停止后，`Notify`什么也不做

### 项目的设置

- 值在“通知”中更改时会立即保存，并触发`SettingsChanged`。开关和下拉列表在更改时，数字在确定时(按Enter或离开输入框时)，文字在输入结束0.3秒后，滑块在松开滑块按钮时
- `SettingsChanged`只在该项目的勾选或设置的值与之前不同时触发。更改文本、通知方式、通知音量、声音时不会触发
- 启动应用时不会触发，因此请用`IsEnabled`、`GetSettings`读取初始值

## 在“通知”中的显示方式

- 在列表中应用项目的后面，加上插件名称的标题后排列。插件按安装的顺序，插件中按定义的顺序
- 项目最初未勾选。插件无法一开始就勾选
- 右上方文本输入框下的下拉列表中会排列插入项目的名称，可以用“插入”放入`{Key}`。预览中会放入示例值
- 右下方的项目设置排列在通知方式的上方
- Windows通知中显示应用的名称和图标。不显示插件的名称
- 值由应用保存在`Data\AppSettings.json`中(与插件文件夹中的设置文件分开)。插件停止后也会保留，删除后会被删除，更新后会保留
- 更改项目的`Id`或程序集名称后，会成为另一个项目，之前的值不会继承

## 错误和异常

- 定义有误(ID或键的形式和重复、数字或滑块的范围、颜色的设置等)时，插件会停止，“[插件](插件)”中行的提示会显示“通知项目的结构有误”。原因会以英语写入日志
- `GetNotificationDefinitions`和`SettingsChanged`中的异常也会使插件停止
- 项目名称、默认文本、插入项目的名称为空时，生成会停止(SRDPS014)
