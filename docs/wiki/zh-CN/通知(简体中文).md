这是用于通过Windows通知或朗读告知游戏中发生的事情的页面。可以按项目决定是否通知、通知文本和通知方式。

## 查看方式

- 中间：通知的项目。只通知左侧勾选的项目(默认全部关闭)
- 右上：所选项目的文本和“预览”(填入示例名称后的文本)
- 右下：所选项目的设置和通知方式

## 操作

- 点击项目后，该项目的文本和设置会显示在右侧
- 文本：填写通知的文本。在下拉列表中选择项目并按“插入”后，光标位置会插入`{PlayerName}`等文字，通知时会替换为名称等内容。留空时使用默认文本通知
- 更改的内容会立即保存

### 项目

| 项目 | 通知时机 | 默认文本 |
|---|---|---|
| 入场确认 | 匹配成功时，以及队伍成员开始进入玩法时(游戏中打开入场确认界面时) | 即将进入{Content} |
| HP降低 | “目标玩家”的HP降到“HP降低判定”的比例以下的状态持续了“通知条件”的秒数时。在此期间HP恢复或被击败时不会通知 | {PlayerName}的HP降低了 |
| 玩家出现 | 名称或UID与目标一致的玩家出现在附近时 | {PlayerName}出现了 |
| 实体出现 | 名称或ID与目标一致的敌人出现在附近时 | {EntityName}出现了 |
| 被锁定玩家 | “目标实体”的敌人锁定“目标玩家”的状态持续了“通知条件”的秒数时 | {PlayerName}成为了{EntityName}的攻击目标 |
| 增益减益效果结束 | 运行中的[增益减益卡片](增益减益卡片)或[增益减益分组](增益减益分组)中显示的增益或减益因时间到而消失时 | {TargetName}的{BuffName}效果已结束 |
| 药剂·料理效果结束 | 药剂或料理增益的剩余时间低于“通知条件”的时间时 | {TargetName}的{BuffName}效果即将结束 |
| 预兆技能 | 首领的技能中，游戏会显示预告或警告的技能即将到来时 | {SkillName}来袭 |
| 实体吟唱 | 有HP条的敌人开始吟唱名称或ID与目标一致的技能时 | {EntityName}正在吟唱 |
| 私聊 | 收到其他玩家的私聊时。在游戏中打开了与该玩家的私聊时不会通知 | 收到{PlayerName}的私聊 |
| 世界聊天 | 世界聊天的发言中包含全部匹配关键词时 | 收到{PlayerName}的招募 |

### 各项目的设置

- HP降低
  - 目标玩家：全部 / 仅队伍成员 / 非队伍成员 / 仅自己(全部)
  - HP降低判定：HP45% / HP35% / HP25% / HP15% / HP5%(HP15%)
  - 通知条件：无条件 / HP降低状态1秒以上 / HP降低状态2秒以上 / HP降低状态3秒以上(HP降低状态3秒以上)
- 玩家出现
  - 目标玩家名称、目标玩家UID：要通知的玩家(空)。可用“|”分隔输入多个。输入UID后将优先于名称
- 实体出现
  - 目标实体名称、目标实体ID：要通知的敌人(空)。可用“|”分隔输入多个。输入ID后将优先于名称。ID可通过设置中的“内部ID”显示，ID和名称可从[时间轴](时间轴)复制
- 被锁定玩家
  - 目标玩家：全部 / 队伍成员 / 守护职业以外 / 守护职业以外的队伍成员(守护职业以外)
  - 目标实体：仅首领 / 首领和精英 / 全部(仅首领)
  - 通知条件：无条件 / 被锁定状态1秒以上 / 被锁定状态2秒以上 / 被锁定状态3秒以上(被锁定状态3秒以上)
- 增益减益效果结束
  - 要通知的增益和减益在卡片和分组设置的“通知目标”中选择。也可以在卡片或分组的行上右键切换
- 药剂·料理效果结束
  - 通知条件：效果1分钟以下 / 效果2分钟以下 / 效果5分钟以下 / 效果10分钟以下(效果2分钟以下)
- 预兆技能
  - 通知条件：发动时 / 发动前1秒 / 发动前2秒 / 发动前3秒(发动时)。有预告的技能以预告结束、技能发动的时刻为基准通知。只显示警告的技能与通知条件无关，在技能开始时通知
- 实体吟唱
  - 目标技能名称、目标技能ID：要通知的技能(空)。可用“|”分隔输入多个。输入ID后将优先于名称
- 世界聊天
  - 匹配关键词：要通知的发言中包含的词语(空)。用空格分隔输入多个时，只通知包含全部关键词的发言

### 通知方式(所有项目通用)

- 通知方式：Windows通知 / 朗读(Windows通知)
- 通知音量：Windows通知的提示音和朗读的音量(100%)。设为0%时，Windows通知不发出声音，朗读不会朗读
- 朗读方式：Windows语音 / VOICEVOX(Windows语音)。通知方式为朗读时显示
- 说话人、风格：选择VOICEVOX的声音。朗读方式为VOICEVOX时显示(风格只在说话人有2种以上风格时显示)

## 注意

- “增益减益效果结束”和其他玩家的“药剂·料理效果结束”只在小组件运行时通知。其他项目即使没有打开小组件也会通知
- 玩家出现、实体出现、实体吟唱、世界聊天如果不填写名称、ID或匹配关键词，即使开启也不会通知
- 名称会应用设置中的“玩家名称”(“隐藏”时为`*****`)
- 游戏中可能会因Windows的“自动打开请勿打扰”而收不到Windows通知。收不到时，请在Windows设置的“通知”中关闭玩游戏时和全屏时的相关项目
- 朗读按到达的顺序逐条进行，不会重叠
- Windows语音使用应用显示语言的声音朗读。如果Windows中没有安装该语言的语音，则无法朗读
- 应用中不包含VOICEVOX。使用时请安装[VOICEVOX](https://voicevox.hiroshiba.jp/)并保持其运行(可以在[设置](设置)的“启动设置”中设为随应用一起启动)。仅支持日语
- 请按照各说话人的使用条款使用VOICEVOX的声音。可以通过说话人一行中的“(说话人名称)的使用条款”确认
