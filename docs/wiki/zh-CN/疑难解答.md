本页按症状介绍遇到问题时的原因和解决方法。无法解决时，请通过“[反馈](反馈)”报告。

## 无法启动

### 出现英文窗口且无法启动

“You must install .NET to run this application.”等英文窗口，会在没有安装.NET 10桌面运行时的情况下出现。请通过[安装与更新](安装与更新)中的“所需环境”进行安装。

### 出现“安装Npcap”后退出

在未安装Npcap，或无法检测到其版本时出现。无论点击哪个按钮，应用都会退出。请从点击“是”后打开的Npcap页面安装Npcap，然后重新启动应用([初始设置](初始设置))。

### 出现“启动错误”后退出

- “无法启动应用。”：无法写入应用文件夹中的`Data`。请检查窗口中显示的文件夹的写入权限和安全软件的设置，或将整个应用文件夹移到可写入的位置
- “初始化失败。”：应用的数据文件可能缺失或已损坏。请从更新日志获取zip，并覆盖到应用的文件夹。设置和战斗历史记录会保留

### 出现“错误”后退出

发生了意外错误。请重新启动。反复出现时，请通过“[反馈](反馈)”报告。

### 启动后没有出现新窗口

应用只能同时运行一个。应用已在运行时，不会再启动新的应用，而是将正在运行的应用的主界面显示到前台。

## 启动时出现窗口

### 出现用户帐户控制

启动快捷键辅助程序时出现。选择“是”即可使用快捷键。不使用快捷键时，在设置的“启动设置”中关闭“应用启动时运行快捷键辅助程序”后，就不会再出现。

### 出现“快捷键错误”

- “快捷键已停用。”：辅助程序未能启动，或已中途停止。请重新启动应用，并在用户帐户控制中选择“是”
- “无法设置以下快捷键。”：窗口中显示的按键正被其他应用使用。请在设置的“快捷键”中分配其他按键

### 出现“Npcap更新”

Npcap版本低于1.86时，每次启动都会出现。旧版本存在电脑停止响应的问题。应用可以照常使用，但请更新到1.86或更高版本。

### 出现“设置读取错误”

由于设置文件已损坏或无法读取，应用已以初始值启动。窗口中显示的文件会在下次保存设置时被覆盖。请根据需要重新进行设置。

### 出现“启动设置错误”

在设置的“启动设置”中开启了“Windows启动时运行应用”，但无法添加到Windows启动项时出现。请检查安全软件是否阻止了添加到启动项。

### 出现“插件错误”

有无法加载的插件。请重新安装该插件，或告知作者([插件](插件))。

## 什么都不显示

### 所有小组件都不显示任何内容

未能读取游戏通信。

- 请将设置中的“游戏执行文件”设为“自动”
- 请在“监听网卡”中选择游戏通信经过的网卡。如果在应用启动后切换了有线和无线网络，请重新启动应用
- 确认是否已读取的方法请参阅[初始设置](初始设置)

### 不显示数值或只显示自己

- 默认在阿斯特里斯、家园庭院、家园房屋中不进行统计([设置](设置)中的“统计设置”)
- 计量器的底栏中显示“[测量中]”时，表示正在测量。测量期间只统计自己的数据。点击“停止测量”即可恢复([统计](统计))
- 请检查是否在计量器显示设置的“筛选设置”中限制了显示的玩家

### 数值不变化

- “[统计](统计)”的左上角显示“历史显示中”时，表示当前打开的是历史记录。再次点击已打开的历史记录行，即可返回当前战斗
- 计量器的底栏中显示“[测量完成]”时，表示测量时间已结束。点击“停止测量”即可恢复

## 信息不足

### 状态圆点变为黄色或红色

将鼠标悬停在圆点或标题上即可显示原因([小组件通用设置](小组件通用设置))。如果在登录游戏后才启动应用，请切换一次地图。

### 名称显示为“UID:编号”

这是尚未收到名称的玩家。重新靠近该玩家，或在游戏中点击该玩家，即可显示名称。

### 名称显示为职业名称

助战NPC会以职业名称代替名称显示。

### 职业显示为“未知”“一阶”

“未知”表示尚未确定的状态。该玩家来到附近后即可确定。“一阶”表示未设置天赋的状态。

### 在家园庭院中自己显示为“一阶”“未启用”

在家园庭院中，游戏不会附加料理和药剂以外的增益，因此无法确定自己的职业和深眠心相仪。前往其他地点后即可恢复。

## 窗口看不到或无法点击

### 小组件没有标题栏或无法移动

小组件已固定。默认情况下，固定期间会隐藏标题栏。在“[小组件](小组件)”的卡片中解除固定后，标题栏就会出现，并可以移动。

### 无法点击小组件

已开启鼠标穿透。请在“[小组件](小组件)”的卡片中解除。

### 小组件被游戏遮挡

设置中的“小组件窗口”为“仅固定时置顶”时，未固定的窗口会被游戏遮挡。请改回“始终置顶”，或将窗口固定。

### 小组件移到了屏幕外

在“[小组件](小组件)”的卡片中停止后重新启动，小组件就会出现在屏幕内。

### 小组件的显示突然改变

请确认是否按下了快捷键。以下是默认按键会引起的变化及恢复方法([快捷键](快捷键))。

| 发生的情况 | 按键 | 恢复方法 |
|---|---|---|
| 运行中的小组件全部关闭 | Ctrl+F8 | 在“小组件”的卡片中启动 |
| 无法移动窗口、标题栏消失 | Ctrl+F7 | 再按一次 |
| 无法点击窗口 | Ctrl+F6 | 再按一次 |
| 窗口被游戏遮挡 | Ctrl+F5 | 再按一次 |
| 名称变为`*****` | Ctrl+F11 | 再按一次 |
| 计量器被清空，底栏中显示“[测量中]” | Ctrl+F10 | 再按一次 |
| 计量器被清空 | Ctrl+F9 | 之前的统计可从“[统计](统计)”的历史记录中打开 |

### 关闭主界面后小组件也关闭了

关闭主界面后，应用会退出。如果只想显示小组件，请将主界面最小化。

## 名称或数值不一致

### 技能名称显示为中文

游戏中没有显示名称的技能会以内部名称(中文)显示。也可以通过设置中的“无名称技能和Buff”改为留空。

### 数值与游戏内的计量器不同

- 每秒数值是用合计除以战斗经过时间得到的值。由于经过时间的计算方式与游戏不同，每秒数值可能会略有差异
- 治疗按实际增加的HP统计。回复药、料理和自然恢复也会计入([HPS计量器](HPS计量器))

## 快捷键不起作用

- 快捷键只在游戏或本应用位于前台时有效
- 在用户帐户控制中选择了“否”时，本次运行期间无法使用。请重新启动应用并选择“是”
- 在设置的“启动设置”中关闭了“应用启动时运行快捷键辅助程序”时，无法使用
- 无法分配其他应用正在使用的按键。请分配其他按键
- 游戏位于前台却不起作用时，请将设置中的“游戏执行文件”设为“自动”。应用通过此设置判断游戏是否位于前台
- 详情请参阅[快捷键](快捷键)

## 收不到通知或不朗读

- 部分通知项目只在小组件运行时才会通知([通知](通知(简体中文))中的“注意”)
- 游戏中收不到Windows通知时，请在Windows设置的“通知”中，关闭“自动打开请勿打扰”中玩游戏时和在全屏模式下使用应用时的项目
- 朗读方式为VOICEVOX时，请事先启动VOICEVOX。VOICEVOX未运行时，启动时等情况下会出现“VOICEVOX连接错误”窗口。游戏中未能朗读时不会出现窗口，而是在“[日志](日志)”中留下警告行
- 出现“VOICEVOX启动错误”时，请检查设置的“启动设置”中的“安装路径”
- 出现“Windows语音”窗口时，请在Windows设置中添加窗口中显示的语言的语音

## 无法更新

- “更新错误”窗口的详细信息中会显示解决方法
- 更新停在“正在等待占用的文件释放…”时，请关闭打开了应用文件夹的文件资源管理器等程序
- 无法正常更新时，请从更新日志获取zip，并覆盖到应用的文件夹([安装与更新](安装与更新))

## 插件无法运行

将鼠标悬停在“[插件](插件)”中插件行的“错误”标记上，即可显示原因。

## 无法打开历史记录

“历史读取错误”会在找不到该历史记录的数据或数据已损坏时出现([统计](统计))。

## 报告问题

- 在“[反馈](反馈)”中点击“问题反馈与功能建议”，会打开已填入应用版本等信息的提交页面
- 应用无法启动时，请通过[GitHub提交页面](https://github.com/kokoukohiro/StarResonanceDps/issues/new?template=feedback.yml)报告。请在环境栏中填写Windows和应用的版本
- 被要求提供日志时，请附上应用文件夹中的`Data\CombatRuntime.log`([日志](日志))
