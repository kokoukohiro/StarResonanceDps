这是汇总查看实体列表中一个敌人的HP、吟唱、正在锁定的玩家和仇恨、增益和减益的小组件。

## 打开方式

- 点击[实体列表](实体列表)的行，或右键点击行并选择“实体信息”
- 也可以通过“[小组件](小组件)”的“实体信息”卡片打开。名称栏的下拉列表中会按相同的顺序显示与实体列表相同的敌人(默认为第1个敌人)。没有敌人时，会打开等待敌人出现的空窗口，并显示出现的敌人
- 按敌人打开窗口。同一敌人的窗口已打开时，会将该窗口显示到前台

## 查看方式

- 标题：“实体信息 - 敌人的名称”
- 第1行：与实体列表的行相同(不显示分数)。吟唱期间，名称右侧会显示技能名称，最右边会显示吟唱条。HP条的长度会随窗口的宽度变化
- 第2行：当前正在锁定的玩家，以及按仇恨从高到低排列的玩家。标记和进度条的查看方式与实体列表的仇恨栏位相同。放不下时会换行
- 再下方：排列敌人身上的增益，然后换行排列减益。栏位上方显示名称(显示设置的“增益名称”)，图标上叠加显示层数(2层以上时)，图标下方显示剩余秒数
- 增益和减益的顺序：优先显示列表中开启的项目在最前面(按列表的顺序)，其余按附加的顺序排列
- 敌人不在附近期间(被击倒、离开)不显示任何内容。同一敌人回来后会再次显示

## 操作

- 点击增益的栏位会打开该敌人的[增益列表](增益列表)，点击减益的栏位会打开[减益列表](减益列表)
- 右键点击栏位，可以选择“增益列表”“增益卡片”“优先显示此增益”(优先显示中为“取消优先显示此增益”)“隐藏此增益”(减益的栏位为“减益列表”“减益卡片”和对应的减益项目)。优先显示和隐藏会立即保存
- 将鼠标悬停在上面时，增益和减益的栏位会显示名称，战斗状态标记会显示“交战中”，仇恨栏位会显示“职业(被锁定为目标)”“职业(仇恨值: 数值)”的提示
- 缩小窗口时，用滚轮或右侧的滚动条移动

## 设置

窗口设置和主题在[小组件通用设置](小组件通用设置)中。

### 显示设置

- 实体名称：填写名称栏中显示的内容。写法与[实体列表](实体列表)的“实体名称”相同，数值分别保存(`Lv.{Level} {EntityName}`)
- 增益名称：填写增益和减益栏位的名称中显示的内容(`{BuffName}({CasterName})`)

| 项目 | 文字 | 显示的内容 |
|---|---|---|
| 增益名称 | `{BuffName}` | 增益的名称 |
| 目标名称 | `{TargetName}` | 敌人的名称 |
| 施加者玩家名称 | `{CasterName}` | 附加增益的玩家的名称。用设置中的“玩家名称”隐藏时为`*****` |
| 等级 | `{Level}` | 敌人等级的数值 |

- HP数值：从护盾量合并显示 / 护盾量单独显示中选择(护盾量合并显示)
- 战斗状态：从显示 / 隐藏中选择战斗状态标记的显示方式(显示)
- 被锁定玩家：是否在第2行的最左边显示当前正在锁定的玩家(显示)
- 仇恨值：从显示全部 / 显示前5名 / 显示前4名 / 显示前3名 / 显示前2名 / 仅显示仇恨第1名中选择第2行显示的人数(显示全部)
- 同类增益显示：从不合并 / 合并中选择。不合并会将玩家附加的增益按附加的人分成不同的栏位(不合并)
- 显示施加者玩家名称：从显示 / 隐藏 / 仅他人施加中选择(仅他人施加)

### 优先显示列表

显示在最前面的增益和减益。用开关开启或关闭，拖动行可以调整顺序。默认为“重伤”和2个“禁疗”，全部开启。可以通过栏位右键菜单的“优先显示此增益”添加。添加的行关闭后保存会被删除。

### 隐藏列表

不显示的增益和减益。通过栏位右键菜单的“隐藏此增益”添加。关闭开关并保存后，会从列表中删除，并再次显示。

### 图标颜色

选择类型图标和仇恨栏位中职业图标的颜色。行和默认颜色与实体列表相同。

## 注意

- 窗口会追踪打开时的那一个敌人
- 增益和减益每秒重新读取一次
- 启动应用之前就在附近的敌人，或者敌人的信息仍然不足时，窗口标题的圆点为黄色。重新靠近该敌人即可恢复
- 窗口的高度会随行数变化
- 即使打开历史记录，也会显示当前的敌人
