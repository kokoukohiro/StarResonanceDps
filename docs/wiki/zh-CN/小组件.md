这是用于启动、停止、固定叠加显示在游戏画面上的窗口(小组件)的页面。打开应用后最先显示此页面。

## 查看方式

- 上方一栏：从左到右依次为搜索框、排序、三点菜单
- 卡片：每个小组件一张。左侧的圆点表示状态，右侧的按钮从左到右依次为收藏、固定、鼠标穿透、设置、启动/停止

| 圆点颜色 | 状态 |
|---|---|
| 灰色 | 窗口未打开(已停止) |
| 绿色 | 窗口已打开，未发现缺少的信息 |
| 黄色 | 窗口已打开，部分信息不足 |
| 红色 | 窗口已打开，在切换地图或重新登录前无法接收信息(无法读取数据时也为红色) |

- 打开了2个以上的窗口时，显示其中最差的颜色。原因可以通过窗口标题左侧的圆点确认([小组件通用设置](小组件通用设置))
- 按对象打开窗口的小组件(玩家信息等)在打开了1个以上的窗口时，会显示已打开的窗口数量来代替圆点
- 按对象打开窗口的小组件在有可选对象时，名称栏会变为选择对象的下拉列表。栏中显示以所选对象打开的窗口的标题
- 卡片顺序(默认)：[玩家列表](玩家列表)、[实体列表](实体列表)、[玩家信息](玩家信息)、[实体信息](实体信息)、[属性详情](属性详情)、[装备信息](装备信息)、[天赋信息](天赋信息)、[深眠心相仪信息](深眠心相仪信息)、[模组信息](模组信息)、[增益列表](增益列表)、[减益列表](减益列表)、[增益减益卡片](增益减益卡片)、[增益减益分组](增益减益分组)、[复活列表](复活列表)、[时间轴](时间轴)、[DPS计量器](DPS计量器)、[HPS计量器](HPS计量器)、[仇恨计量器](仇恨计量器)、[破韧计量器](破韧计量器)、[承伤日志](承伤日志)、[技能详情(伤害)](技能详情(伤害))、[伤害详情](伤害详情)、[DPS趋势图表](DPS趋势图表)、[技能详情(治疗)](技能详情(治疗))、[治疗详情](治疗详情)、[HPS趋势图表](HPS趋势图表)、[技能详情(仇恨值)](技能详情(仇恨值))、[TPS趋势图表](TPS趋势图表)、[技能详情(破韧值)](技能详情(破韧值))、[BPS趋势图表](BPS趋势图表)、[承伤详情](承伤详情)、[聊天](聊天)。插件的小组件排在其后

## 操作

- 搜索框：只显示名称栏中包含输入文字的卡片。不区分大小写
- 排序：从“默认”、“名称排序”、“收藏”、“运行状态”、“固定”、“鼠标穿透”中选择(默认：“默认”)。选择“收藏”到“鼠标穿透”时，带有对应设置的卡片会排在上方
- 三点菜单：启动收藏 / 停止全部 / 固定运行中 / 全部解除固定 / 固定项开启鼠标穿透 / 全部解除鼠标穿透
- 卡片的按钮
  - 收藏：添加到收藏。用三点菜单的“启动收藏”可以一并启动已收藏的小组件
  - 固定：使窗口无法移动，也无法改变大小。点击窗口也不会将其激活，因此不会妨碍游戏操作。默认情况下，固定期间会隐藏标题栏
  - 鼠标穿透：窗口不接收鼠标操作，直接传给下方的画面(游戏等)
  - 设置：打开该小组件的设置窗口
  - 启动/停止：打开窗口。已打开时则关闭。按对象打开窗口的小组件只打开或关闭所选对象的窗口
- 名称栏的下拉列表：选择后，所选对象会显示在栏中。按下启动按钮时才会打开窗口

## 注意

- 收藏、固定、鼠标穿透会保存。搜索、排序以及在下拉列表中选择的对象不会保存
- 在运行状态下关闭应用的小组件，下次启动时会再次打开。通过窗口的×或停止按钮关闭的小组件会变为停止状态
- 开启鼠标穿透的窗口中，窗口的按钮和滚动也无法使用。请通过卡片的按钮、三点菜单或[快捷键](快捷键)解除
- 三点菜单的操作也可以通过[快捷键](快捷键)进行(默认：Ctrl+F8、Ctrl+F7、Ctrl+F6)。快捷键可用时，菜单项后面会显示按键
- 窗口是始终置顶，还是仅固定的窗口置顶，可以在[设置](设置)的“小组件窗口”中选择
- 窗口的移动方法、大小的调整方法以及设置窗口的通用项目，请参阅[小组件通用设置](小组件通用设置)
