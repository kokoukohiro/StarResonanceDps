![减益列表](images/zh-CN/DebuffList1.png)

这是将一名玩家或一个敌人身上的减益，连同剩余时间和进度条每行一个排列显示的小组件。结构与[增益列表](增益列表)相同，设置与增益列表分开保存。

## 打开方式

- 在“[小组件](小组件)”的“减益列表”卡片中，从名称栏的下拉列表中选择对象，然后点击启动按钮。排列顺序与增益列表相同(默认为自己)
- 右键点击[玩家列表](玩家列表)、[复活列表](复活列表)、[实体列表](实体列表)的行，选择“减益列表”也可以打开。点击[实体信息](实体信息)的减益栏位也可以打开
- 按对象打开窗口。同一对象的窗口已打开时，会将该窗口显示到前台

## 查看方式

- 标题：“减益列表 - 对象的名称”
- 行的查看方式与[增益列表](增益列表)相同。默认情况下，敌人的窗口会将玩家附加的减益按附加的人每人1行显示，并附上附加者的名称(图中为2名玩家附加给首领的减益)
- 顺序：优先显示列表中开启的减益在最前面(按列表的顺序)，其余按附加的顺序排列(新的在下方)

## 操作

- 点击行会打开该减益的[增益减益卡片](增益减益卡片)
- 右键点击行，可以选择“减益卡片”“优先显示此减益”(优先显示中为“取消优先显示此减益”)“隐藏此减益”。在自己的窗口中还会显示“添加至分组”“添加到增益减益卡片快捷方式”。作用与增益列表相同
- 行在窗口中放不下时，用滚轮或右侧的滚动条移动

## 设置

窗口设置和主题在[小组件通用设置](小组件通用设置)中。

### 显示设置

项目和可插入的文字与[增益列表](增益列表)相同。默认值为：增益名称为`{BuffName}({CasterName})`，进度条长度为30秒，同类增益显示为仅合并玩家，显示施加者玩家名称为仅他人施加。

### 优先显示列表

显示在最前面的减益。用开关开启或关闭，拖动行可以调整顺序。默认为以下6行。

| 行 | 默认 |
|---|---|
| 时间凝滞 | 关 |
| 机械故障 | 关 |
| 元素凝滞 | 关 |
| 重伤 | 开 |
| 禁疗(“奥义！地狱突刺”的减益) | 开 |
| 禁疗(职责技能“地狱突刺”的减益) | 开 |

可以通过行右键菜单的“优先显示此减益”添加。添加的行关闭后保存会被删除。

### 隐藏列表

不显示的减益。通过行右键菜单的“隐藏此减益”添加。关闭开关并保存后，会从列表中删除，并再次显示。

### 减益颜色

进度条左侧和右侧的颜色(从左到右渐变)，以及减益颜色不透明度(100%)。

## 注意

- 注意事项与[增益列表](增益列表)相同
- 优先显示和隐藏按减益的编号决定。即使名称相同，编号不同的减益(2个“禁疗”等)也会分别处理
