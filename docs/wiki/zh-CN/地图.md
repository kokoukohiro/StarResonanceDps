这是在自己所在地图上显示自己、附近的玩家和敌人以及队伍成员位置的小组件。

## 打开方式

- 在“[小组件](小组件)”的“地图”卡片中点击启动按钮。窗口只有1个
- [玩家信息](玩家信息)的当前位置带有下划线时，点击后会打开窗口，并以该玩家为中心显示。是在其他地图的队伍成员时，显示那张地图
- 点击[聊天](聊天)中共享位置的链接，会打开窗口并在该位置放置位置标记

## 查看方式

- 地图：以自己为中心显示自己所在地图。切换地图后，会换成移动后的地图。有层的地图显示自己所在层的地图。没有地图图像的地图只显示图标
- 玩家：以职业图标显示。战斗中的玩家显示为带白色边框的小圆。自己显示为指向面朝方向、带白色边框的三角形(显示设置的“简化显示交战中玩家”)。通过显示设置的“始终简化显示自己”，可以让自己在不在战斗中时也显示为三角形
- 敌人：首领显示为首领图标，其他敌人显示为没有边框的小圆。颜色全部为图标颜色中“实体”的颜色
- 分数：在通过空间调查收集分数的副本中，不在战斗中的敌人的圆上方会显示该敌人的分数(“60分”等)。首领的分数显示在图标中央
- 名称：显示在图标下方。在显示设置中选择显示名称的对象。不显示名称的图标，将鼠标悬停在上面时也会以提示显示名称
- 场地标记：以与游戏相同的图像显示副本中队长放置的1~6的标记(“场地标记01”~“场地标记06”)。与层无关都会显示
- 位置标记：显示在通过聊天链接共享的位置
- 底栏：左侧为显示中的地图名称(有分线时会以“12线”的形式附上)，右侧为“实体”和“玩家”的数量。数量是经过显示设置筛选后、在该地图上的对象数量(也包括窗口外的对象)。通过空间调查收集分数期间，会变为“交战中”(战斗中的敌人的分数合计)和“当前”(当前的分数)

## 操作

- 滚轮：放大或缩小地图。放到最大时窗口的短边为20m，缩到最小时能放下整张地图。打开时为200m，缩放程度不保存
- 拖动地图可以改变显示的位置(只限地图超出窗口的方向)。自己移动后，会回到以自己为中心
- 在没有图标的地方双击，会立即回到以自己为中心
- 点击玩家的图标会打开该玩家的[玩家信息](玩家信息)。点击敌人的图标会在[目标信息](目标信息)中显示该敌人
- 显示其他地图，或通过链接共享的其他层时，标题栏会显示“返回自己所在的地图”。点击后会回到自己所在的地图和层
- 右键点击可以选择“返回自己所在的地图”(显示其他地图或层时)和“清除位置标记”(有位置标记时)
- 显示通过链接共享的其他地图或层时，即使自己移动、拖动地图或双击，也会一直显示该位置。只有点击“返回自己所在的地图”或切换地图时才会返回

## 设置

窗口设置和主题在[小组件通用设置](小组件通用设置)中。

### 显示设置

- 玩家：从全部显示 / 仅队伍成员 / 非队伍成员 / 仅自己中选择显示的玩家(全部显示)
- 实体：从全部显示 / 隐藏物件中选择。隐藏物件不显示游戏中看不到HP条的敌人(隐藏物件)
- 玩家名称：从全部显示 / 仅显示队伍成员 / 显示非队伍成员 / 仅显示自己中选择显示名称的玩家。不显示名称的玩家只显示图标(全部显示)
- 实体名称：从显示 / 隐藏中选择是否显示敌人的名称(隐藏)
- 交战中隐藏名称：从全部 / 仅玩家 / 仅实体 / 不隐藏中选择战斗中不显示名称的对象(全部)
- 简化显示交战中玩家：将战斗中的玩家显示为带白色边框的小圆(自己为三角形)。关闭后，战斗中也显示职业图标(开)
- 始终简化显示自己：即使不在战斗中，也将自己显示为带白色边框的三角形(关)
- 地图不透明度：以0~100%选择地图图像的浓淡。与窗口的不透明度无关，按此浓淡显示(100%)

### 图标颜色

第1行的“实体”是敌人的图标和圆的颜色(默认为第2格的橙色)。接下来的职业行(包括变身)和“未知职业”(无法判别职业的玩家)是玩家的图标和圆的颜色。

## 注意

- 附近的玩家和敌人只显示在自己附近(约90m以内)的对象
- 队伍成员即使离得远，只要在同一张地图上也会显示。是否在战斗中只能在附近时判别，因此离得远的队伍成员总是显示为不在战斗中
- 场地标记只在放置标记的人在附近时显示。切换地图后消失
- 位置标记在点击新的链接、选择“清除位置标记”或登出时消失。切换地图不会消失
- 在游戏途中启动应用时，在自己移动之前可能什么都不显示
- 即使打开历史记录，也会显示当前的位置
