这是将一名玩家的深眠心相仪中生效的节点效果、高级节点效果、因子每行一个排列显示的小组件。

## 打开方式

- 在“[小组件](小组件)”的“深眠心相仪信息”卡片中，从名称栏的下拉列表中选择对象，然后点击启动按钮。默认对象为自己
- 右键点击[玩家列表](玩家列表)和[复活列表](复活列表)的行，选择“深眠心相仪信息”也可以打开
- 按对象打开窗口。同一对象的窗口已打开时，会将该窗口显示到前台

## 查看方式

- 标题：“深眠心相仪信息 - 玩家名称”
- 行：左侧为图标，右侧为名称。按节点效果 → 高级节点效果 → 因子的顺序排列
- 高级节点效果的名称为“通用1”～“通用5”，图标因类型而异
- 因子的名称：其他玩家不带因子等级(“巨刃真实因子X6”等)，自己带有因子等级(“G10”等)
- 没有任何内容时为空

## 操作

- 将鼠标悬停在行上会显示背景。点击不会有任何反应
- 行在窗口中放不下时，用滚轮或右侧的滚动条移动

## 设置

只有窗口设置和主题([小组件通用设置](小组件通用设置))。

## 注意

- 自己和其他玩家能了解的内容不同。游戏不会发送其他玩家的因子，因此只显示能从效果附加的增益中了解到的部分

| | 自己 | 其他玩家 |
|---|---|---|
| 节点效果、高级节点效果 | 显示 | 显示 |
| 因子 | 全部(包括不附加增益的因子) | 只显示附加增益的因子 |
| 因子等级(“G10”等) | 显示 | 不显示 |

- 自己的因子根据深眠心相仪的养成数据显示。在游戏途中启动应用时，在切换地图之前与其他玩家的显示方式相同
- 不显示类型本身(显示在[玩家列表](玩家列表)和[玩家信息](玩家信息)中)。也不显示破妄心相仪，以及高级节点中各类型专用的效果
- 其他玩家的数据在该玩家位于附近期间发送。不会通过队伍信息发送
- 离开玩家列表的人也会继续显示最后了解到的数值。登出后会清除
- 打开历史记录期间，对于在该战斗中的人，会以当时的数值显示
